第16章 R 第8节 torch for R

引言

R语言为深度学习的三大主流深度学习框架（TensorFlow、Keras、PyTorch）都提供了功能强大的接口包，让R用户能直接在熟悉的环境中进行复杂的深度学习任务。

1.tensorflow

tensorflow 包是R语言访问完整TensorFlow API的官方接口。

  • 核心功能：它提供了对TensorFlow核心功能的完全访问，包括张量（Tensor） 操作、自动微分以及数据流图（Data Flow Graph） 的构建与执行。作为底层框架，它负责所有数值计算。
  • 设计定位：它是构建更高级API（如keras）的基础。你可以直接用它来构建自定义的计算图或模型，但通常需要编写更多代码。
  • 硬件加速：支持利用CPU或GPU进行加速计算，这对于大规模深度学习训练至关重要。

2.keras / keras3

keras 包（以及新一代的 keras3 包）为R用户提供了高层次的神经网络API，极大地简化了模型构建和训练流程。

  • keras vs keras3：旧的 keras 包是专为TensorFlow后端设计的（Keras 2.x）。而新的 keras3 包则连接了Keras 3，其最大特点是后端无关性，支持在 TensorFlow、JAX 或 PyTorch 等多个后端之间自由切换。对于新项目，官方推荐使用 keras3。
  • 主要特点：
    • 用户友好：API设计简洁直观，便于快速原型开发。
    • 模块化：可以像搭积木一样，通过组合不同的层（Layers）、优化器（Optimizers） 和损失函数（Loss Functions） 来构建模型。
    • 功能全面：内置了对卷积神经网络（CNN，用于计算机视觉）、循环神经网络（RNN，用于序列处理） 等多种网络结构的支持。
    • 跨硬件运行：代码可以无缝地在CPU或GPU上运行。

3.torch

torch 包是R语言对流行深度学习框架 PyTorch 的移植。

  • 纯R实现：与依赖Python后端的tensorflow不同，torch包是完全用R编写的，底层基于 libtorch（PyTorch的C++库）。这意味着它没有Python依赖，对R用户更加纯粹。
  • 核心功能：提供与PyTorch类似的功能，包括张量（Tensor） 运算、自动梯度（Autograd） 系统以及神经网络（NN） 模块。
  • 动态计算图：继承了PyTorch的动态计算图特性，使得模型调试和修改更加灵活直观。
  • 硬件加速：同样支持GPU加速。

在当今深度学习领域，TensorFlow、Keras 与 PyTorch 并称为三大主流开源框架。三者各有千秋。尽管TensorFlow（含Keras）作为工业界的重要成员，具备不可替代的价值，但若论及科研灵活度、社区活跃度以及实际落地场景的覆盖广度，PyTorch 无疑已占据显著优势。

作者本人在日常研发工作中长期深度使用 PyTorch 框架，积累了较多的实践经验，也熟悉其常见陷阱与性能调优技巧。基于这份熟悉与信任，同时也为了帮助读者避开我曾经走过的弯路，本节将集中于 Torch 的深度讲解

一、torch包简介

torch 包为 R 语言用户提供了一个强大、原生且无需依赖 Python 的深度学习框架。它是广受欢迎的 PyTorch 库在 R 语言中的“移植”版本，让 R 用户能够直接在 R 环境中使用与 PyTorch 类似的功能和 API 来构建和训练神经网络。

其核心特点在于，它并非简单地用 reticulate 封装 Python 的 PyTorch，而是直接构建于 PyTorch 底层的 C++ 库 libtorch 之上。这种设计带来了两大优势：

  • 无需 Python 环境：用户无需安装和配置 Python，极大地简化了安装和部署流程。

  • 性能与稳定性：通过底层的 C++ 实现，确保了高性能，并避免了跨语言调用可能引入的问题。

1.核心功能

torch 包提供了从基础张量操作到高级神经网络构建的全套工具，其核心功能模块主要包括：

1.1.张量（Tensor）

这是深度学习的基石，类似于 NumPy 的多维数组，但支持在 GPU 上加速运算。

  • 创建与转换：可以用 torch_tensor() 从 R 的数组（array）创建张量，并用 as_array() 转回 R 数组。
  • 设备支持：张量可以轻松地在 CPU 和 GPU 之间移动，例如 torch_tensor(1, device = "cuda") 将张量创建在 GPU 上。

1.2.自动微分（Autograd）

torch 的核心功能，能够自动计算张量的梯度，这是训练神经网络的基础。

  • 示例：下面的代码展示了如何自动计算简单函数 y = w * x + b 关于参数 x, w, b 的梯度。
library(torch)




x <- torch_tensor(1, requires_grad = TRUE)
w <- torch_tensor(2, requires_grad = TRUE)
b <- torch_tensor(3, requires_grad = TRUE)




y <- w * x + b
y$backward()  # 计算梯度




x$grad  # 输出: 2
w$grad  # 输出: 1
b$grad  # 输出: 1

1.3.神经网络模块（nn 和 nnf）：提供构建神经网络的“乐高积木”。

  • nn_module：用于定义包含可训练权重的神经网络层或完整模型。例如 nn_linear()（线性层）、nn_conv2d()（卷积层）。
  • nnf_* (nn functional)：提供无状态（不包含可训练权重）的函数式版本，如激活函数 nnf_relu()、nnf_softmax() 等。

1.4.优化器（Optimizers）：实现了多种优化算法来更新模型权重，以最小化损失函数。

  • 包括 optim_sgd() (随机梯度下降)、optim_adam() (Adam)、optim_rmsprop() (RMSprop) 等。

1.5.数据加载（Data Loading）：提供了高效的数据处理工具。

  • dataset：一个抽象类，用于定义自定义数据集。
  • dataloader：组合数据集和采样器，提供批量、多进程的迭代方式，方便模型训练。

1.6.损失函数（Loss Functions）：提供了用于训练的常用损失函数。

  • 例如 nn_mse_loss() (均方误差损失)、nn_cross_entropy_loss() (交叉熵损失) 等。

2.安装与配置

torch 包的安装非常直接，主要步骤如下：

2.1.安装 R 包：

可以从 CRAN 或 GitHub 安装。

# 从 CRAN 安装稳定版
install.packages("torch")


# 从 GitHub 安装开发版（获取最新功能）
remotes::install_github("mlverse/torch")

2.2.安装 LibTorch

首次加载 torch 包时，它会自动检测系统环境（如是否有 CUDA 支持的 NVIDIA GPU），并下载并安装相应版本（CPU 或 GPU）的 libtorch 库。这一过程由 install_torch() 函数管理。

如果电脑未安装NVIDIA CUDA环境，则默认安装基于CPU环境。安装CPU版本的torch过程比较简单，正常情况按提示默认执行安装即可。如果要安装基于NVIDIA GPU和CUDA的环境，安装过程相对比较复杂，我们将在后文详细介绍。

3.生态系统

围绕 torch 包，一个丰富的生态系统正在形成，提供了更高级和便捷的功能：

  • luz：一个高级接口，极大地简化了训练流程。它封装了训练、验证、早停、学习率调度等繁琐的循环代码，让用户能像在 Keras 中一样简洁地训练模型。
  • torchvision：专门用于计算机视觉任务，提供了流行的数据集、数据增强工具和预训练模型。
  • torchaudio：专门用于计算机音频任务。
  • cito：另一个高级接口，允许用户使用 R 的公式语法（如 y ~ x1 + x2）来构建和训练神经网络，对熟悉 R 统计建模的用户非常友好。

二、学习资料

torch 包为 R 语言社区带来了顶级深度学习框架的能力，并且设计得对 R 用户非常友好。如果你希望在 R 环境中进行深度学习，它是一个非常理想的选择。

1.官方文档

R 的 torch 包官方文档网站是 https://torch.mlverse.org/docs。这是一个为 R 语言用户设计的、基于 PyTorch 的深度学习框架的完整知识库。

文档网站结构清晰，方便用户按需查找：

  • 起步指南 (Articles)：包含从安装到序列化等一系列入门文章。例如，有专门文章介绍如何加载数据。
  • 参考 (Reference)：提供了所有函数的详细 API 文档，是开发时的必备工具。
  • 高级主题 (Advanced)：涵盖内存管理、CUDA 兼容性、自动混合精度 (AMP) 等进阶内容。
  • 示例 (Examples)：包含从基础（basic-autograd, basic-nn-module）到具体应用（如 dataset）的各类示例。
  • 生态系统：文档首页也提到了 torch for R 是一个包含多个扩展包的生态系统。

该文档为 R 用户使用 torch 进行从张量操作到复杂神经网络训练的各项工作，提供了全面且结构化的指南。

2.《Deep Learning and Scientific Computing with R torch》

《Deep Learning and Scientific Computing with R torch》是一本为R语言用户编写的、关于使用 torch 包进行深度学习和科学计算的实用指南。

这本书为那些希望使用R语言进行深度学习，但又不想转向Python的统计学家和研究人员提供了完美的解决方案。

2.1.书籍基本信息

  • 作者：Sigrid Keydana。
  • 出版时间：2023年4月1日。
  • 免费在线版本：https://skeydan.github.io/Deep-Learning-and-Scientific-Computing-with-R-torch/
  • 源代码：所有源代码和相关资源托管在GitHub上：https://github.com/skeydan/Deep-Learning-and-Scientific-Computing-with-R-torch。
  • 纸质书/电子书：可通过 CRC Press、Amazon 等渠道购买
  • 本书的在线版本采用”知识共享署名-非商业性使用-相同方式共享 4.0国际许可协议“授权 (CC BY-NC-4.0）。

2.2.核心特点与目标读者

这本书最大的特点是为R语言用户量身打造，目标是让不熟悉Python的R用户也能轻松上手深度学习。其核心特点包括：

  • 概念优先，易于理解：本书以清晰、平易近人的方式解释复杂概念，并通过大量示例和代码进行说明。
  • 实用性强：书中提供了丰富的应用案例，范围涵盖图像识别、时间序列预测和音频分类等。
  • 全面的入门指南：它不仅是深度学习的教程，也展示了torch在更广泛的科学计算领域的应用。

目标读者非常广泛，包括：

  • 统计学家和其他应用型研究人员，他们精通R但不熟悉Python。
  • 本科生、硕士生和博士生，他们了解R并希望开始拟合深度学习模型。
  • 任何没有广泛机器学习背景的R用户。

2.3.内容结构

全书共28章，清晰地分为三个部分：

第一部分：熟悉 torch (第1-11章) 这部分是全书的基础，旨在让读者掌握 torch 的核心概念。 * 入门与安装：介绍如何在不安装Python的情况下，在R环境中安装 torch 及相关包。 * 核心构件：详细讲解张量（Tensors）、自动微分（Autograd）、优化器（Optimizers）和模块（Modules）。 * 从零开始：引导读者从张量开始，手动构建并训练一个用于回归任务的小型神经网络，这有助于理解底层原理。

第二部分：使用 torch 进行深度学习 (第12-22章) 这部分聚焦于如何使用 torch 实现各种深度学习模型。 * 数据处理：介绍如何批量加载数据以应对大数据集。 * 高效训练：引入 luz 包，它进一步简化了神经网络的训练、验证和测试流程。 * 实战应用：通过一系列案例，展示如何解决实际问题，如图像分类、图像分割、处理表格数据、时间序列预测和音频分类等。

第三部分：torch 的其他应用 (第23-28章) 这部分展示了 torch 在深度学习之外的科学计算能力。 * 矩阵计算：探讨如何使用 torch 解决最小二乘问题等。 * 信号处理：介绍离散傅里叶变换（DFT）、快速傅里叶变换（FFT）和小波（Wavelets）等主题。

2.4.优点与不足

  • 优点：
    • 上手快：相比其他R语言深度学习方案（如Keras），torch 包的安装和使用过程更简单、稳定。
    • 可读性强：文笔生动有趣，易于阅读。
  • 不足：
    • 理论不深：本书并非一本厚重的理论著作，对于希望深入了解算法背后数学原理的读者，可能需要补充其他资料。

无论如何，这本书是R语言社区中弥合“R语言技能”与“深度学习应用”之间鸿沟的重要作品。是我最推荐的关于R torch的第一阅读书籍。

3.《A Minimal rTorch Book》

《A Minimal rTorch Book》是一本旨在帮助R语言用户快速上手rTorch包（R语言与PyTorch的桥梁）的入门教程。这本书的核心特点是 “极简” 与 “实用”，它并非一本面面俱到的百科全书，而是一份旨在让读者“在乐趣中学习”的快速指南。

3.1.书籍概要

  • 作者：Alfonso R. Reyes。
  • 免费在线版本：：https://f0nzie.github.io/rtorch-minimal-book/。
  • 源代码：所有源代码和相关资源托管在GitHub上：https://github.com/f0nzie/rtorch-minimal-book。

3.2.核心特点与目标读者

  • 为R用户量身打造：本书是写给那些希望在R环境中使用PyTorch强大功能的R语言使用者。
  • 动机明确：作者写作的初衷是，虽然可以直接用Python写PyTorch，但难以割舍RMarkdown在文学化编程（Literate Programming） 和可重复性研究方面的卓越体验。
  • 强调R与Python的协同：它展示了如何在同一个RMarkdown文档中无缝地混合使用R和Python代码，各取所长。

3.3.主要内容

这本书通过一系列精心设计的章节，引导读者从入门到实践：

  • 环境配置：详细指导如何安装Anaconda、R、Rtools、RStudio，以及reticulate和rTorch包。
  • 基础入门：介绍如何开始使用rTorch，获取PyTorch版本和配置信息。
  • 核心概念：通过对比，阐明rTorch与原生PyTorch在语法上的主要差异（例如，R中使用$符号调用模块和方法）。
  • 实践案例：提供了丰富的实战示例，包括：
    • 线性回归：以“降雨量预测”为例，展示从数据到模型的全过程。
    • 逻辑回归：解决分类问题。
    • 神经网络：从零开始，分步构建神经网络。
    • 数据操作：展示如何将R语言中熟悉的data.frame与PyTorch张量结合使用。

值得一提的是，作者还计划了另一本进阶教程《rTorch Advanced Examples》，可以作为本书的补充学习材料。

总的来说，这本书是一份非常友好的rTorch入门教程。如果你是一位希望涉足深度学习领域的R语言用户，它会是一个很棒的起点。

4. 社区学习资源：R4DS Book Club

“R4DS Book Club”是一个围绕经典书籍 《R for Data Science》（简称R4DS） 组织起来的全球性、公益性的在线学习社区。它的正式名称是 “数据科学学习社区”（Data Science Learning Community, DSLC）。该社区始于2017年，最初就是为了共同阅读《R for Data Science》这本书而创立。如今，它已发展成为一个举办各种数据科学相关书籍读书会的活跃社区。

以下是关于它的详细介绍：

4.1.核心书籍

读书会研读的核心书籍是 《R for Data Science》 。

三、R torch & GPU 环境安装指南

本文我们以Windows系统为例进行讲解，MacOS和Linux系统可参考Windows系统。

1.前置条件

在常规的 R 包安装之后，torch 还需要安装另外两个库：LibTorch 和 LibLantern。以Windows系统下，

如果你没有 GPU，或者只想要安装 CPU 版本的 torch，可以运行以下命令安装：

install.packages("torch")  


library("torch")  


# 之后按提示默认执行即可。

如果想要安装 GPU版本的 torch，要在 torch 中使用 GPU，你需要：

  • 拥有一块支持 CUDA 的 NVIDIA GPU。你可以在这里查询你的 GPU 是否支持 CUDA。

  • 正确安装 NVIDIA CUDA Toolkit 12.8 版本。关于 CUDA v12.8，请按照此链接的安装说明进行操作。

    注意：CUDA Toolkit 的版本必须与上述版本完全一致。

  • 安装 cuDNN 。要求与 CUDA v12.8 兼容。请按照此链接的安装说明进行操作。

  • torch 对支持的 CUDA 和 CUDNN 版本有非常具体的要求。

安装好了以上所有前置条件，才可以安装 torch。

install.packages("torch")  


library("torch")  # 滞后按提示默认执行即可。

如果你采用了默认的安装位置，R会检测到你已安装 CUDA 软件，并自动下载启用 GPU 的 Lantern 二进制文件。你也可以通过设置 CUDA 环境变量来强制指定某个特定版本的 CUDA Toolkit，例如：

Sys.setenv(CUDA="12.8")

请参考兼容性矩阵来选择你的版本。

2.方法一：使用 cudatoolkit R 包

根据官方文档，torch 的 GPU 环境安装主要有两种方式。其中，使用 cudatoolkit R 包是官方最新推荐的方法。

这是 torch 官方文档在当前版本中首推的方法。你无需在系统上完整安装 CUDA Toolkit，只需安装对应的 R 包即可提供 CUDA 运行时库。

操作步骤：

# 1. 安装 cudatoolkit R 包（以 CUDA 12.8 为例）
install.packages("cuda12.8",
                 repos = c("https://mlverse.r-universe.dev",
                           "https://cloud.r-project.org"))


# 2. 然后正常安装 torch
install.packages("torch")

说明：

  • 支持的 CUDA 版本有 12.6、12.8、12.9。

  • torch 启动时会自动检测已安装的 cudatoolkit R 包并使用。

  • 如果安装了多个版本，会自动选用最新的受支持版本。

环境变量

TORCH_CUDATOOLKIT 环境变量控制 cudatoolkit R 包的检测行为：

  • 未设置（默认）：torch 自动检测已安装的 cudatoolkit R 包。
  • 设置为特定版本（例如 TORCH_CUDATOOLKIT=12.8）：强制 torch 使用该特定版本的 cudatoolkit R 包。如果该包未安装则会报错。如果同时还设置了 CUDA，这两个值必须一致。
  • 设置为 FALSE：完全禁用 cudatoolkit R 包检测。torch 将仅使用系统 CUDA（通过 CUDA_HOME、CUDA_PATH 或 nvcc）。
# 强制 torch 使用 cuda12.8 这个 R 包
Sys.setenv(TORCH_CUDATOOLKIT = "12.8")


# 或者，完全禁用 cudatoolkit R 包的检测
Sys.setenv(TORCH_CUDATOOLKIT = "FALSE")


# 设置完成后，再加载 torch 包
library(torch)

完整的 CUDA 版本检测优先级如下：

  1. TORCH_CUDATOOLKIT：显式指定 cudatoolkit R 包。
  2. CUDA：如果已安装匹配的 cudatoolkit R 包则使用它；否则直接将该值用于系统 CUDA。
  3. 自动检测已安装的 cudatoolkit R 包。
  4. 系统 CUDA：CUDA_HOME / CUDA_PATH、常规路径、PATH 中的 nvcc。

当通过上述步骤 1-3 中的任意一步找到了 cudatoolkit R 包时，系统 CUDA 检测将被完全跳过。

3.方法二：从预编译二进制包安装

从 torch v0.9.1.9000 开始，官方提供了一个 CRAN 风格的仓库，其中的预编译二进制包已经包含了所有必要的共享库（包括 CUDA 和 cuDNN），因此同样无需手动安装 CUDA 或 cuDNN。

操作步骤：

options(timeout = 600)  # 建议增加超时时间，因为要下载约 2GB 的文件


# 选择 GPU 版本（"cu128" 表示 CUDA 12.8）
kind <- "cu128"


version <- available.packages()["torch","Version"]


options(repos = c(
  torch = sprintf("https://torch-cdn.mlverse.org/packages/%s/%s/", kind, version),
  CRAN = "https://cloud.r-project.org"
))


install.packages("torch")

安装完成后运行：

library(torch)


cuda_is_available()

返回 TRUE 即表示 GPU 已就绪。

4.方法三：手动安装 CUDA Toolkit + cuDNN

尽管官方推荐的方法一和方法二都不需要手动安装 CUDA Toolkit 和 cuDNN，但对其版本的匹配方法并未做详细介绍。

方法三介绍的手动安装是我花费大量精力和时间摸索出来的方法，可以帮助大家更明确的了解整个安装过程，更好的解决上述方法遇到的软硬件版本匹配问题。

必须强调的安装核心原则：

必须确保“R torch版本 -> LibTorch版本 -> CUDA版本 -> cuDNN版本 -> 显卡驱动版本”这一链条完全匹配。

再次提示：对于Windows平台，你需要：

  • 拥有支持 CUDA 的 NVIDIA GPU （显卡）

  • 安装与之匹配版本的显卡驱动版本

  • 安装 NVIDIA CUDA Toolkit

  • 安装与 CUDA 兼容的 cuDNN

  • 安装与之匹配的LibTorch版本

  • 安装与之匹配的R torch

4.1.第一步：软件依赖关系确认

开始任何操作前，必须先规划并确认好版本组合。你可以通过以下步骤获得版本信息，并使用下表梳理你的方案。

  1. 确认 R torch 及其对应的 LibTorch 版本

    在R中执行install.packages("torch")并加载库(library(torch))，安装程序会自动下载匹配的LibTorch。

    安装日志中显示的LibTorch文件名（如libtorch-win-shared-with-deps-2.7.1%2Bcpu.zip）即指明了其版本。

    注意：由于未安装 CUDA，它会默认安装 CPU 版的，需要及时停止。

  2. 确认所需 CUDA 版本

    访问PyTorch历史版本页面，根据上一步确定的 LibTorch 版本（如2.7.1），查找其对应的官方指定的CUDA版本（如CUDA12.8）。请以此官方信息为准。

  3. 确认所需 cuDNN 版本

    根据上一步确定的 CUDA 版本，继而确定 cuDNN 版本 。

    访问：https://docs.nvidia.com/deeplearning/cudnn/backend/latest/reference/support-matrix.html#support-matrix。

    以上网页中介绍了 NVIDIA cuDNN 版本与各种受支持的 NVIDIA CUDA Toolkit、CUDA 驱动程序以及 NVIDIA 硬件版本之间的兼容性。

  4. 确认显卡驱动要求

    根据上一步确定的CUDA版本，到NVIDIA官方文档确认该版本CUDA所要求的最低显卡驱动版本。

4.2.第二步：安装前系统准备

  1. 安装 VisualC++ Redistributable

    前往Microsoft官网下载并安装最新的VC_redist.x64.exe。

    这是LibTorch在Windows上运行的必备组件。

    注意，务必更新安装最新版。 Microsoft Visual C++ Redistributable latest supported downloads Latest supported Visual C++ Redistributable downloads | Microsoft Learn

  2. 安装VisualStudio（可选）

    如果你未来需要进行C++扩展开发，可安装VisualStudio并在安装时勾选“使用C++的桌面开发”工作负载。

  3. 更新显卡驱动

    以管理员身份运行从NVIDIA官网下载的最新驱动。

    建议在“自定义安装”中选择“执行清洁安装”，以确保旧驱动组件被彻底清理。

4.3.第三步：安装 CUDA Toolkit

  1. 下载

    前往CUDAToolkitArchive，选择与你规划版本完全一致的安装包。

  2. 安装

    运行安装程序，在安装类型界面选择“自定义”。

    在组件选择中，建议取消勾选“Visual Studio Integration”和“Driver components”，仅保留必要的CUDA工具包组件，避免与现有驱动或环境冲突。

  3. 验证

    安装完成后，打开新的命令提示符（CMD），输入nvcc--version。

    如果正确显示你安装的CUDA版本号，则表明安装成功。

4.4.第四步：安装与配置cuDNN

  1. 下载

    前往cuDNNArchive，登录后下载与你CUDA版本精确匹配的cuDNN。

    例如，对于CUDA12.x，应选择标题中带有_cuda12字样的压缩包（如cudnn-windows-x86_64-9.7.1.26_cuda12-archive.zip）。

  2. 安装（本质是文件复制）

    解压下载的cuDNN压缩包，会得到bin、include、lib三个文件夹。

    导航到CUDA安装目录（通常是C:\ProgramFiles\NVIDIAGPUComputingToolkit\CUDA\v12.x）。

    将解压出的三个文件夹内的所有内容，分别复制到CUDA目录下对应的同名文件夹中。

  3. 配置环境变量

    确保系统环境变量PATH中包含CUDA的bin和libnvvp目录，例如： C:2.8C:2.8

    检查并确保存在CUDA_PATH变量，其值应为C:\ProgramFiles\NVIDIAGPUComputingToolkit\CUDA\v12.8。

4.5.第五步：安装验证与测试

建议按照以下顺序进行验证，确保底层支持完好，最后再次安装R包。

  1. CUDA基础测试

    以管理员身份打开CMD，进入CUDA示例目录并运行两个测试程序：

    cd C:2.8_suite deviceQuery.exe 和 bandwidthTest.exe 两个测试的Result=PASS是CUDA环境就绪的关键标志。

  2. 安装与验证Rtorch

    在R或RStudio中运行：install.packages(“torch”)

    安装完成后，加载包并进行GPU可用性验证： library(torch)

    查看CUDA是否可用 cuda_is_available() ，返回TRUE为成功

    查看检测到的CUDA版本 cuda_version()

    查看检测到的cuDNN版本 backends_cudnn_version()

版本管理： 严格遵守依赖链条。若需更换版本，建议从更新驱动开始，并按顺序重装CUDA、cuDNN，最后重新安装Rtorch。

5.libTorch

LibTorch 是 Rtorch 和 PyTorch 的 C++ 前端库。LibTorch 是Python 的 PyTorch 项目的核心。PyTorch 底层是基于它们构建的。

和 PyTorch 类似，R torch 包的底层引擎也是 C++ 的 LibTorch，R torch 和 LibTorch 的关系是：

  • 底层引擎是 C++：R torch 包官方说明指出，它完全基于 LibTorch 库构建。所有张量运算、自动求导、GPU 加速这些核心计算，都是 C++ 实现的，R 包只是一个调用接口。

  • 中间层有少量 C：为了实现 R 和 C++ 的跨编译器兼容（尤其在 Windows 上），开发者曾引入了一个叫 Lantern 的 C 语言接口层来“嫁接” libtorch，因此底层也含有极小部分的 C 代码。

  • 安装即下载 C++ 库：你安装 R torch 时，install_torch() 命令会自动从 PyTorch 官网下载并配置好对应的 LibTorch 二进制文件（以及 LibLantern）。这本质上就是在你的 R 环境里装好这个 C++ 引擎。

R torch 和 PyTorch 是 “兄弟”关系：

  • 共同的底层引擎：R torch 和 Python PyTorch 都直接依赖同一个 C++ 核心库 —— LibTorch。

  • 各自独立封装：PyTorch 用 Python 封装 LibTorch；R torch 用 R/C++ 封装 LibTorch。两者是平行且独立的两套前端。

R torch 不调用 Python：

  • R torch 在运行时 完全不需要安装 Python，也不会启动 Python 进程。
  • 它通过 R 的 C++ 扩展（Rcpp）直接调用 libtorch 的 C++ API。
  • R torch 是一个 原生 R 包，并不是 Python 的 wrapper（封装器）。

结论： R torch 的底层引擎（C++ LibTorch）和 PyTorch 一样，但 R 前端是独立重写的，两者只是在“发动机”上相同，而非一个依赖另一个。

四、Torch 内存管理

cuda_empty_cache() 是 R Torch 中的一个函数，用于清空 CUDA 缓存分配器持有的未使用内存，将这些内存释放回系统，以便其他进程或应用程序使用。

要理解这个函数，首先需要了解 PyTorch 如何管理 GPU 内存：

  • 1. 缓存分配器：R Torch 使用一个缓存内存分配器来加速内存分配。当张量被释放时，R Torch 通常不会立即将内存返还给系统，而是保留在自己的缓存池中。这样，当需要分配新张量时，可以直接从缓存中快速分配，而不用向系统申请，大大提升了性能。
  1. 内存碎片：频繁分配和释放不同大小的张量会导致内存碎片。即使总空闲内存很多，也可能因为没有足够大的连续内存块而无法分配大张量。

cuda_empty_cache() 就是用来解决上述问题的：

功能：强制清空 R Torch 缓存分配器中所有未使用的、缓存的内存块，将它们释放回系统。它不会释放当前正被张量占用的内存，只释放那些已经被 R Torch 标记为空闲但还保留在缓存中的内存。

主要应用场景 ：

  • 1在多个 R Torch 进程或实验之间：当你完成一个实验或训练任务，准备开始下一个时，调用此函数可以确保干净的内存状态。

  • 2内存不足错误之前：当你预计接下来要分配一个非常大的张量，并且之前的内存操作产生了很多碎片时，可以尝试先清空缓存。

  • 3与其他 GPU 应用程序共享时：如果你需要在 R Torch 和其他 GPU 应用程序（如 TensorFlow、游戏、渲染软件）之间切换，调用此函数可以释放 R Torch 占用的 GPU 内存给其他程序使用。

  • 4在评估/推理阶段：在训练后进行评估时，如果遇到内存不足，可以调用此函数释放训练过程中缓存的但不再需要的内存。

注意：

  • 性能影响：频繁调用 empty_cache() 会降低性能，因为它清空了缓存，后续的内存分配需要重新向系统申请。不要在训练循环中调用它。
  • 不是万能药：它不能解决真正的内存泄漏问题。如果张量仍然有引用，内存不会被释放。它不能增加可用的 GPU 内存总量，只是更好地利用现有内存。
  • 监控工具：使用 torch.cuda.memory_summary() 或 nvidia-smi 来监控实际的内存使用情况，判断是否需要调用此函数。
  • 替代方案：有时使用 torch.cuda.synchronize() 确保所有操作完成后再测量内存会更准确。对于内存碎片问题，可以考虑调整张量分配策略或使用内存优化技术。
