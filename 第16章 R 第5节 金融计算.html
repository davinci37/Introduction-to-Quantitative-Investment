第16章 R 第5节 金融计算

引言

金融计算是量化投资、金融工程、风险管理和资产定价的核心技术基础。R语言凭借其深厚的统计学基因、丰富的金融计算包生态以及卓越的数据可视化能力，是金融数据分析与建模的首选工具之一。

量化投资中，比较重要的金融计算场景包括：技术指标计算、策略回测、绩效分析、以及衍生品定价等等。本文，我们将系统介绍R语言在这些金融计算场景中的常用包：TTR、quantmod、PerformanceAnalytics、和RQuantLib。

一、TTR包：技术指标计算

1. TTR包概述

TTR（Technical Trading Rules）是R语言中技术分析函数最为全面的包之一，提供了超过50种主流技术指标的计算实现，广泛用于系统化交易策略的构建和金融图表的绘制。该包由Joshua Ulrich开发维护，与xts包深度集成，支持对时间序列数据的高效处理。

TTR包的核心定位是提供金融市场数据最常用的技术分析函数集合。它包含超过50种技术指标，这些指标广泛用于系统性交易策略的构建和金融图表的绘制。此外，该包还提供了滚动窗口函数的高效实现以及多种波动率计算方法。

2. TTR包的技术指标

TTR包的技术指标可按功能划分为五大类别。以下逐一详述。

2.1 移动平均类（Moving Averages）

移动平均是技术分析中最基础的指标类别，TTR包提供了极为丰富的移动平均函数：

函数 全称 核心特征
SMA() Simple Moving Average 算术平均，对过去n期观测值等权计算
EMA() Exponential Moving Average 指数加权平均，赋予近期数据更高权重
DEMA() Double Exponential Moving Average 双指数移动平均，通过双重平滑减少滞后
WMA() Weighted Moving Average 加权移动平均
EVWMA() Elastic Volume Weighted Moving Average 弹性成交量加权移动平均
ZLEMA() Zero-Lag Exponential Moving Average 零滞后指数移动平均
VWAP() Volume Weighted Average Price 成交量加权平均价格
VMA() Variable Moving Average 可变移动平均
HMA() Hull Moving Average 赫尔移动平均
ALMA() Arnaud Legoux Moving Average 阿诺·勒古移动平均
GMMA() Guppy Multiple Moving Average 顾比多重移动平均

函数调用范式：

library(TTR)


# 加载示例数据（模拟的OHLCV数据，1985-2006年）
data(ttrc)


# 计算20期指数移动平均
ema_20 <- EMA(ttrc[,"Close"], n = 20)


# 计算20期简单移动平均
sma_20 <- SMA(ttrc[,"Close"], n = 20)

2.2 动量与振荡指标类（Momentum & Oscillators）

此类指标用于衡量价格变动的速度和幅度，是识别趋势强度和潜在反转点的核心工具。

相对强弱指标（RSI） ：RSI()是衡量价格变动速度和幅度的经典动量振荡器，取值范围0-100，通常以70/30作为超买/超卖的阈值分界线。

平滑异同移动平均线（MACD） ：MACD()由快速EMA、慢速EMA和两者的差值（MACD线）及其信号线组成，是识别趋势方向变化的重要工具。

随机指标（Stochastics） ：stoch()和SMI()（Stochastic Momentum Index）用于比较收盘价与一定时期内价格区间的相对位置，%K和%D两条线的交叉产生交易信号。

其他动量指标：

函数 指标名称 核心用途
CCI() Commodity Channel Index 商品通道指数，识别超买超卖
CMO() Chande Momentum Oscillator 钱德动量振荡器
DPO() De-Trended Price Oscillator 去趋势价格振荡器，消除长期趋势
TRIX() Triple Exponential Average 三重指数平滑平均，过滤微小波动
KST() Know Sure Thing 综合多个时间框架的动量指标
ultimateOscillator() Ultimate Oscillator 终极振荡器，捕捉三个不同时间框架的动量
DVI() DV Intermediate Oscillator DV中级振荡器

2.3 波动率与通道类（Volatility & Channels）

此类指标用于衡量价格波动幅度和构建价格通道。

布林带（Bollinger Bands） ：BBands()由John Bollinger创立，是基于移动平均和标准差构建的自适应波动率通道，最常使用HLC序列的典型价格（Typical Price），也可基于单变量价格序列计算。计算公式为：中轨 = n期移动平均，上轨 = 中轨 + k倍标准差，下轨 = 中轨 - k倍标准差。

唐奇安通道（Donchian Channel） ：DonchianChannel()基于一定时期内的最高价和最低价构建通道，是海龟交易法则的核心指标。默认参数include.lag=FALSE表示包含当前周期在内的计算，与其他TTR函数保持一致。

平均真实波幅（ATR） ：ATR()计算真实波幅（True Range）的Welles Wilder式移动平均，是衡量市场波动性的经典指标。真实波幅定义为以下三者中的最大值：当日最高-最低、当日最高-前日收盘、前日收盘-当日最低。

其他波动率指标：

函数 指标名称 说明
volatility() Volatility Estimators 多种波动率估计器，支持基于收盘价或OHLC的计算
PBands() Performance Bands 可进一步平滑和中心化的波动率通道
chaikinVolatility() Chaikin Volatility Chaikin波动率

2.4 趋势与方向类（Trend & Direction）

此类指标用于识别和量化市场趋势的方向与强度。

动向指标（ADX） ：ADX()（Average Directional Movement Index）是Welles Wilder开发的经典趋势强度指标，由ADX线、+DI（正向方向指标）和-DI（负向方向指标）三部分组成。ADX值高于25通常表示强劲趋势，低于20表示无趋势或盘整市场。

阿隆指标（Aroon） ：aroon()用于识别趋势的开始和结束，包含Aroon Up和Aroon Down两条线。

2.5 成交量与资金流类（Volume & Money Flow）

此类指标将成交量信息纳入分析框架，衡量资金的流入流出。

函数 指标名称 核心逻辑
chaikinAD() Chaikin Accumulation/Distribution Chaikin累积/派发线
CMF() Chaikin Money Flow Chaikin资金流
CLV() Close Location Value 收盘价位置值

3.应用示例

以下通过一个完整的示例，展示TTR包多个指标的综合使用：

library(TTR)
library(quantmod)


# 加载示例数据
data(ttrc)


# 提取OHLC数据
hlc <- ttrc[, c("High", "Low", "Close")]


# === 移动平均 ===
sma_20 <- SMA(ttrc[,"Close"], n = 20)
ema_20 <- EMA(ttrc[,"Close"], n = 20)


# === 动量指标 ===
rsi_14 <- RSI(ttrc[,"Close"], n = 14)        # 相对强弱指标
macd_result <- MACD(ttrc[,"Close"])          # MACD
stoch_result <- stoch(hlc)                   # 随机指标


# === 波动率指标 ===
bbands_result <- BBands(hlc)                 # 布林带
atr_result <- ATR(hlc, n = 14)               # 平均真实波幅


# === 趋势指标 ===
adx_result <- ADX(hlc)                       # 动向指标


# === 与quantmod集成可视化 ===
# 将数据转换为xts对象
xttrc <- xts(OHLCV(ttrc), ttrc[["Date"]])


# 绘制K线图并叠加技术指标
chartSeries(xttrc, subset = "2006-09/", theme = "white")
addBBands()    # 叠加布林带
addRSI()       # 叠加RSI

4. 注意事项

滚动窗口函数的高效实现：TTR包不仅提供了技术指标函数，还提供了快速实现通用滚动窗口函数的能力。例如runCor()可用于评估滚动相关性。

数据格式要求：TTR的函数输入对象需可强制转换为xts或matrix格式。对于需要HLC（High-Low-Close）输入的指标（如ATR、ADX、BBands等），必须提供三列数据。

NA值处理：技术指标计算中，由于需要一定数量的历史数据才能产生有效值，指标输出的前n-1个观测值通常为NA。用户在使用时应使用na.omit()或类似方法处理。

在实际量化研究或交易系统开发中，TTR通常与quantmod（数据获取与可视化）、PerformanceAnalytics（绩效评估）等包协同工作，构成从数据到决策的完整链路。

二、quantmod包

1. 概述

quantmod（Quantitative Financial Modelling Framework）是R语言量化金融生态中的核心包之一，由Jeffrey A. Ryan开发、Joshua M. Ulrich维护，旨在为量化交易者提供一个快速原型开发环境，涵盖策略的开发、测试与部署全流程。

其设计哲学正如官方文档所概括的：quantmod是一个具备综合数据管理与可视化工具的快速原型开发环境，量化交易者可以在此快速、清晰地探索和构建交易模型；quantmod不是任何统计方法的替代品，它本身不提供新的建模算法，而是通过封装R语言已有的强大功能，使建模工作更加便捷。

2.核心功能模块

2.1 数据获取

getSymbols()是quantmod最广为人知的功能。它与多源数据集成，只需一个函数即可从多种数据源加载金融数据。支持的数据源包括：

数据源 说明
Yahoo! Finance OHLC数据（默认数据源）
FRED（圣路易斯联储） 超过11,000个经济时间序列
Google Finance OHLC数据
Oanda 外汇与贵金属数据
MySQL数据库 本地数据存储
CSV文件 逗号分隔值文件
RData/rda R二进制格式

基本用法：

library(quantmod)


# 从Yahoo Finance获取苹果公司股票数据
getSymbols("AAPL", src = "yahoo", from = "2020-01-01", to = "2023-12-31")


# 从FRED获取经济数据
getSymbols("DEXJPUS", src = "FRED")  # 美元兑日元汇率


# 从Oanda获取贵金属数据
getSymbols("XPT/USD", src = "Oanda") # 铂金价格

getSymbols()返回的对象与所请求的股票代码同名，自动加载到当前工作空间中。例如：getSymbols("AAPL")会在环境中创建名为AAPL的xts对象。该对象包含Open、High、Low、Close、Volume和Adjusted六列标准OHLCV数据。

2.2 数据管理

quantmod提供了完备的OHLC数据处理工具链：

OHLC数据提取：通过OHLC()、Op()、Hi()、Lo()、Cl()、Vo()、Ad()等函数，可分别提取开盘价、最高价、最低价、收盘价、成交量和调整收盘价。

周期收益计算：periodReturn()函数可根据给定的价格序列计算周期收益，支持日、周、月、季度、年度等不同频率：

# 计算日收益率
daily_returns <- dailyReturn(AAPL)
# 计算月收益率
monthly_returns <- monthlyReturn(AAPL)

2.3 可视化

chartSeries()是quantmod的金融图表绘制引擎，能够以K线图、柱状图或线图等多种形式可视化金融时间序列。其核心技术优势在于：

  • 自动识别数据格式：根据输入数据的类型自动选择最合适的图表样式
  • 技术指标叠加：与TTR包深度集成，可一键添加各类技术指标
  • 多配色主题：支持黑白等多种配色方案
# 基础K线图
chartSeries(AAPL, theme = "white")


# 蜡烛图（多色显示涨跌）
candleChart(AAPL, multi.col = TRUE, theme = "white")


# 叠加技术指标
chartSeries(AAPL)
addMACD()      # 添加MACD
addBBands()    # 添加布林带
addRSI()       # 添加RSI
addSMA(20)     # 添加20期简单移动平均

quantmod还提供了barChart()和lineChart()等便捷包装函数。

用户可通过newTA()函数创建自定义技术指标的图表叠加层：

addFibonacci <- newTA(function(x) Fibonacci(x, n = 55), on = 1)
chartSeries(AAPL, TA = "addFibonacci()")

2.4 建模与交易

quantmod提供了从模型构建到交易模拟的完整框架：

  • 模型构建：buildModel()函数用于构建quantmod模型对象，可指定拟合方法。

  • 交易模拟：tradeModel()是quantmod回测功能的核心函数。给定一个已拟合的模型，tradeModel()计算指定历史时期的交易信号，然后应用指定的交易规则（trade.rule），计算并返回一个tradeLog对象。

应用示例

# 1. 加载包
library(quantmod)


# 2. 获取数据（以标普500 SPY为例）
getSymbols("SPY", from = "2020-01-01", to = "2024-12-31")
price <- Cl(SPY)  # 提取收盘价


# 3. 数据预处理与特征工程（创建滞后因子）
# 注意：quantmod的模型框架依赖公式，且数据需为xts类型
# 我们构建一个简单的数据对象：包含当前收益率和前一日的价格水平
spy_data <- SPY
# 计算当日收益率（作为预测目标）
spy_data$Target <- na.omit(ROC(Cl(spy_data), n = 1, type = "continuous"))
# 计算前一日收盘价相对于近期均线的偏离度（作为预测因子）
spy_data$Factor <- Cl(spy_data) / SMA(Cl(spy_data), n = 10) - 1


# 移除前期的NA值，确保数据整齐
spy_data <- na.omit(spy_data)


# 4. 定义模型规范 (specifyModel)
# 公式含义：预测次日（Next）的收盘开盘变化率，由当前因子（Factor）解释
# Next(OpCl()) 表示明日的开盘到收盘的收益率，这里我们直接用 Next(Target) 做演示
# 为了契合 tradeModel 的自动信号逻辑，我们预测下一期的收益率方向。
spec <- specifyModel(
  Next(Target) ~ Lag(Factor, 1),  # 用前一期的因子预测下一期目标
  data = spy_data
)


# 5. 使用线性回归方法构建模型（在指定的训练集上）
# 这里我们指定 2020-2022 年作为训练集进行拟合
model_fit <- buildModel(
  spec,
  method = "lm",  # 使用线性回归，也支持"nnet", "rpart", "rf"等
  training.data = spy_data["2020-01-01::2022-12-31"]
)


# 查看模型摘要
summary(model_fit)


# 6. 使用训练好的模型进行交易模拟回测
# tradeModel 会将模型预测值作为信号强度，当预测值大于 signal.threshold 时开多，
# 小于负阈值时开空（默认信号阈值为 c(0,0)）
trade_log <- tradeModel(
  model_fit,                    # 已拟合的 quantmod 模型对象
  signal.threshold = c(0.001, -0.001),  # 预测收益率大于0.001买入，小于-0.001卖出
  period = "2023-01-01::2024-12-31",    # 回测期间（样本外）
  trade.rule = tradeRule(length = 1)    # 指定交易规则（持有1期）
)


# 7. 查看回测结果
# trade_log 是一个 S3 对象，打印会显示交易记录摘要
print(trade_log)


# 提取交易明细（交易日期、方向、价格等）
trades <- as.data.frame(trade_log@trades)
print(trades)


# 查看收益率曲线（隐含在 tradeLog 中的 equity 曲线）
# 可以绘制净值曲线
plot(trade_log@equity, main = "Strategy Equity Curve", col = "blue")

重要提醒：
quantmod的建模与交易框架 (buildModel/tradeModel) 是 quantmod 早期的“黑箱”回测封装，目前在业界实际生产中用得较少，它不包含手续费、滑点、止损等高级功能，更适合做简单交易策略的快速演示。

3. 策略信号生成与回测

quantmod本身并不提供独立的回测引擎，而是通过与TTR、PerformanceAnalytics等包的协同，构建完整的回测工作流。其核心价值在于提供了统一的数据基础设施和信号生成框架。

典型的回测流程如下：

library(quantmod)
library(TTR)
library(PerformanceAnalytics)


# 1. 获取数据
getSymbols("SPY", from = "2015-01-01", to = "2024-12-31")
price <- Cl(SPY)  # 提取收盘价


# 2. 计算技术指标并生成交易信号
sma_fast <- SMA(price, n = 20)
sma_slow <- SMA(price, n = 50)
signal <- Lag(ifelse(sma_fast > sma_slow, 1, 0))  # 金叉买入，死叉卖出


# 3. 计算策略收益
returns <- dailyReturn(SPY)
strategy_returns <- returns * signal
strategy_returns <- na.omit(strategy_returns)

quantmod通过Lag()函数实现信号的滞后处理，避免未来信息泄露（look-ahead bias），这是回测中必须遵守的基本原则。

三、PerformanceAnalytics包

PerformanceAnalytics 是 R 语言中用于投资组合绩效与风险分析的核心计量经济学工具包。该包旨在帮助从业者和研究人员应用学术界的最新研究成果，对正态和非正态分布的收益序列进行分析。

1. 设计哲学

PerformanceAnalytics 的设计围绕两个核心理念展开：

  • 填补学术与实践的鸿沟：将过去数十年学术文献中出现的绩效分析和风险度量方法，以 R 函数的形式实现。

  • 统一的命名与默认值：为常用功能提供封装函数（wrappers），并采用金融文献中通用的命名规范和合理的默认参数。

该包主要针对收益率数据（而非价格数据）进行优化，几乎所有的函数都支持从年度、月度、日度到分钟/秒级的任何周期数据，无论是规则还是不规则的时间序列。

2. 核心功能模块详解

2.1 绩效度量（Performance Metrics）

该包提供了超过50种绩效度量指标，涵盖从基础到前沿的各类评估方法。

类别 核心函数 说明
风险调整收益 SharpeRatio(), SortinoRatio(), CalmarRatio(), BurkeRatio() 夏普比率衡量单位总风险下的超额收益；索提诺比率只考虑下行风险；Calmar比率衡量最大回撤下的收益
超额收益 ActiveReturn(), CAPM.jensenAlpha() 主动收益和Jensen’s Alpha，衡量相对于基准的超额表现
捕获比率 CaptureRatios() 衡量投资组合在市场上涨/下跌时对基准的捕获能力
调整后夏普比率 AdjustedSharpeRatio() 对偏度和峰度进行调整的夏普比率

2.2 风险度量（Risk Metrics）

PerformanceAnalytics 在风险度量方面的最大特色是同时支持正态分布和非正态分布假设下的风险度量。

2.2.1 在险价值

包内提供了多种在险价值（Value at Risk, VaR）与条件在险价值（Conditional VaR, CVaR）估算方法：

# 计算95%置信水平下的VaR
VaR(returns, p = 0.95, method = "modified")   # Cornish-Fisher修正VaR
VaR(returns, p = 0.95, method = "gaussian")   # 正态VaR
VaR(returns, p = 0.95, method = "historical") # 历史模拟VaR


# 计算条件在险价值（Expected Shortfall）
ES(returns, p = 0.95, method = "modified")

其中 method = "modified" 采用 Cornish-Fisher 展开，对收益序列的偏度（skewness）和峰度（kurtosis） 进行调整，适用于金融资产常见的尖峰厚尾（leptokurtic）分布特征。

2.2.2 其他风险度量
函数 度量指标 说明
maxDrawdown() 最大回撤 历史上从峰值到谷底的最大跌幅
AverageDrawdown() 平均回撤 所有回撤事件的平均值
DownsideDeviation() 下行偏差 仅考虑低于目标回报的波动
CDD() / CDaR() 条件回撤风险 类似于CVaR，但针对回撤序列

2.3 可视化分析（Charts）

PerformanceAnalytics 提供了丰富的金融图表函数，是投资组合展示的核心工具。

2.3.1 综合绩效总结图 - charts.PerformanceSummary()

这是该包最常用的综合可视化函数，在一张图中展示三个维度的信息：

library(PerformanceAnalytics)
data(managers)  # 包内置的示例数据集


# 绘制投资组合的绩效总结图
charts.PerformanceSummary(managers[, c("HAM1", "SP500 TR")],
                          main = "策略绩效总结")

该函数生成的三联图包括： - 上图：累积财富指数（Wealth Index），展示净值增长曲线 - 中图：周期收益柱状图（Period Returns），展示各期的收益分布 - 下图：回撤水下图（Underwater Drawdown Chart），展示回撤的深度与持续时间

2.3.2 其他核心图表函数
函数 用途
chart.CumReturns() 累积收益曲线
chart.Drawdown() 回撤曲线
chart.BarVaR() 柱状图叠加VaR风险线
chart.RiskReturnScatter() 风险-收益散点图，用于多策略比较
chart.Boxplot() 收益分布的箱线图
chart.Correlation() 相关性热力图

2.4 表格化汇总（Tabular Data）

该包提供了大量用于生成标准化报告表格的函数：

# 年化绩效汇总表
table.AnnualizedReturns(managers[, 1:8], Rf = 0.04/12)


# 滚动周期统计表

# 自定义指标表

                metricsNames = c("均值", "标准差", "VaR"))

table.Arbitrary() 允许用户传入任意自定义函数列表，生成灵活的统计汇总表。

2.5 滚动窗口分析（Rolling Analysis）

# 滚动计算绩效指标
chart.RollingPerformance(returns, width = 24,
                         main = "24个月滚动收益")

2.6 高阶矩与共同矩（Higher Moments & Co-Moments）

对于非正态分布的分析，该包提供了偏度（skewness）、峰度（kurtosis）以及协偏度（coskewness）、协峰度（cokurtosis）的计算函数。

以下通过一个完整的示例，展示 PerformanceAnalytics 从数据准备到综合报告的全流程：

四、RQuantLib包

1.概述

RQuantLib是R语言与QuantLib之间的桥梁，由Dirk Eddelbuettel于2002年发起开发，旨在将QuantLib的C++高性能计算能力与R的交互式数据分析环境相结合。QuantLib是全球领先的开源量化金融C++库，涵盖金融工程的大部分核心模块，包括各类金融工具的定价引擎、收益率曲线建模、蒙特卡洛与有限差分引擎、PDE求解器以及风险管理等。

RQuantLib自2002年诞生以来，经过二十余年的持续发展，已成长为R语言量化金融生态中衍生品定价与固定收益分析的标准工具。它通过将QuantLib的C++高性能计算能力与R的交互式数据分析环境相结合，为R用户提供了：

  • 完整的权益类期权定价：从欧式、美式到障碍、二元等奇异期权
  • 全面的固定收益工具链：从贴现曲线构建到多种债券类型的定价
  • 利率衍生品定价：百慕大互换期权和仿射互换期权
  • 实用的日历与假期工具：支持多市场工作日和假期计算

包保持活跃维护状态，始终适配QuantLib的最新版本，用户可通过CRAN的二进制包或源码方式安装。对于需要处理衍生品估值、收益率曲线构建或固定收益分析的量化从业者和研究人员而言，RQuantLib提供了从R环境直接调用QuantLib专业能力的便捷通道，是R语言金融计算生态中不可或缺的核心组件。

2.核心功能模块

RQuantLib最早于2002年从权益类期权定价起步，目前已涵盖从标准期权到奇异期权的完整定价体系。

2.2 固定收益与收益率曲线

RQuantLib于2005年首次引入固定收益市场支持，经过多年发展，已形成完整的固定收益分析工具链。

2.2.1 贴现曲线构建：DiscountCurve

DiscountCurve()函数根据市场输入数据构建即期利率期限结构。输入数据包括：

输入类型 识别名称 说明
平坦曲线 flat 单一利率（必须为首项）
存款利率 d1w, d1m, d3m, d6m, d9m, d1y 1周至1年期存款
互换利率 s2y ~ s100y 2年至100年互换利率
期货合约 fut1 ~ fut8 前8个IMM日期的3个月期货
FRA合约 fra3x6, fra6x9, fra6x12 3x6、6x9、6x12 FRA

插值方法支持线性（linear）、对数线性（loglinear）和样条（spline）三种。

# 构建贴现曲线
params <- list(
  tradeDate = as.Date("2024-01-15"),
  settleDate = as.Date("2024-01-18"),
  interpWhat = "discount",
  interpHow = "loglinear"
)


tsQuotes <- list(
  d1m = 0.035,   # 1个月存款利率3.5%
  d3m = 0.038,   # 3个月存款利率3.8%
  d6m = 0.040,   # 6个月存款利率4.0%
  s2y = 0.042,   # 2年互换利率4.2%
  s5y = 0.045,   # 5年互换利率4.5%
  s10y = 0.048   # 10年互换利率4.8%
)


times <- seq(0.5, 10, by = 0.5)
discount_curve <- DiscountCurve(params, tsQuotes, times)
2.2.2 拟合债券曲线：FittedBondCurve

2009年，RQuantLib通过FittedBondCurve()函数扩展了收益率曲线拟合能力，支持三种拟合方法：

  • ExponentialSplines：指数样条拟合

  • SimplePolynomial：简单多项式拟合

  • NelsonSiegel：Nelson-Siegel模型拟合

该函数返回包含日期、零息利率和贴现因子的数据框，可直接转换为zoo对象用于时间序列分析。

2.2.3 债券定价

RQuantLib支持多种债券类型的定价：

# 固定利率债券
FixedRateBond(
  bond = list(settlementDays = 3, maturityDate = "2034-01-15"),
  coupon.rate = 0.05,
  schedule = list(period = "Annual", calendar = "UnitedStates/GovernmentBond"),
  calc = list(dayCounter = "Actual360"),
  discountCurve = discount_curve

# 零息债券
ZeroCouponBond(params, discountCurve)


# 浮动利率债券
FloatingRateBond(bond, schedule, discountCurve)

支持的债券类型包括：零息债券（Zero Coupon）、固定利率债券（Fixed Coupon）、浮动利率债券（Floating Rate）、可赎回债券（Callable）、可转换零息债券（Convertible Zero）、可转换固定利率债券（Convertible Fixed Coupon）、可转换浮动利率债券（Convertible Floating Coupon）等。

定价函数返回净现值（NPV）、净价（Clean Price）、全价（Dirty Price）、应计利息、到期收益率及现金流明细等信息。

五、pracma包

1. 概述

pracma（Practical Numerical Math Functions）是R语言中一个功能全面的数值计算扩展包。它提供了大量数值分析、线性代数、数值优化、微分方程、时间序列分析以及特殊数学函数的R语言实现。

该包的设计理念之一是将函数命名为与MATLAB/Octave相对应的名称，以方便用户从MATLAB迁移到R。截至目前，pracma包含了超过220个与MATLAB同名的函数仿真实现。

包的主要目标包括：

  • 为“数值分析”或“科学计算”课程提供R演示脚本

  • 使用MATLAB函数命名以简化从MATLAB/Octave向R的移植

六、stats 包的插值函数

对于一些简单的插值任务，通常使用R的基础包 stats 中的四个函数：

  • approx() / approxfun()：进行线性或常数插值。

  • spline() / splinefun()：进行三次样条插值。

它们是R语言最轻量、最基础的插值工具，无需安装任何包即可使用。在金融工程中，它们通常用于快速原型验证、简单数据填补或预处理，但在生产级曲线构建中，它们缺少对负利率、对数空间插值或远期利率的专项支持。下面为你详细拆解这四大函数。

1. 核心差异

这两对函数的核心逻辑完全相同，唯一的区别在于返回值：

函数 返回值 适用场景
approx() / spline() 直接返回一个列表，包含插值后的 x 和 y 数值向量。 一次性使用：只需要拿到具体的插值数值，画个图或填个表。
approxfun() / splinefun() 返回一个R函数对象（闭包），可以反复调用计算任意点的值。 重复调用：需要多次查询不同期限的利率，或作为其他优化函数的输入。

2. approx() 与 approxfun()

这是最基础、速度最快的插值方法，默认在数据点之间用直线连接，即线性（或常数）插值。

核心参数解析：

  • x, y：已知的数据点（期限和利率）。
  • xout：需要插值的目标点（仅在 approx 中有效）。
  • method：
    • "linear"（默认）：线性插值。
    • "constant"：常数插值（阶梯状），通常取左端点值。
  • rule（极其重要）：控制边界外（外推）的行为。
    • rule = 1（默认）：超出范围返回 NA。
    • rule = 2：超出范围时，使用最外侧端点的值进行常数外推（平推）。
  • ties：处理重复 x 值的策略。在金融中，若同一期限有多个报价，常用 ties = "mean"（取均值）或 "ordered"（按顺序取）。

代码示例：

# 模拟期限（年）与即期利率（%）
terms <- c(0.5, 1, 2, 3, 5)
rates <- c(2.1, 2.3, 2.8, 3.2, 3.5)


# 1. 一次性插值：获取1.5年和2.5年的利率
approx(x = terms, y = rates, xout = c(1.5, 2.5))
# 结果会在1.5年处输出 2.55，2.5年处输出 3.0


# 2. 构建插值函数（金融中最常用）
rate_fun <- approxfun(x = terms, y = rates, rule = 2)


# 之后可以像函数一样反复调用
rate_fun(c(0.8, 4.2, 10)) # 注意：10年超出了范围，由于 rule=2，会取末端值 3.5

3. spline() 与 splinefun()

三次样条插值，保证曲线在数据点处一阶、二阶导数连续，曲线更光滑，在金融中用于生成平滑的收益率曲线。

核心参数解析（关键区别在于 method）：

  • method = "fmm"（默认）：Forsythe-Malkin-Moler 样条。曲线最光滑，但在数据点之间可能会产生过冲（震荡），导致负利率或明显的波浪。
  • method = "natural"：自然样条。边界二阶导数为0，端点处曲率最小，曲线在两端更平缓。
  • method = "periodic"：周期样条。适用于季节性数据，金融中不常用。
  • method = "monoH.FC"（金融重点）：单调三次Hermite样条。它能保证插值曲线在数据点之间严格单调，不会产生无效的震荡。在构建远期利率曲线时，为了防止负远期利率，常首选此方法。

代码示例：

terms <- c(1, 2, 3, 4, 5)
rates <- c(1.5, 1.2, 1.8, 2.0, 2.1) # 利率先降后升


# 构建默认样条（可能产生轻微过冲）
spline_fmm <- splinefun(terms, rates, method = "fmm")


# 构建单调样条（保证平滑且不产生额外波浪）
spline_mono <- splinefun(terms, rates, method = "monoH.FC")


# 查询 2.5 年处的利率
spline_fmm(2.5)
spline_mono(2.5)


# 建议绘图对比，你会看到 fmm 在 1-2 年之间可能出现低于 1.2% 的凹陷，而 mono 则平缓过渡。

4. 注意

在使用这四个基础函数时，有几个固收领域特有的陷阱需要特别留意：

  • 外推（Extrapolation）的脆弱性：
    • 虽然 rule = 2 可以进行平推，但在长端（如30年）曲线构建中，简单平推会导致定价偏差巨大。生产环境中通常需要结合 Smith-Wilson 或 Nelson-Siegel 等参数化模型进行外推。
  • 插值标的物的选择：
    • 你是对即期利率（Spot Rate）、远期利率（Forward Rate），还是贴现因子（Discount Factor） 进行插值？
    • 基础函数默认对 y 进行数学插值。如果直接对贴现因子做线性插值，隐含着远期利率为分段常数；如果直接对利率做样条插值，远期曲线可能会剧烈震荡。业内更稳健的做法是对贴现因子取对数后再进行样条插值（spline(log(df) ~ terms)），但 stats 包需要手动操作。
  • 单调性保持：
    • 在构建远期利率曲线时，为防止套利，曲线通常被要求为正且单调。强烈建议在 splinefun 中设置 method = "monoH.FC"，这在基础包中就能提供很好的保障，而无需依赖外部包。

七、akima 包

akima 包是 R 语言中实现 Akima 插值法的权威工具，尤其擅长处理二维不规则散点数据的网格化插值。akima 包的核心，是实现了由 Hiroshi Akima 本人开发的一系列插值算法。它覆盖了从一维到二维、从不规则数据到规则网格数据的多种插值场景。

功能维度 具体描述
核心算法 实现 Akima 的一维 (ACM 433, 697) 和二维 (ACM 760, 761) 插值方法。
主要应用 将不规则分布的散点数据插值到规则的网格上，生成用于可视化的平滑曲面。
插值类型 支持线性 (linear=TRUE) 和样条 (linear=FALSE) 两种插值方式。
辅助功能 提供针对规则网格数据的双三次 (bicubic) 和双线性 (bilinear) 插值。

1. 核心函数

包中的几个核心函数各有侧重，以下是它们的详细说明：

1.1. interp(): 二维散点数据网格插值（主力函数）

这是包中使用最频繁的函数，用于将散落的二维点(x, y, z)插值到一个规则的网格上。

  • 基本用法: interp(x, y, z, xo, yo, linear, ...)
  • 重要参数:
    • x, y, z: 输入数据的坐标和数值向量，长度必须相同，且至少需要4个点。
    • xo, yo: 定义输出网格的 x 和 y 坐标向量。默认会在数据范围内生成40x40的网格。
    • linear: 逻辑值。TRUE (默认) 为线性插值，FALSE 则为平滑的样条插值。
    • extrap: 逻辑值，是否允许在数据点的凸包外进行外推。默认为 FALSE。
    • duplicate: 处理重复数据点的方式，可选 “error”（报错）、“strip”（移除）、“mean”（取均值）等。
  • 返回值: 一个包含 x, y, z 三个分量的列表，z 是一个矩阵，代表了网格上的插值结果。

1.2. interpp(): 二维散点数据的点插值

与interp()不同，interpp() 不是生成整个网格，而是直接计算指定的一系列点上的插值结果。

  • 基本用法: interpp(x, y, z, xo, yo, ...)
  • 适用场景: 当你只需要少数几个特定位置的插值，而非整个曲面时，此函数更高效。

1.3. aspline(): 一维 Akima 插值

该函数实现了一维的 Akima 插值。

  • 基本用法: aspline(x, y, xout, ...)
  • 特点: 计算效率高，无需解大型方程组。其功能与 pracma 包中的 akimaInterp() 类似。

2. 应用示例

下面通过一个完整的例子，展示如何使用 akima 包处理内置数据集并进行可视化。

library(akima)


# 2. 加载内置示例数据

head(akima)

# linear = FALSE 表示使用平滑的样条插值

# 4. 可视化插值结果

3. 注意事项

  • 许可证限制：akima 包的核心 Fortran 代码来自 ACM（Association for Computing Machinery），其许可证对商业用途可能有限制。
  • 现代替代方案 interp：CRAN 上的 interp 包是在自由许可证下完全重写的版本，功能与 akima 高度重叠，是更现代的替代选择。
  • 一维插值替代：R 基础包中的 spline() 函数或 pracma 包中的 akimaInterp() 函数，也可用于一维插值。

八、interp 包

interp 包可以被看作是 akima 包的自由、开源替代品。它旨在解决 akima 包因许可证限制而带来的问题，为 R 用户提供了一个功能几乎一致但许可证更宽松的选择。

interp 包的使用方式与 akima 包非常相似，可以轻松过渡。interp 包提供了与 akima 几乎完全相同的功能，同时采用更自由的 GPL 许可证，是更安全、更现代的选择。它提供与 akima 包高度向后兼容的二维插值函数，同时规避了后者的许可证风险。它的主要功能是对不规则分布的二维散点数据 (x, y, z) 进行插值，生成规则网格上的数据或计算指定点的值。

1. 网格插值

这是最核心的函数，用于将不规则散点数据插值到一个规则的矩形网格上。

  • 基本用法： r interp(x, y, z, xo, yo, method = "linear", ...)
  • 关键参数：
    • x, y, z: 输入数据的坐标和数值向量。
    • xo, yo: 定义输出网格的 x 和 y 坐标向量，默认会在数据范围内生成 40x40 的网格。
    • method: 这是最重要的新参数，用于指定插值方法。
      • "linear": 默认方法，进行分段线性插值，与 akima::interp(..., linear=TRUE) 等效。
      • "akima": 进行 Akima 样条插值，生成更平滑的曲面，与 akima::interp(..., linear=FALSE) 等效。
    • linear: 这是一个已弃用的参数，仅用于向后兼容。官方推荐使用新的 method 参数。

2. 点插值

interp 包将 akima 包中 interpp() 函数的功能整合进了 interp() 函数本身。

  • 基本用法：通过设置 output="points" 来实现。 r interp(x, y, z, xo, yo, output = "points", ...)
  • 注意：当 output="points" 时，xo 和 yo 需要是相同长度的向量，指定你想要计算插值结果的那些点。
  • 兼容性：为方便旧代码，包仍保留了 interpp() 函数，但官方推荐使用新的 interp() 函数。

3. 应用示例

下面通过一个完整的例子，对比 interp 包中两种核心方法的效果。

# 3. 执行样条插值，生成一个更精细的 100x100 网格
# 使用 method="akima" 获得平滑曲面

# 4. 可视化插值结果
# 使用 image() 绘制热力图，contour() 叠加等高线
