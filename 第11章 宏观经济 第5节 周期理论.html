第11章 宏观经济 第5节 周期理论

引言

投资本质上是关于未来现金流的概率判断，而周期则是这种概率判断的时间骨架。无论是宏观经济增长、企业盈利、信贷条件，还是市场情绪与估值水平，都不是沿直线运动，而是在扩张与收缩、乐观与悲观、风险积累与风险释放之间往复摆动。

1936年凯恩斯在《就业、利息和货币通论》中已经指出，经济发展呈现明显的规则性周期，并把一个完整周期划分为繁荣、恐慌、萧条、复苏四阶段。

霍华德·马克斯则在《投资最重要的事》和《周期》中进一步把周期从宏观延伸到企业盈利、信贷、债务和市场心理，强调“我们无法预测，但可以准备”。

本节，我们将系统梳理周期理论的层级结构、驱动机制、建模方法和投资应用，并特别关注现代高频数据、机器学习、小波分析、情绪量化与动态风控对传统周期框架的修正与挑战。

需要事先说明的是，周期理论不是精确的计算科学，而是对复杂经济系统规律性的近似描述。它最大的价值不在于预测某一年的具体拐点，而在于帮助投资者理解“我们现在大致处于什么位置”，“哪些力量在主导”，“哪些风险正在积累”。

一、宏观周期

周期研究的基本问题是：经济活动是否围绕某一长期趋势存在重复但非严格规则的波动？如果是，这些波动的长度、振幅、相位和驱动机制是什么？

在量化投资中，周期思想之所以重要，是因为它提供了一种将“时间”纳入资产配置的框架：不同资产、行业和因子在不同周期阶段可能表现出不同风险收益特征。

从时间跨度的层次上看，宏观周期最常见的划分包括：基钦周期（库存周期，约3-5年）、朱格拉周期（设备投资周期，约7-11年）、库兹涅茨周期（建筑与人口周期，约15-25年）、康德拉季耶夫周期（技术&制度周期，约40-60年）。

然而，周期研究存在一个核心难题：周期长度并非物理常数，而是历史统计上的平均区间；相位也不固定，可能因政策、战争、技术扩散和全球化而漂移。因此，周期理论更适合作为“情景框架”和“风险提示”，而不是精确的日历预测工具。

1. 康德拉季耶夫周期：技术革命与制度变迁

康德拉季耶夫周期（Kondratiev Wave），又称康波周期或长波周期，是宏观周期中时间尺度最长的一类。前苏联学者康德拉季耶夫对英、法、美等资本主义国家18世纪末到20世纪初100多年数据进行分析，发现经济中存在长度约40至60年的长期波动。

其核心驱动因素包括：根本性技术革命及其扩散、大规模资本积累与耗竭、社会制度的变迁、战争与和平。这些因素并非孤立作用，而是相互强化：技术革命带来新的主导产业，主导产业吸引大规模资本投入，资本积累推动繁荣，但也会导致产能过剩、金融泡沫和制度僵化，最终通过危机、战争或制度重构完成出清，为下一轮技术扩散腾出空间。

从历史看，自工业革命以来，全球经济已经历了五个完整的康波周期。

  • 第一次康波周期（1782-1845年）以蒸汽机和纺织机为标志，英国率先完成工业革命，工厂制度、铁路雏形和自由贸易制度逐步确立。

  • 第二次康波周期（1845-1892年）是煤钢时代，钢铁、电力、机器制造和蒸汽机驱动的铁路成为主导，重工业资本密集度大幅上升，股份公司和金融市场加速发展。

  • 第三次康波周期（1892-1948年）是电气时代，电力和内燃机普遍应用，汽车、化工、无线电等产业崛起，两次世界大战和1929年大萧条构成了剧烈的出清与制度重建。

  • 第四次康波周期（1948-1991年）是汽车、通信和传媒时代，战后重建、石油化工、消费社会、计算机雏形和全球化贸易体系共同推动长期繁荣，并在1970年代滞胀和1980年代债务危机中经历调整。

  • 第五次康波周期（1991年至今）是信息技术时代，互联网、移动通信、半导体、软件和平台经济深刻改变了生产与生活方式，2008年全球金融危机和2020年疫情冲击则暴露了金融化、债务化和供应链脆弱性问题。

第六次康波周期可能正在发生，其候选主导技术包括人工智能、生物技术、新能源、量子计算和先进制造。与以往不同的是，本轮技术扩散发生在全球产业链重构、地缘政治竞争加剧、人口老龄化、气候变化和债务高企的背景之下，因此其路径可能更加复杂。

康波周期的投资含义非常深刻。在长波繁荣期，风险资产、成长股、信用扩张和全球化交易往往表现优异；在长波衰退与萧条期，安全资产、黄金、现金、防御性行业和逆周期政策受益。

但康波最大的问题是时间尺度太长，人的投资生涯往往只有三四十年，无法等待完整周期验证。因此，康波更适合作为战略背景，而不是短期择时工具。它告诉我们：当前的主导技术、制度安排和债务结构，决定了哪些资产具有长期贝塔，哪些风险正在被低估。

2. 库兹涅茨周期：房地产、人口与城市化

库兹涅茨周期（Kuznets Cycle），也被称为”建筑周期”或”基础设施周期”，由美国经济学家、1971年诺贝尔经济学奖得主西蒙·库兹涅茨提出。他通过对19世纪到第二次世界大战前美国经济发展的研究，发现许多生产部门尤其是基础工业部门的经济增长率，约15到22年呈现有规则的波动。

库兹涅茨周期长度通常为15至25年，核心驱动因素包括人口结构变化（移民潮、婴儿潮）、城市化进程、建筑寿命与更新需求、长期信贷条件（抵押贷款利率）、家庭形成速度、劳动力增长、家庭数量变化以及迁移模式对住房和基础设施的需求。

人口结构变化尤其关键：移民潮和婴儿潮会创造长期住房需求，而老龄化、少子化和逆城市化则可能削弱需求。长期信贷条件也至关重要：抵押贷款利率的微小变化会通过杠杆放大购房能力，进而影响周期斜率。当前中国和许多发达经济体都面临人口老龄化与房地产调整，库兹涅茨周期的下行压力可能持续较长时间，这对利率、财政政策和资产配置都有深远影响。

房地产周期是库兹涅茨周期最典型的表现。人口流入城市、家庭形成加速、信贷利率下降时，住房和基础设施需求上升，建筑投资扩张，带动钢铁、水泥、家电、金融等产业链繁荣。当人口增长放缓、城市化接近尾声、利率上升或信贷收紧时，住房供给过剩，价格下跌，建筑投资萎缩，银行坏账上升，进而拖累整体经济。

库兹涅茨周期之所以重要，是因为房地产既是实体经济的支柱，又是金融体系的抵押品基础。2008年美国次贷危机、1990年代日本房地产泡沫、中国过去二十年的房地产周期，都带有库兹涅茨周期的深刻烙印。在投资中，库兹涅茨周期影响大类资产配置。房地产上行期，银行、地产、建材、家电、消费信贷等板块受益；下行期，避险资产、高股息、公用事业和现金流稳定的企业更具防御性。

在当代数字化与绿色转型背景下，库兹涅茨周期的驱动逻辑正在发生深刻变化。传统库兹涅茨周期以物理基础设施（公路、铁路、住宅、工厂）为核心，而当代基础设施的内涵已大幅扩展至数字基础设施（数据中心、5G基站、光纤网络）和绿色基础设施（光伏电站、风电场、充电网络、电网升级）。

这意味着库兹涅茨周期的长度和形态可能发生变化。一方面，数字基础设施的建设周期短于传统物理基础设施，可能导致周期缩短；另一方面，绿色能源基础设施的资本密集度和政策依赖度极高，可能拉长投资周期并增强政策周期性。数字化与绿色化的融合，正在创造新的基础设施投资浪潮，形成库兹涅茨周期与康波周期的共振。

3. 朱格拉周期：设备投资与产能周期

朱格拉周期（Juglar Cycle）由法国医生兼经济学家克莱门特·朱格拉于1862年提出。他研究法、英、美等国的银行数据、利率和价格水平，发现经济中存在约7至10年的周期性波动。

朱格拉周期描述了一个由企业设备投资驱动的兴衰过程，核心驱动因素包括企业固定资产（厂房、机器设备、交通工具等）的更新换代与扩张投资、企业利润波动、信贷可获得性与成本（利率）、技术创新（设备层面）。

朱格拉周期是宏观经济周期研究中最为”经典”的中周期，其核心机制是企业设备投资的生命周期。朱格拉周期的逻辑是：经济复苏时，企业利润改善，对未来需求乐观，开始扩大资本支出；设备投资增加带动上游产业，就业和收入上升，进一步刺激需求；但当产能集中投放、需求增速放缓时，供过于求出现，企业利润下滑，投资收缩，经济进入下行期；设备逐渐老化、产能出清后，新一轮更新需求再次启动。

很多研究通过傅里叶变换的方法，从数据中提取出约104个月的周期分量，与朱格拉周期一致。因此，将朱格拉周期典型时长定义为约10年或100个月，并与基钦周期在特定时期可能重叠并产生延迟共振。

朱格拉周期对投资的意义在于，它直接对应企业盈利和产能利用率的变化。在朱格拉上行期，制造业、资本品、原材料、银行等顺周期行业表现较好；在下行期，需求萎缩、价格下跌、信用风险上升，防御性行业和债券更优。由于朱格拉周期长度适中，许多宏观择时模型会将其作为核心周期之一，结合基钦周期判断短期拐点。后文我们将详细介绍其方法。

在数字经济时代，朱格拉周期的传统物质基础正在被削弱。软件、算法、数据等无形资产的更新周期远短于物理设备，且边际更新成本极低。这可能导致两个后果：第一，数字经济投资的波动性低于重资产行业，传统以设备投资为核心的朱格拉周期可能被”平滑化”；第二，以技术平台迭代、芯片制程升级、算力扩张为核心的”数字朱格拉周期”形态可能出现。

然而，朱格拉周期的核心逻辑（产能扩张与收缩的交替）在数字经济中依然存在。数据中心的建设、算力集群的部署、半导体晶圆厂的投产，都具有典型的资本密集型特征，其投资周期可能形成新的中周期波动。此外，传统制造业的自动化改造、绿色转型中的设备更新，如新能源汽车产线、光伏组件产线等，仍在创造显著的设备投资周期。

4. 基钦周期：库存波动

基钦周期由英国经济学家约瑟夫·基钦于1923年提出，也被称为“库存周期”或“短波理论”，周期长度约为3至5年（约40个月），核心驱动力是企业库存水平的周期性波动。基钦周期通常分为四个阶段：被动去库存、主动补库存、被动补库存、主动去库存。

  • 被动去库存发生在经济复苏初期，需求开始回暖，企业销售加快，但生产尚未完全调整，库存意外减少。

  • 主动补库存阶段，企业预期需求持续向好，主动增加生产并补充库存，生产加速，经济加速增长。

  • 被动补库存阶段，需求增长放缓或不及预期，销售下滑，但企业生产尚未调整，库存因销售减慢而被动累积。

  • 主动去库存阶段，企业意识到需求疲软、库存过高，大幅削减生产计划，暂停采购、降价促销以清理库存，生产收缩带来经济增速放缓或衰退。

很多有研究通过傅里叶变换提取出约42个月的周期分量，与基钦周期一致。因此，将基钦周期典型时长定义为约40至43个月或4年，并与朱格拉周期可能重叠共振。

在投资中，基钦周期对短期择时、行业轮动和商品价格影响显著。被动去库存和主动补库存阶段，股票和商品往往表现较好；被动补库存和主动去库存阶段，债券和防御性资产更优。

实践中，库存周期还可以与情绪指标结合使用，效果更好：当库存处于低位且需求改善时，市场情绪更容易从恐惧转向贪婪；当库存高企且需求恶化时，情绪更容易从乐观转向悲观。

5. 周期嵌套与共振

四大经济周期之间存在明确的嵌套关系，形成一个复杂的多层周期结构：一个康波周期（50-60年）包含约3个库兹涅茨周期（15-25年）；一个库兹涅茨周期包含约2个朱格拉周期（7-10年）；一个朱格拉周期包含约3个基钦周期（3-5年）。

这种嵌套关系意味着较长周期的阶段变化会影响其中嵌套的较短周期的表现。例如，当康波周期处于萧条期时，即使较短周期可能处于上升阶段，其上升幅度也会受到限制；反之，当康波处于繁荣期时，较短周期的下行可能被缓冲。

而当多个不同长度的经济周期同时处于同一阶段时，则由于周期共振，其对经济的影响产生放大效应。例如，很多研究通过历史数据发现，基钦周期与朱格拉周期在特定时间段可能重叠并产生延迟共振。

周期嵌套对投资的启示在于：不能只看单一周期。投资者需要建立“周期仪表盘”，同时跟踪康波、库兹涅茨、朱格拉和基钦的位置。例如，如果康波处于衰退、库兹涅茨处于下行、朱格拉处于去产能、基钦处于主动去库存，那么风险资产面临多重共振下行，应大幅降低仓位；如果康波萧条但朱格拉和基钦同时触底回升，则可能出现结构性反弹，但仍需警惕长波压制。周期共振是放大收益和风险的来源，也是宏观择时模型的核心逻辑之一。

二、投资周期

1. 凯恩斯四阶段与霍华德·马克斯周期框架

凯恩斯把完整经济周期分为繁荣、恐慌、萧条、复苏四个阶段。这个四阶段框架简洁，抓住了周期运行的心理与金融特征。

  • 繁荣期，投资和消费旺盛，价格和利润上升，乐观情绪蔓延；

  • 恐慌期，市场对未来的信心突然逆转，资产价格暴跌，流动性紧张；

  • 萧条期，需求萎缩，企业破产，失业上升，悲观情绪达到极点；

  • 复苏期，价格和需求触底，企业开始重建库存和投资，信贷逐步恢复。

霍华德·马克斯基于橡树资本管理经验，在《投资最重要的事》和《周期》中把周期细分为多个层次：经济周期、企业盈利周期、政府调节逆周期、信贷周期、债务周期和市场周期。

  • 经济周期决定企业盈利的大环境；

  • 企业盈利周期因经营杠杆和财务杠杆而放大经济波动；

  • 政府调节逆周期通过货币政策和财政政策熨平波动，但也可能制造新的扭曲；

  • 信贷周期决定资金的可获得性和成本，是市场周期最直接的驱动之一；

  • 债务周期反映经济体加杠杆和去杠杆的长期过程；

  • 市场周期则综合了基本面、心理和估值，表现为股票、债券、房地产和商品价格的波动。

马克斯特别强调，在投资领域，心理或情绪扮演着非常突出的角色。证券市场中的情绪波动就像一个摆钟一样运动，围绕中心点来回摆动，但很少停在中心点，大部分时间都在走极端。股票市场处在常态水平的时间可能不到10%，即收益率大约等于历史平均收益率。所以股票市场的常态其实是非常态。

偏离常态主要是投资人的心理和情绪像摆钟一样大幅摆动，根本原因是投资人的心理和情绪在恐惧和贪婪之间来回摆动。想获得高于平均值的贪婪心理导致他们高位追涨，恐惧导致他们杀跌。

人有各种不同的情绪摆钟：贪婪到恐惧、乐观到悲观、风险忽视到风险规避、信任到怀疑、相信价值到怀疑价值、急于购买到恐慌卖出。贪婪到恐惧的摆动，其底层是从兴奋到沮丧的摆动，过度兴奋引发贪婪，过度沮丧引发恐惧。兴奋和沮丧两种基本情绪导致市场发生从贪婪到恐惧的摆动。信任和怀疑、乐观主义和悲观主义等情绪都呈现情绪摆钟现象。投资人总是在这些极端点之间摆动，而卓越的投资人能平衡好这种情绪，拒绝参与情绪摆钟，利用市场情绪的极端偏离而获利。

2. 信贷周期

信贷周期是马克斯框架中最重要的周期之一。信贷周期是指银行体系信贷供给的扩张与收缩交替，其核心机制是金融中介的风险偏好变化与监管环境的周期性调整。信贷周期的特殊性在于，它既是经济周期的”放大器”，也是金融危机的”导火索”。

信贷窗口打开时，银行和债券市场愿意放贷，利率低、利差窄、条件宽松，企业容易融资，投资者容易加杠杆，资产价格上升；信贷窗口关闭时，银行收紧信贷，利差扩大，再融资困难，企业被迫去杠杆，资产价格下跌。

信贷周期具有很强自我强化特征：资产价格上升提高抵押品价值，进一步增加信贷供给；资产价格下跌降低抵押品价值，引发追加保证金和抛售，形成恶性循环。

从计量经济的角度看，实务中常用实体部门债务增速或债务宏观杠杆率（如广义社融同比增速）来度量信用周期。这些指标的优势在于数据可得性高、频率适中（月度或季度），且与经济活动高度相关。

我们可以从多个角度刻画信贷周期风险，通常包括流动性、偿债能力和误定价风险。其中，流动性和偿债风险指标呈反周期性，而误定价风险呈顺周期性，且这些指标通常领先于信贷周期。这具有重要的预警含义：当流动性指标开始恶化、偿债风险上升时，信贷周期的下行可能尚未在信贷数据中体现，但风险已在积聚。

此外，我们还可以利用企业信贷利差等金融价格作为信贷周期波动的实时评估，通过模型识别周期阶段和概率，并据此动态对冲风险资产。

3. 债务周期

债务周期与信贷周期密切相关，但视角略有不同。信贷周期关注的是信贷供给的扩张与收缩，债务周期则关注经济体整的体债务水平，及其更长期的趋势变化。债务可以刺激短期增长，但也会积累偿债压力。当债务增速超过收入增速，杠杆率上升，金融脆弱性增加；当去杠杆开始，支出减少，经济放缓，甚至出现债务通缩。

根据瑞·达利欧（Ray Dalio）的框架，债务周期可分为短期债务周期（约5至8年）和长期债务周期（约50至75年），后者与康波周期的时间尺度大致吻合。

长期债务周期的核心机制是债务存量的持续累积最终达到不可持续的水平，触发去杠杆过程。去杠杆的方式包括：债务减记、紧缩、财富转移和债务货币化。不同方式的政治可行性与经济后果差异巨大，决定了去杠杆过程的痛苦程度与持续时间。

在微观层面，企业战略激进与债务违约相关，且信贷周期在其中起调节作用，涉及融资来源和期限结构等变量。这意味着，在信贷扩张期，激进企业的违约风险可能被掩盖；而在信贷收缩期，同样的企业可能迅速陷入困境。这一”信贷周期调节效应”对信用债投资具有直接的组合管理含义。

在宏观层面，债务违约风险的计量通常涉及债务/GDP比率、债务收入比率、利息覆盖率等指标。债务收入比率特别重要，因为它衡量的是收入流中用于偿债的比例，直接反映了债务负担的现金流压力。

货币政策和金融冲击等宏观冲击对尾部风险的影响通常具有不对称性，不利冲击在经济状况不佳时会不成比例地增加金融压力，存在“金融加速器”或非线性放大机制。有研究将一个尾部风险演变划分为四阶段循环模型：均衡、风险积累、风险前移、风险显现，这与债务周期和信贷周期的风险积累过程高度一致。

债务周期与政策转折点的关系极为密切。当债务水平过高时，央行面临两难：加息以控制通胀可能触发债务危机，降息以支持增长可能加剧通胀。这种”债务陷阱”在2022至2023年的全球加息周期中表现得尤为明显，部分新兴市场国家被迫跟随加息以稳定汇率，但国内债务负担随之加重。

主要经济体政策转折点的前瞻预警，需要综合信贷周期指标、债务周期指标与情绪周期指标。单一指标往往发出矛盾信号，需要构建综合指数并进行交叉验证。

4. 估值周期

霍华德·马克斯把市场比作摆钟，永远在贪婪与恐惧、乐观与悲观、高估与低估之间摆动。估值周期就是这种摆动的量化表现。它包含三层含义：

  • 价值中枢相对稳定：一个资产的内在价值（未来现金流折现）在短期内变化不会太剧烈，但价格可以大幅偏离。

  • 偏离会自我强化，也会自我修正：上涨时，乐观情绪、赚钱效应、杠杆资金会推动估值继续扩张；下跌时，悲观情绪、赎回压力、去杠杆会推动估值继续收缩。

  • 极端值往往意味着反转条件在积累：估值极低不等于立刻上涨，但意味着长期赔率改善；估值极高不等于立刻下跌，但意味着长期赔率恶化。

所以，估值周期是判断风险收益比、控制仓位、识别周期位置的工具。通常可以把一轮完整估值周期拆成四个阶段：

  1. 低估期：价值发现前夜

    • 特征：PE/PB 处于历史低位，股债性价比高，破净股增多，成交低迷，情绪极度悲观。
    • 逻辑：价格已经反映了大量坏消息，甚至过度反映。
    • 投资含义：左侧布局区。虽然可能继续下跌，但长期赔率占优。
    • 典型信号：格雷厄姆指数高位、ERP 高位、产业资本增持、回购增加。

  2. 修复期：估值均值回归

    • 特征：经济预期边际改善，流动性宽松，盈利尚未明显回升，但估值开始修复。
    • 逻辑：从“极度悲观”回到“正常悲观”，再到“中性”。
    • 投资含义：戴维斯双击的早期阶段，仓位应逐步提升。
    • 典型信号：股债性价比从高位回落，成交量温和放大，风险溢价收窄。

  3. 扩张期：乐观自我强化

    • 特征：盈利增长与估值扩张同步，市场情绪转向乐观，资金加速流入。
    • 逻辑：赚钱效应吸引更多资金，估值被推升到历史中高位甚至高位。
    • 投资含义：持有为主，但开始警惕。需要跟踪流动性、政策、盈利兑现情况。
    • 典型信号：PE/PB 进入历史 70% 分位以上，ERP 降至低位，融资余额快速上升。

  4. 泡沫期与收缩期：均值回归

    • 特征：估值极端高估，情绪狂热，杠杆高企，随后出现流动性收紧或盈利不及预期。
    • 逻辑：价格远超价值，任何负面冲击都可能触发踩踏。
    • 投资含义：减仓、对冲、防守。右侧确认后应果断降低风险暴露。
    • 典型信号：估值创历史极值，股债性价比极低，IPO/再融资激增，散户加速入场。

估值周期本质上是价格围绕价值摆动的过程，由基本面、流动性、情绪与资金行为共同驱动，经历低估、修复、扩张、泡沫与收缩的循环。它并非预测短期涨跌的工具，而是判断风险收益比和周期位置的锚。估值低不等于马上涨，估值高也不等于马上跌，极端值更多意味着长期赔率的变化，而非精确的择时信号。

实践中，估值周期通过 PE、PB、股债性价比（Equity Risk Premium）等指标衡量，并与流动性、情绪、动量合成择时与仓位信号。低估区适合左侧分批布局，中位区持有并优化结构，高位区减仓防守，极端区则警惕均值回归。不同资产和市场的估值周期并不同步。估值中枢会随利率和产业变迁动态调整。

估值周期最大的价值，是帮助投资者在极端低估时敢于承担风险，在极端高估时避免过度暴露，在周期中部保持纪律。它不告诉你何时见顶见底，但告诉你当前处于摆钟的哪个位置，从而在别人恐惧时贪婪、在别人贪婪时恐惧，实现逆向布局与风险管理。

5. 情绪周期

霍华德·马克斯对“情绪周期”的思考，在《投资最重要的事》和《周期》中反复提及和深化。马克斯将证券市场情绪比作钟摆运动：弧线中点是“平均”位置，但钟摆“几乎始终在朝着或者背离弧线的端点摆动”。投资者“花在端点上的时间似乎远比花在中点上的时间多”。这种摆动发生在兴奋与沮丧、庆祝积极发展与困扰于消极发展、定价过高与定价过低之间。马克斯将其称为“投资世界最可靠的特征之一”。钟摆隐喻的关键推论是：朝向端点运动本身为回摆提供了动力。极端本身就是反转的条件。

马克斯强调情绪周期研究中最关键的认知：基本面本身的变化幅度有限，是心理放大了波动。在现实世界中，“事情一般都在‘相当好’和‘不那么好’之间波动。但在投资世界，感知却常常在‘完美无缺’和‘无可救药’之间摆动”。

于是，马克斯将投资者对于风险的态度的周期性变化置于分析中心。金融理论普遍假设投资者永远风险规避。但马克斯指出：这一态度“波动性非常大”。在贪婪盛行时，投资者安于风险；当恐惧弥漫，投资者厌恶风险。当投资者过度容忍风险时，证券价格体现的是更高的风险而非收益；当投资者过度规避风险时，价格体现出来的收益高于风险。这就是马克斯为什么将不恰当的对待风险的态度，视为市场出现过度泡沫或严重崩溃的主要原因。

马克斯借鉴一位资深投资者的框架，用以刻画情绪在周期中的具体演进路径：

  • 牛市三阶段：少数有远见者相信基本面将好转 → 大多数投资者认识到改善确实在发生 → 人人都认为情况会永远更好。

  • 熊市三阶段：少数人意识到好日子不会持续 → 大多数人认识到市场正在恶化 → 人人都相信情况只会越来越糟。

这一框架的实践价值不在于预测，而在于定位，帮助判断当前情绪走到了哪一步。马克斯特别强调第三阶段的危险性：“当投资者相信情况只会越来越好的时候，就进入了最危险的阶段。”

马克斯将情绪周期的实践归结为一个无法回避的判断：当下应该更多地承受“买入而出错”的风险，还是“不买而错过”的风险？ 这两个风险无法同时消除。

  • 当情绪冰点与估值低位共振时，错过风险占主导，应倾向进攻；

  • 当情绪沸点与估值高位共振时，买入出错风险占主导，应倾向防守。

但马克斯也反复提醒，钟摆“究竟能摆多远、会在极端位置停留多久、什么因素会导致反转”，都是无法预知的。情绪周期的价值不在于告诉你何时反转，而在于告诉你现在站在钟摆的哪个位置，从而决定风险暴露的倾向。

他的总结简洁而有力：我们永远不知道钟摆会摆得多远，什么因素会使摆动停止，然后往另一个方向摆回去。但是我们知道当它摆向某个极端时，不会永远待在某个极端。

已经有大量研究尝试把“感知钟摆位置”的工作进行量化，将恐慌/贪婪指标作为映射钟摆极端位置的代理变量，例如：CNN 恐慌贪心指标（CNN Fear and Greed Index）。这是一个衡量投资市场情绪的指标，由CNN Business创建。 该指数基于七个不同的指标，包括股市波动、市场动量、投资者情绪、股票新高新低比率等，通过这些指标的综合分析来衡量市场的恐惧和贪婪程度。 指数的取值范围是0到100，其中低于25表示市场极度恐慌，而高于75表示市场极度贪婪。

6.市场周期

市场周期是霍华德·马克斯周期框架中最核心的概念，也是《周期》一书讨论的落脚点。他将市场周期定义为所有其他周期在股市层面的综合映射——经济周期、信贷周期、情绪周期、风险态度周期等相互作用，最终通过市场参与者的买卖行为凝结为价格的波动。

马克斯描述了一个典型的市场周期路径：

  • 上行阶段：经济基本面改善，盈利增长并超出预期，乐观情绪渗入市场。媒体报道全是好消息，进一步强化乐观。预期上升，心理走强，人们只看到有利发展，资本变得唾手可得，资产价格上涨，投资者开始拥抱更多风险。价格和风险双双触及高点。然而此时人们高度亢奋，倾向于将谨慎抛诸脑后。这就是为什么当价格开始下跌时，大多数投资者措手不及。

  • 下行阶段：基本面开始恶化，盈利下降且不及预期。媒体只报道坏消息，进一步强化悲观情绪。预期下降，心理走弱，资产价格下跌，投资者变得更加风险厌恶。价格最终触底，此时风险很低。这正是应该变得激进的时候。随着投资者在底部开始买入，周期再次转向，如此往复。

马克斯指出，投资人主要做三件事：评估资产价格、评估估值水平、做出决策。而资产价格受两个层面影响：基本面（企业收益和现金流，以及对其未来的预期）和心理面（投资人对基本面因素的感觉）。关键认知在于：如果仅依据基本面计算，资产价格不会波动太大。正是心理面导致价格波动幅度远远大于收益波动。投资人存在三种心理倾向，“以歪曲的眼光看待当前事实、有选择性地感知、带有偏见地解读”这些倾向在周期极端处集中爆发，使市场从“相当好与不那么好之间波动”放大为“完美无缺与无可救药之间摆动”。

马克斯对市场周期的观察可以归纳为三条规律：

  • 第一，少走中间，多走两边。 钟摆也许会摆动到中心点，但停留时间极其短暂。以美股百年经验为例，“偏离水平”的年份占比远远超过“正常水平”的年份。股票市场表现符合正常水平绝不是正常现象，常态是非常态。

  • 第二，不会相同，只会相似。 周期都会有涨有跌，但幅度、时点、速度不会相同，因为世界存在随机性。识别周期的关键是了解模式，而非细节，重点是知道处在什么位置。

  • 第三，历史不会重演细节，但会重复相似的过程。 在投资周期中，涨跌方式会重复历史相似模式，但涨跌幅度不会重复。

霍华德·马克斯在《投资最重要的事》中提出的“市场评估指南”，其正式名称其实带有自嘲意味，叫作 “穷人市场评估指南”（Poor Man’s Guide to Market Assessment） 。马克斯设计这份指南的目的，并非为了精准预测市场，而是提供一种直觉性的“温度计”，用来感知当前市场在周期钟摆中大概处于什么位置。

三、周期分析和建模方法

宏观与投资周期往往呈现出非平稳性、非线性、多频率叠加以及信噪比极低的特征。传统的线性回归和时间序列模型（如ARIMA）难以有效刻画周期的动态演变。因此，我们需要引入信号处理、状态空间模型以及机器学习等方法，将抽象的“周期理论”转化为可计算、可回测的因子与信号。

1. 频域分析与信号处理

1.1.傅里叶变换（Fourier Transform, FFT）

傅里叶变换是周期分析的基石，其核心逻辑是将时域信号\(x(t)\)分解为不同频率的正弦波叠加：

\(X(f) = \int_{-\infty}^{\infty} x(t) e^{-i 2\pi f t} dt\)

在实际计算中，由于数据为离散采样，我们使用离散傅里叶变换（DFT）及其快速算法FFT。功率谱密度（PSD）定义为：\(P(f) = |X(f)|^2\)，用于衡量各频率成分的能量强度。在实践中，我们通常对宏观指标或资产价格的同比序列进行FFT，通过PSD峰值识别主导周期。

后文中，我们将详细介绍，华泰金工利用傅里叶变换对股票市场数据进行谱分析，发现主要股票市场数据都存在42个月和100个月附近的周期，宏观数据和商品数据还会存在200个月附近的周期。42个月周期与宏观经济学中的基钦周期（库存周期）一致，100个月周期对应朱格拉周期（产能周期），200个月周期则与库兹涅茨周期（房地产周期）对应。从回归拟合效果来看，将42个月、100个月、200个月三个周期上提取的高斯滤波作为自变量，对原始同比序列进行回归，上证综指的拟合优度达到0.7311，标普500的拟合优度为0.7750，部分数据甚至可以达到0.8以上。

此外，也有券商研究采用“HP滤波+傅里叶变换”的方法，先使用HP滤波将趋势项剥离，得到平稳的周期项，满足傅里叶变换对平稳性的要求，然后再对周期项进行FFT，提取核心周期并进行中长期预测。研究对产出、通胀、存货、利润、货币、信贷等六维经济数据进行核心周期提取，发现大部分数据的核心周期长度都为3至4年。

FFT假设信号是平稳且全局存在的，但金融数据往往存在结构突变。因此，FFT多用于全局周期的初步探索，或作为带通滤波器的基础。具体操作是，通过高斯滤波与傅里叶逆变换，将频域上特定周期及其附近信号频率拟合成包含更丰富信号的周期序列，再与原始同比序列回归，可决系数通常能达到50%以上。

1.2.HP滤波（Hodrick-Prescott Filter）

HP滤波是宏观周期量化中最常用的趋势—周期分解工具。它将观测序列 \(y_t\) 分解为趋势项 \(\tau_t\) 与周期项 \(c_t\)：

\(y_t = \tau_t + c_t\)

并通过求解如下最小化问题得到趋势项：

\(\min_{\{\tau_t\}} \sum_{t=1}^{T}(y_t-\tau_t)^2 + \lambda \sum_{t=2}^{T-1}\left[(\tau_{t+1}-\tau_t)-(\tau_t-\tau_{t-1})\right]^2\)

第一项衡量趋势对原序列的拟合程度，第二项惩罚趋势项的二阶差分，即限制趋势的平滑程度。\(\lambda\) 越大，趋势越平滑，周期项 \(c_t=y_t-\tau_t\) 保留的波动越大。

常用经验参数为：年度数据 \(\lambda=100\)，季度数据 \(\lambda=1600\)，月度数据 \(\lambda=14400\)。日频或周频金融数据一般不建议直接使用标准 HP 参数，因为高频噪声会被大量归入周期项，通常需改用 CF 滤波、BK 滤波或 Hamilton 回归滤波。

在频域上，HP 滤波本质上是一个低通滤波器，用于剥离低频趋势、保留中短周期成分。但它的频率响应并非理想带通，存在通带波纹、端点偏差和伪周期问题。因此，在量化实践中，HP 滤波更适合作为预处理和稳健性基线，而非最终信号生成器。使用时建议同时比较多种 \(\lambda\)、多种滤波方法，并在回测中严格使用扩展样本或单边滤波，避免右端点估计引入前视偏差。

HP 滤波在周期量化中的典型应用包括：

  • 宏观缺口估计：实际产出减 HP 潜在产出得到产出缺口，CPI、信贷、库存等指标也可类似处理，用于刻画经济周期位置。

  • 周期项提取：对同比序列先做 HP 去趋势，得到平稳周期项，再做 FFT 识别 42 个月、100 个月、200 个月等主导周期。前文中研究采用的“HP 滤波 + 傅里叶变换”两步法即属此类：先剥离趋势，再对周期项做谱分析，最后用高斯滤波重构核心周期序列并回归预测。

  • 与状态空间模型衔接：HP 滤波可视为局部线性趋势模型的特例。设：

    \(y_t=\tau_t+\varepsilon_t,\quad \tau_{t+1}=\tau_t+\beta_t+\eta_t,\quad \beta_{t+1}=\beta_t+\zeta_t\)

    在 \(\eta_t=0\) 时，其平滑解与 HP 滤波对应，\(\lambda=\sigma_\varepsilon^2/\sigma_\zeta^2\)。因此可用卡尔曼平滑实现 HP 滤波，并自然处理缺失值与实时估计问题。

  • 在因子构建层面，HP 滤波输出的周期项 \(c_t\) 可进一步衍生为：周期 z-score、周期斜率、周期相位、滚动振幅、周期位置等特征，再输入机器学习模型（如：XGBoost/LightGBM）中，形成“周期预处理 + 非线性映射 + 区制切换”的复合策略框架。

1.3.小波变换（Wavelet Transform）

为解决FFT无法捕捉时变特征的缺陷，小波变换引入了“时频局部化”能力。连续小波变换（CWT）的数学定义为：

\(W(a, b) = \frac{1}{\sqrt{|a|}} \int_{-\infty}^{\infty} x(t) \psi^*\left(\frac{t-b}{a}\right) dt\)

其中\(a\)为尺度参数（对应频率），\(b\)为平移参数（对应时间），\(\psi\)为母小波。最常用的复值小波是Morlet小波：

\(\psi_0(\eta) = \pi^{-1/4} e^{i\omega_0 \eta} e^{-\eta^2/2}\)

其中\(\omega_0 = 5\)是常用的中心频率选择，兼顾时频分辨率。Morlet小波的复值特性使其能同时提取信号的振幅和相位信息，适合分析周期分量随时间的漂移。

离散小波变换（DWT）则将尺度和平移参数离散化，常用于信号的多分辨率分解。实践中，DWT可将价格序列分解为趋势项（低频近似系数）和噪声/短周期项（高频细节系数），实现信号去噪。

在宏观数据应用中，小波去噪常用于提升GDP、CPI等数据的信噪比。具体流程为：

对原始序列进行DWT分解 → 对各层细节系数设定阈值（软阈值或硬阈值）进行收缩 → 重构去噪后的序列。

这一方法能有效剔除高频噪声，同时保留低频周期结构，为后续建模提供干净的特征。

1.4.经验模态分解（EMD）

EMD是一种完全数据驱动的自适应信号分解方法，无需预设基函数。其核心思想是：任何复杂信号都可分解为有限个本征模态函数（IMF）和一个残差项：

\(x(t) = \sum_{j=1}^{n} \text{IMF}_j(t) + r_n(t)\)

每个IMF必须满足两个条件：（1）极值点数量与过零点数量之差不超过1；（2）上包络和下包络的均值为零。

EMD通过“筛选”过程迭代提取IMF：先识别信号的所有局部极值点，用三次样条插值构造上、下包络线，计算均值包络，用原信号减去均值包络得到新信号，重复直至满足IMF条件。对残余信号继续上述过程，直到残余信号成为单调函数。

实践中，可以将资产价格进行分解，低频IMF代表长周期趋势，中频IMF对应中周期，高频IMF则反映短期市场情绪。

传统EMD存在“模态混叠”和端点效应。实践中通常采用EEMD等改进方法，其分解精度和完备性优于EEMD。例如：在价格预测研究中，可以先使用EEMD将波动率分解为多个IMF与残差项，再依据样本熵值重构为高、中、低频分量。一般认为，EEMD分解出的多个IMF分量分别代表不同频率的市场驱动因素，各分量输入LSTM进行独立预测后再集成，具有更好的预测效果。

2. 状态空间与状态转换模型

2.1.马尔可夫状态转移模型（Markov Switching, MS）

经济周期本质上是一种“状态切换”。MS模型假设时间序列在不同状态（或称区制，Regime）下服从不同的数据生成过程，且状态之间的转换由马尔可夫链驱动。

标准MS模型的形式为：

\(y_t = \mu_{S_t} + \sum_{i=1}^{p} \phi_{i,S_t} y_{t-i} + \sigma_{S_t} \epsilon_t, \quad \epsilon_t \sim N(0,1)\)

其中\(S_t \in \{1, 2\}\)为不可观测的区制状态，转移概率矩阵为：

\(P = \begin{pmatrix} p_{11} & 1-p_{11} \\ 1-p_{22} & p_{22} \end{pmatrix}, \quad p_{ij} = P(S_t = j | S_{t-1} = i)\)

模型参数通常通过EM算法或极大似然估计进行估计，其中滤波概率\(P(S_t = j | y_1, \ldots, y_t)\)通过Hamilton滤波递归计算。

有研究选取工业品、黄金、国债及股票指数，采用MS模型进行状态划分，发现PPMI+PPI的指标组合能够对经济周期进行最优的状态划分。各资产在不同状态区制的表现与经验预期一致：在复苏期股票最优、债券最差；在过热期工业品最优、黄金最差；在滞涨期黄金最优、股票最差；在衰退期债券最优、工业品最差。可基于PMI+PPI状态划分所构造的资产轮动投资组合。

2.2 隐马尔可夫模型（HMM）与卡尔曼滤波

隐马尔可夫模型（HMM）更侧重于离散状态的观测概率。在HMM中，观测变量\(y_t\)由隐藏状态\(S_t\)的概率分布生成，即：\(y_t \sim p(y_t | S_t; \theta)\)。

在高斯HMM中，输出概率为高斯分布：

\(y_t \mid S_t = j \sim N(\mu_j, \Sigma_j)\)

  • \(y_t\)：第 \(t\) 期的观测向量，可以是收益率、宏观指标、多因子截面等，维度为 \(d\)。
  • \(S_t\)：第 \(t\) 期的隐藏状态，取值 \(1,2,\dots,K\)，不可直接观测，只能通过 \(y_t\) 推断。
  • \(j\)：某个具体状态，比如“牛市”“熊市”“高波动”“低波动”。
  • \(\mu_j\)：状态 \(j\) 下的均值向量。
  • \(\Sigma_j\)：状态 \(j\) 下的协方差矩阵，刻画波动率和变量间相关性。

参数通过 Baum-Welch 算法（一种EM算法）进行估计，状态推断通过Viterbi算法获取最优状态路径。

卡尔曼滤波则是处理不可观测周期因子的利器。状态空间模型的一般形式为：

\(\begin{aligned} \alpha_{t+1} &= T \alpha_t + R \eta_t, \quad \eta_t \sim N(0, Q) \\ y_t &= Z \alpha_t + \epsilon_t, \quad \epsilon_t \sim N(0, H) \end{aligned}\)

其中：\(\alpha_t\)为不可观测的状态向量，\(y_t\)为观测向量。卡尔曼滤波通过“预测-更新”递归实现状态的最优线性估计。预测步骤计算先验状态估计和先验误差协方差，更新步骤利用新息（观测值与预测值之差）和卡尔曼增益修正状态估计。

前面章节中，介绍了动态因子模型（DFM），结合卡尔曼滤波，能够从数十个宏观指标中提取出实时的“经济增长周期因子”和“通胀周期因子”。具体而言，DFM假设每个宏观指标的观测值由少数几个共同因子驱动。通过将DFM写成状态空间形式，并应用卡尔曼滤波，可以实时估计因子值，并测算新发布数据对GDP等重要低频数据预测值的信息冲击程度，实现对经济数据的系统化实时监测。这是桥水等宏观对冲基金全天候策略的核心基石。

3. 机器学习与深度学习

3.1. Logit 模型

在周期量化中，如果目标是预测未来资产涨跌、经济衰退/扩张、或区制状态切换，Logit 模型（即 Logistic 回归，逻辑回归） 模型往往比树模型集成更合适。原因在于：宏观周期理论本身提供了强先验和结构化特征，而 Logit 模型的可解释性、概率输出、正则化稳健性和小样本下的低过拟合特性，恰好匹配低信噪比的金融数据。树模型虽然能自动捕捉非线性，但在小样本、结构突变和外推场景下容易过拟合，且概率校准常不理想。

3.1.1. 基本形式

设 \(y_t \in \{0,1\}\) 表示未来 \(h\) 期是否发生某事件，例如“未来一个月收益为正”“未来 12 个月进入衰退”“下一期状态为高波动区制”。给定特征向量 \(x_t\)，Logit 模型假设：

\(P(y_t=1 \mid x_t)=\frac{1}{1+\exp[-(\beta_0+\beta^\top x_t)]}\)

等价地，对数几率是特征的线性函数：

\(\log\frac{P(y_t=1\mid x_t)}{1-P(y_t=1\mid x_t)}=\beta_0+\beta^\top x_t\)

这就是 Logit 模型的核心：它不直接建模收益率，而是建模事件发生的对数几率。系数 \(\beta_k\) 表示特征 \(x_{k,t}\) 每增加一单位，事件发生的 log-odds 增加多少。若 \(\beta_k>0\)，该特征提高上涨/扩张概率；若 \(\beta_k<0\)，则降低。

参数通过极大似然估计：

\(\ell(\beta)=\sum_{t=1}^T\left[y_t \log p_t+(1-y_t)\log(1-p_t)\right]\)

其中 \(p_t=P(y_t=1\mid x_t)\)。加入弹性网惩罚后：

\(\min_\beta -\ell(\beta)+\lambda\left[\alpha\|\beta\|_1+\frac{1-\alpha}{2}\|\beta\|_2^2\right]\)

L1 部分做特征选择，L2 部分处理共线性并稳定估计。在宏观因子高度相关的场景下，弹性网 Logit 比纯 L1 或纯 L2 更实用。

3.1.2. 多分类与有序扩展

若周期阶段分为复苏、过热、滞胀、衰退四类，可用多项 Logit：

\(P(y_t=k\mid x_t)=\frac{\exp(\beta_k^\top x_t)} {\sum_{l=1}^K \exp(\beta_l^\top x_t)}\)

若周期阶段本身有序，例如“衰退→复苏→过热→滞胀”，则有序 Logit 更合适：

\(P(y_t\le k\mid x_t)=\frac{1}{1+\exp[-(\theta_k-\beta^\top x_t)]}\)

其中 \(\theta_1<\theta_2<\cdots<\theta_{K-1}\) 为切点。有序 Logit 假设特征对累积概率的影响方向一致，只是切点不同，比多项 Logit 更省参数，也更符合周期阶段的递进逻辑。

3.1.3. 特征工程与周期理论的衔接

Logit 模型要求特征与 log-odds 近似线性，因此特征构造尤为关键。可沿用前文体系：

  • 频域特征：FFT 在 42、100、200 个月频段的能量占比。
  • 状态特征：MS/HMM 输出的滤波状态概率、状态持续期、切换概率。
  • 周期相位特征：当前周期位置。相位不宜直接用线性时间，而应做周期编码： \(\sin(2\pi t/T),\cos(2\pi t/T)\) 其中 \(T\) 为主导周期长度。
  • 宏观因子特征：DFM 提取的增长因子、通胀因子的当期值与变化率。
  • 交互项：周期相位 × 状态概率、增长因子 × 通胀因子、信用利差 × 状态持续期。Logit 本身不自动生成交互，需手工加入。

3.1.4. 典型案例和实践建议

Logit 模型在周期量化中的典型案例：

  • 衰退概率 Nowcasting：用期限利差、信用利差、PMI、DFM 增长因子预测未来 12 个月衰退概率。
  • 状态切换预测：用 MS/HMM 当前滤波状态概率、持续期、宏观因子预测下一期状态，作为区制转换的即时预测。
  • 资产择时：预测未来 \(h\) 期收益为正的概率 \(p_t\)，构建仓位： \(w_t=\text{clip}(2p_t-1,-1,1)\)
  • Stacking 元学习器：将 XGBoost、LightGBM、LSTM 的输出作为新特征，再用 Logit 做最终集成。Logit 作为元学习器不易过拟合，且权重可解释。

注意：金融时序不能随机划分训练集和测试集，必须使用扩展窗口或滚动窗口。交叉验证时，标准 K-Fold 在金融数据上存在信息泄露问题，建议用 purged K-fold + embargo，避免未来信息泄漏。

此外，宏观事件常存在样本不均衡，例如衰退月份远少于扩张月份。处理方式包括：

  • 加权极大似然，给少数类更高权重；
  • Firth 惩罚 Logit，缓解分离问题；
  • 调整决策阈值，而非固定 0.5；
  • 用 Brier score、可靠性图评估概率校准，而非只看准确率。

详细可参考《Advances in Financial Machine Learning》一书内容。

3.1.5.与树模型的对比

因此，在宏观周期量化中，更稳妥的架构是：以弹性网 Logit 为主模型，树模型作为特征筛选或非线性补充。尤其是周期理论提供的是相位、状态概率、频域能量等结构化特征，Logit 的线性 log-odds 假设反而成为优势，它帮助我们了解“周期相位每上升一单位，上涨概率到底增加多少”，而不是把解释权完全交给黑箱。
维度 Logit 模型 树模型集成
非线性 需手工构造样条/交互 自动捕捉
可解释性 系数符号、显著性、几率比 特征重要性，但方向不直接
小样本 稳健，正则化后更稳 易过拟合
外推 合理 差，树不能外推
概率校准 通常较好 常需额外校准
特征工程 要求高 要求低
适用场景 低信噪比、小样本、重解释 大样本、高维、强非线性

Logit 模型把周期理论转化为可检验的几率比，把状态概率转化为可交易的仓位，在低信噪比、小样本、重解释的宏观周期场景中，往往比树模型集成更稳健、更可信。

3.2. 树模型集成（XGBoost/LightGBM）

树模型集成是处理结构化周期特征的非线性映射工具。与 Logit 需要手工构造样条和交互项不同，梯度提升树可以自动捕捉特征间的非线性关系和交互效应。在周期量化中，它适合作为 Logit 的非线性增强和特征筛选器，而非替代品。

树模型对特征工程的要求低于 Logit，仍可沿用同一套周期特征体系。树模型无需手工加入交互项，因为它会在分裂节点时自动寻找最优组合。

XGBoost 和 LightGBM 都是梯度提升决策树（GBDT）的高效实现。其核心思想是：串行训练多棵决策树，每棵树拟合前序模型的残差，最终预测为所有树输出的加权和。XGBoost 使用 Level-wise 生长策略，即逐层分裂节点，对每层所有节点同时分裂。LightGBM 使用 Leaf-wise 生长策略，每次选择当前增益最大的叶子节点进行分裂。配合基于直方图的决策树算法（将连续特征离散化为桶），LightGBM 在处理大规模特征时效率显著优于 XGBoost。其直方图算法将特征值分桶，分裂时只需遍历桶而非所有样本，内存和计算开销大幅降低。

两者均可输出特征重要性：

  • Gain：特征在分裂中带来的平均增益，最能反映特征贡献。
  • Cover：特征分裂覆盖的样本数。
  • Frequency：特征被用于分裂的次数。

优势：

  • 对异常值鲁棒，不需要严格的分布假设。

  • 小样本下比深度学习更不易过拟合，且可通过早停、子采样、正则化控制复杂度。

  • 能输出特征重要性，帮助研究员验证周期理论。

  • 训练速度快，尤其 LightGBM 在高维特征上效率突出。

局限：

  • 外推能力差，无法预测训练集范围外的值。

  • 概率校准通常不理想，需 Platt scaling 或 isotonic regression 后处理。

  • 不擅长捕捉长序列依赖和多周期共振，需要手工构造滞后和滚动特征。

  • 对超参数敏感，学习率、树深、叶子数、子采样比例等需仔细调优。

因此，在宏观周期量化中，更稳妥的架构是：以弹性网 Logit 为主模型，树模型作为特征筛选或非线性补充。例如，先用 LightGBM 做特征重要性排序，筛选出 Top 20 特征，再放入弹性网 Logit 做最终概率输出。这样既利用了树模型的非线性发现能力，又保留了 Logit 的可解释性和概率校准优势。

3.3. 深度学习模型

深度学习适合处理长序列、多频率叠加、非线性交互的周期问题。金融数据信噪比极低，直接预测价格极易过拟合，因此更有效的用法是降维去噪、状态推断、波动率建模和策略训练，而非直接替代 Logit 或树模型。

3.3.1.LSTM 和 GRU

LSTM 和 GRU 通过门控机制捕捉时间序列的长依赖关系。在周期量化中，可用于：

  • 波动率预测：捕捉波动率聚集和长记忆性。
  • 宏观 Nowcasting：利用高频数据实时预测 GDP、通胀等低频指标。
  • 状态切换预测：输入宏观因子序列，预测下一期 HMM/MS 状态。
  • 多周期共振建模：将 42、100、200 个月周期的相位编码作为输入，学习多周期叠加下的非线性交互。

LSTM 在低频数据（日频、月频）上样本效率较高，可解释性优于 Transformer。但训练需要大量数据，且容易过拟合，需配合 Dropout、早停、正则化。

3.3.2.Transformer

Transformer 通过自注意力机制处理长序列：

\(\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V\)

多头注意力允许模型同时关注不同时间尺度和不同频率的周期模式。在周期量化中，Transformer 可用于与：

  • 多周期交互：同时建模基钦、朱格拉、康波周期的非线性叠加。
  • 区制转变识别：捕捉长程依赖下的状态切换前兆。
  • 高频数据建模：处理分钟级、日级高频序列中的微观结构状态。

但 Transformer 对数据量要求更高，金融小样本下容易过拟合，且黑箱性强，可解释性差。

3.3.3.其它

GAN 可以生成符合历史周期分布的模拟路径，用于扩充训练样本。例如，LSTM-based Wasserstein GAN 可以合成大量真实的市场路径，与真实历史数据合并，形成增强训练环境。

强化学习 则可用于策略训练。在模拟环境中，智能体根据当前周期状态、持仓和宏观因子决定仓位，通过奖励函数学习最优策略。由于金融数据稀缺，强化学习通常需要 GAN 生成的模拟路径来增加训练样本，降低过拟合风险。

深度学习模型应用面临巨大的局限性，包括：金融数据信噪比低，容易过拟合；黑箱性强，可解释性差。 需要大量数据和计算资源；概率校准困难，输出概率往往不可靠；超参数敏感，训练不稳定。

因此，深度学习在周期量化中更适合作为特征提取器或复杂场景补充，而非最终决策模型。最终的概率输出和仓位决策，仍建议由 Logit 或经过校准的树模型完成。

3.4. 多模型融合框架

单一模型难以全面刻画周期的复杂性，实践中常采用 Stacking 融合策略。架构如下：

  • 第一层，基学习器：
    • 弹性网 Logit：提供可解释概率基线。
    • LightGBM / XGBoost：提供非线性增强。
    • LSTM / Transformer：提供长序列和多周期交互（数据充足时）。
    • Autoencoder + HMM：提供降维状态概率。
  • 第二层，元学习器：
    • 使用 Logit 作为元学习器，输入第一层各模型的样本外预测概率。
    • Logit 元学习器不易过拟合，权重可解释，且输出概率校准较好。
    • 若数据量充足，也可用浅层神经网络或带正则化的线性模型。

具体而言，XGBoost和LightGBM处理结构化特征（频域能量、状态概率等），LSTM处理序列依赖，Transformer捕捉长程周期交互，各基模型的输出再通过一个元学习器（如线性回归）进行集成。这一框架能够充分利用不同模型在周期不同维度上的优势，提升预测的稳健性。

实践中，建议：

  • 以 Logit 为锚：先建立可解释基线，检验周期相位、状态概率等特征的几率比。
  • 树模型做增强：用 LightGBM 做特征重要性排序，筛选 Top 特征后放入 Logit。
  • 深度学习做补充：在数据充足时，用 LSTM 或 Autoencoder 提取额外特征，但需严格验证是否带来样本外提升。
  • 概率校准不可省略：无论树模型还是深度学习，输出概率都需用 Platt scaling 或 isotonic regression 校准。
  • 经济逻辑优先：任何模型提升都应能对应到周期理论的经济逻辑，否则可能是数据挖掘的假象。

3.5. 小结

在低信噪比、小样本、重解释的宏观周期场景中，Logit 模型是稳健的锚，它把周期理论转化为可检验的几率比，把状态概率转化为可交易的仓位；树模型是非线性增强，擅长自动捕捉交互和筛选特征，但需警惕外推和校准问题；深度学习是复杂场景的补充，适合长序列、多周期共振和高维降维，但需大量数据和严格验证。三者通过 Stacking 融合，以 Logit 为元学习器，配合 Purged K-Fold + Embargo 和 Brier score 评估，可构建既稳健又具备样本外泛化能力的周期量化框架。

四、投资中的应用

1.CNN 恐贪指数

1.1.概述

市场短期是投票机，长期是称重机。而“投票”的背后，是数以亿计投资者的情绪起伏：恐惧与贪婪。恐惧与贪婪指数（Fear & Greed Index）正是试图把这种看不见摸不着的市场情绪，转化为一个可量化、可比较、可跟踪的数字。

情绪本身无法直接观测，但它的“痕迹”会留在各类市场数据中。恐惧与贪婪指数的核心思想，就是选取一组能够反映资金流向、市场宽度、波动预期和避险行为的代理变量，通过加权合成，输出一个分值。最广为人知的版本是CNN Business于2012年推出的Fear & Greed Index，最初用于股票市场，后来被广泛借鉴到加密货币、商品、外汇等领域。下面以股票版为主轴，兼顾加密版的差异。

1.2.各个分项

CNN版本由七个等权分项构成，每个分项都从不同角度捕捉情绪。理解编制，首先要理解每个指标的经济含义。

  1. 股价动量（Stock Price Momentum） 用标普500指数与其125日移动均线的偏离度衡量。价格远高于均线，说明追涨情绪浓厚，偏向贪婪；跌破均线则偏向恐惧。这是最直接的“价格情绪”代理。

  2. 股价强度（Stock Price Strength） 统计纽约证券交易所中创52周新高的股票数与创52周新低股票数的比值。新高多于新低，市场内部健康、情绪乐观；新低激增，则恐慌蔓延。它衡量的是市场广度而非指数点位，能揭示“指数涨但个股跌”的背离。

  3. 股价广度（Stock Price Breadth） 用上涨股票成交量与下跌股票成交量的比值，通常以McClellan Volume Summation Index（基于上涨/下跌股成交量的累计差值）形式呈现。它关注的是资金在个股层面的参与度，成交量是情绪的“燃料”。

  4. 看跌看涨期权比率（Put/Call Ratio） 看跌期权成交量除以看涨期权成交量。比率高，说明投资者大量买入看跌期权对冲或投机下跌，情绪恐惧；比率低，说明看涨期权受追捧，情绪贪婪。这是一个典型的反向指标，极端恐慌往往对应市场底部。

  5. 市场波动率（Market Volatility） 用VIX指数（恐慌指数）及其与50日均线的偏离。VIX飙升代表恐惧，VIX低迷代表自满与贪婪。注意，VIX本身是隐含波动率，反映的是期权市场对未来波动的定价。

  6. 避险需求（Safe Haven Demand） 比较股票与国债在过去20个交易日的相对表现。资金涌入国债、逃离股票，说明避险情绪主导；股票跑赢国债，说明风险偏好上升。

  7. 垃圾债需求（Junk Bond Demand） 比较垃圾债（高收益债）与投资级国债的收益率之差（利差）。利差收窄，说明投资者愿意为风险资产支付更高价格，情绪贪婪；利差扩大，说明风险厌恶上升，情绪恐惧。

这七个指标覆盖了价格、广度、成交量、期权、波动率、跨资产避险和信用利差，形成了一个相对立体的情绪画像。

1.3.编制方法

各分项合成步骤如下：

第一步：计算每个分项的原始值。 例如动量指标，计算标普500当前价与125日均线的百分比偏离；看跌看涨比率，取当日成交量比值。

第二步：将原始值映射到0-100。 CNN的方法并非简单的线性缩放，而是将每个指标与其自身的历史区间比较。常见做法是：取过去一段时间（如一年或两年）的每日数值，计算其分位数，再把当前值映射到0-100。有些指标越高越贪婪（如动量、垃圾债需求），有些越高越恐惧（如VIX、看跌看涨比率）。对于反向指标，需用100减去标准化值，确保所有分项“越高越贪婪”。

第三步：等权平均。 将七个分项的标准化值简单平均，得到最终指数。

第四步：平滑与分级。 为避免单日噪声，有时会对指数做移动平均。然后按区间分级：0-25极度恐惧，25-45恐惧，45-55中性，55-75贪婪，75-100极度贪婪。

等权重设计的方法论优势在于：第一，避免了对任一单一指标的过度依赖，降低了模型过拟合风险；第二，七个指标分别来自价格、期权、信用、波动率和避险资产等不同市场板块，等权重隐含地假设各板块的信息含量大致相当；第三，等权重方案透明、可复现，便于投资者理解与验证。

1.4.实战应用

恐惧与贪婪指数仅仅是情绪温度计，不是买卖信号。它常见的使用方法包括：

  • 极端值逆向参考。 当指数跌破10（极度恐惧），往往意味着恐慌性抛售接近尾声，历史上常出现反弹；当指数突破90（极度贪婪），市场可能过热，需警惕回撤。但“极端”可以持续很久，不能单独作为抄底逃顶依据。

  • 仓位调节的辅助因子。 可将FGI作为风险预算的调整项：极度恐惧时适度提高风险敞口，极度贪婪时降低杠杆。

  • 多因子模型中的情绪因子。 在量化多因子框架中，FGI可作为情绪类因子，与价值、动量、质量因子组合，提升模型的解释力。

  • 背离观察。 指数与价格背离时值得警惕。例如价格创新高但FGI未创新高，说明上涨动能减弱。

应用中常见误区：

  • 把反向指标当反向操作指令。 恐惧时买入、贪婪时卖出，说起来简单，但市场可以在极度恐惧中继续下跌30%。

  • 忽略时间尺度。 FGI更适合中期（数周至数月）择时，不适合日内交易。

  • 跨市场生搬硬套。 股票版FGI用到加密市场会失真，因为两者参与者、波动结构、避险工具完全不同。

  • 过拟合历史阈值。 不同市场、不同时代，恐惧与贪婪的阈值会漂移。2008年的“极度恐惧”和2020年3月的“极度恐惧”在数值上可能不同，需动态看待。

2. A股市场恐贪指数

参考CNN恐贪指数，我们可以构建一个可落地、可回测、可解释的A股恐贪指数，用于识别A股市场的极端情绪状态，辅助仓位管理与逆向择时决策。

2.1.维度一：市场动能

分项1：价格乖离率

  • 代理变量：沪深300指数与125日移动均线的偏离度
  • 方向：偏离度越高越贪婪，越低越恐惧
  • 逻辑：价格远离均线时，追涨或杀跌情绪积累。这是最基础的情绪“温度”读数。

分项2：MACD 趋势强度

  • 代理变量：沪深300日线MACD指标，即DIF-DEA柱值，取20日均值
  • 方向：柱值越大越贪婪
  • 逻辑：MACD不仅反映价格方向，还反映动能的加速或衰减。

2.2.维度二：市场内部结构

分项3：股价强度

  • 代理变量：全市场创52周新高股票占比 − 创52周新低股票占比
  • 方向：差值越大越贪婪

分项4：涨停占比

  • 代理变量：每日涨停股数量占全市场股票数的比例，取20日均值
  • 方向：越高越贪婪
  • 逻辑：涨停股数量占比的大幅提升经常出现在上涨行情末期，需要关注市场过热风险。

此外，还经常使用“创近一年新高股票占比“、”换手率“、”成交量“等指标作为代理。

2.3.维度三：资金行为

分项5：杠杆资金（融资净买入占比）

  • 代理变量：净融资买入额 / 两市总成交额，取20日均值
  • 方向：越高越贪婪
  • 逻辑：融资余额占比高往往对应着市场风险偏好较高的阶段。

分项6：散户资金（行业ETF净申购）

  • 代理变量：宽基ETF净申购额的20日滚动值
  • 方向：申购为贪婪，赎回为恐惧

分项7：外资行为（北向资金）

  • 代理变量：陆股通累计净买入额的20日偏离度
  • 方向：净流入为贪婪，净流出为恐惧
  • 逻辑：北向资金是重要的市场定价力量之一，其流向可作为外资情绪的观测窗口。

此外，还经常使用”新增开户数“、“机构持仓”等指标作为代理。

2.4.维度四：期权市场预期

分项8：持仓量PCR

  • 代理变量：上证50\沪深300股指期权持仓量PCR（看跌持仓/看涨持仓），取20日均值
  • 方向：PCR值越高越恐惧

分项9：隐含波动率偏度

  • 代理变量：上证50\沪深300股指期权隐含波动率偏度
  • 方向：隐含波动率偏度越高越恐惧

A股本质上偏向做多的单边市场，多空生态与其它市场不同，衍生品指标表现出的特征也略有不同。

2.5.维度五：估值锚（低频校验）

分项10：估值分位数

  • 代理变量：沪深300 PE与PB的10年滚动分位数均值
  • 方向：越高越贪婪
  • 逻辑：估值是情绪的大周期坐标。估值不直接给出短期信号，但它决定了恐贪指数的“基准水位”。

分项11：股债性价比

  • 代理变量：沪深300的1/PE-10年期国债到期收益率
  • 方向：利差高意味着股票便宜、情绪恐惧；利差低意味着股票贵、情绪贪婪。
  • 逻辑：以沪深300为代表的股票理论回报率”是1/PE，如果这个回报率显著高于无风险国债收益率，说明股票相对便宜，性价比高。

对每个分项，取过去250个交易日的滚动窗口，将当前值映射到其历史分位数上，得到0-100的标准化值。对于反向指标（如ETF净申购、持仓PCR），用 100-分位数 转换，确保所有分项“越高越贪婪”。将标准化后的各类分项等权平均，得到最终指数（0–100）。

3.华泰三周期模型方案

华泰证券金工团队于2021年5月发布深度研究报告《工业社会的秩序》，提出金融经济系统存在三个稳定运行的共同周期：42个月、100个月和200个月，分别对应古典经济学中的基钦周期（库存周期）、朱格拉周期（设备投资周期）和库兹涅茨周期（建筑/长周期）。

3.1.技术路线：从时域到频域的三步信号处理

第一步：傅里叶变换——周期存在性的初筛

对全球主要市场的金融资产（股票指数、债券指数、大宗商品指数）和宏观经济变量（CPI、PPI、M1、M2等）的同比序列进行傅里叶变换，将时域信号转换到频域，观察功率谱中是否存在显著的能量集中。

上证综指等序列的功率谱函数在42个月、100个月和200个月附近呈现明显波峰，初步验证了三周期的存在。

同时，小波分析被用于检验这些周期分量在不同时间窗口中的稳定性，发现40~45个月的周期分量强度高且稳定，100个月周期分量在部分指标中同样强势且稳定。

第二步：MUSIC算法——系统级共同周期的精确测度

傅里叶变换只能说明单个序列存在周期，但无法证明不同序列之间存在共同周期。华泰引入阵列信号处理中的MUSIC算法解决这一问题。核心思路是：将每个经济金融序列视为一根“天线”，将它们的时域序列看作天线的采样矩阵，从而借助信号处理算法提取多个序列的共同谱。

MUSIC算法通过对协方差矩阵做特征值分解，利用信号子空间和噪声子空间的正交性推导功率谱函数，在参数空间中搜索最优频率值，实现对共同周期的超分辨率估计。

实证检验表明，全球重要市场的股票指数、CPI、PPI、CRB大宗商品指数等均存在42、100和200个月左右的三个共同周期信号。

第三步：高斯滤波——周期信号的提纯与分离

在确定三个核心周期后，需要对原始序列进行滤波提纯，提取出每个周期的独立信号分量。高斯滤波器因其在频域上平滑的过渡特性，能够在保留目标频率附近信号的同时有效抑制噪声。

具体做法是对去趋势后的序列施加中心频率分别为42、100、200个月的高斯滤波，得到三组周期信号，再用这三组信号对原始同比序列进行回归拟合。

回归结果表明，拟合优度（R²）普遍在0.5以上，股票市场和CRB指数可达0.7，部分CPI和PPI指标可达0.8以上，说明三周期信号表达了原始数据的主要信息。

3.2.三周期因子模型的构建

华泰将42个月、100个月、200个月三个周期的滤波信号抽象为三个因子：基钦周期因子、朱格拉周期因子、库兹涅茨周期因子，构建回归方程：

\(Y_t = \beta\_0 + \beta_1 X_{42,t} + \beta_2 X_{100,t} + \beta_3 X_{200,t} + \varepsilon_t\)

其中\(Y_t\)为资产或宏观变量的同比序列，\(X_{42}\)、\(X_{100}\)、\(X_{200}\)为对应周期的高斯滤波信号。

三个周期分别对应经济体的短期、中期和长期增长动力：42个月周期反映库存与短周期波动，100个月周期反映设备投资与产能周期，200个月周期反映建筑投资与结构性变迁。三种动力共同作用，构成系统级别的经济周期驱动力。

3.3.三周期因子模型的应用

不同长度的周期对应不同级别的趋势，长周期决定战略方向，短周期提供战术买卖点。战略层使用康波、库兹涅茨和朱格拉周期判断大类资产配置；战术层使用基钦周期和情绪指标判断行业轮动和仓位调整；同时使用高频数据和微观结构信号捕捉短期机会。

  • 资产配置：基于周期三因子定价模型，计算各资产同比序列的周期拟合值，当拟合值处于上升阶段时看多该资产，处于下行阶段时减配或规避。策略覆盖股票、债券、商品三大类资产，并在发达市场与新兴市场之间充分分散化。

  • 行业轮动：以CRB综合现货指数为实体经济代表，提取行业波动的周期信号，定量刻画库兹涅茨、朱格拉、基钦周期视角下的行业轮动规律。

    实证显示，三周期因子模型能够精准拟合行业涨跌走势，识别板块的相位和幅度分化，据此进行行业配置。A股短期牛熊变化主要由基钦周期驱动，每轮周期的主导板块呈现“消费→成长→价值→周期”的轮动规律。

择时与风险管理：通过判断三大周期当前所处的相位（上行/下行/底部/顶部），形成对市场整体风险偏好的判断。当多个周期同时处于下行阶段（如“三周期共振下行”）时，应系统性降低风险敞口。也可在此基础上，可引入其它择时信号和预警机制辅助调仓规避风险。

# 1. 模拟包含 42、100、200 个月周期的序列 

# 样本长度：600 个月，覆盖 3 个 200 月周期
n <- 600        
t <- 1:n

# 三个周期分量（模拟真实周期信号）
comp42  <- 1.0 * sin(2 * pi * t / 42)
comp100 <- 1.5 * sin(2 * pi * t / 100 + pi / 4)
comp200 <- 2.0 * sin(2 * pi * t / 200 + pi / 3)

# 线性趋势 + 噪声
trend <- 0.01 * t
noise <- rnorm(n, 0, 0.5)

# 观测序列（假设为同比序列）
y <- comp42 + comp100 + comp200 + trend + noise

# 绘制原始序列
plot(t, y, type = "l", main = "模拟的同比序列", xlab = "月份", ylab = "值")

# 2. 去趋势（消除高阶趋势对长周期估计的干扰）
y_detrend <- resid(lm(y ~ t))

plot(t, y_detrend, type = "l", main = "去趋势后的序列", xlab = "月份", ylab = "值")

# 3. 傅里叶变换：功率谱初筛 
Y <- fft(y_detrend)
power <- Mod(Y)^2
freqs <- (0:(n - 1)) / n
periods <- 1 / freqs

# 只取前半部分（正频率）
half <- 1:(n / 2)
plot(periods[half], power[half], type = "l", log = "x",
     xlab = "周期（月）", ylab = "功率",
     main = "傅里叶功率谱")
abline(v = c(42, 100, 200), col = "red", lty = 2)
legend("topright", legend = c("42", "100", "200"), col = "red", lty = 2)

#  4. MUSIC 算法：估计共同周期 
# 定义 MUSIC 谱函数（单序列，通过 Hankel 矩阵构造协方差）
music_spectrum <- function(x, M, K, f_grid) {
  T <- length(x)
  # 构造 Hankel 矩阵：行 M，列 T-M+1
  X <- matrix(0, nrow = M, ncol = T - M + 1)
  for (i in 1:M) {
    X[i, ] <- x[i:(T - M + i)]
  }
  # 协方差矩阵
  R <- X %*% Conj(t(X)) / (T - M + 1)
  # 特征分解
  eig <- eigen(R)
  idx <- order(eig$values, decreasing = TRUE)
  eig$values <- eig$values[idx]
  eig$vectors <- eig$vectors[, idx]
  # 噪声子空间：从 K+1 到 M
  En <- eig$vectors[, (K + 1):M, drop = FALSE]
  # 计算 MUSIC 谱
  P <- numeric(length(f_grid))
  for (j in seq_along(f_grid)) {
    f <- f_grid[j]
    a <- exp(1i * 2 * pi * f * (0:(M - 1)))
    P[j] <- 1 / sum(abs(Conj(t(En)) %*% a)^2)
  }
  return(P)
}

# 参数设置
M <- 200          # 子阵列长度，影响分辨率
K <- 3            # 信号数（三个周期）
f_grid <- seq(0.001, 0.1, length.out = 2000)  # 频率网格（周期/月）

# 计算 MUSIC 谱
P_music <- music_spectrum(y_detrend, M, K, f_grid)
period_grid <- 1 / f_grid

# 绘制 MUSIC 谱
plot(period_grid, P_music, type = "l", log = "x",
     xlab = "周期（月）", ylab = "MUSIC 谱",
     main = "MUSIC 共同周期估计")
abline(v = c(42, 100, 200), col = "red", lty = 2)

# 寻找峰值对应的周期
peaks <- which(diff(sign(diff(P_music))) == -2) + 1
peak_periods <- period_grid[peaks]
peak_values <- P_music[peaks]

# 按谱值排序，取前 5 个
top_idx <- order(peak_values, decreasing = TRUE)[1:5]
cat("MUSIC 检测到的主要周期（月）：\n")
print(round(peak_periods[top_idx], 2))

# 频域高斯滤波器
gaussian_filter <- function(x, f0, sigma) {
  n <- length(x)
  X <- fft(x)
  freqs <- (0:(n - 1)) / n
  # 将频率映射到 [-0.5, 0.5)
  freqs <- ifelse(freqs > 0.5, freqs - 1, freqs)
  # 高斯窗（正负频率对称）
  H <- exp(-(freqs - f0)^2 / (2 * sigma^2)) +  exp(-(freqs + f0)^2 / (2 * sigma^2))
  X_filt <- X * H
  x_filt <- Re(fft(X_filt, inverse = TRUE) / n)
  return(x_filt)
}

五、总结和结论

周期理论为理解宏观经济和金融市场提供了重要框架。周期理论从康德拉季耶夫的长期波动，到库兹涅茨的房地产周期，到朱格拉的设备投资周期，再到基钦的库存周期，构成了一个多层嵌套的时间结构。

霍华德·马克斯则把周期从宏观延伸到信贷、债务、盈利和市场心理，强调情绪摆钟在极端之间摆动，股票市场常态其实是非常态。信贷周期、债务周期和情绪周期分别从金融条件、资产负债表和市场心理三个维度补充了周期理论。

现代量化工具，如傅里叶变换、小波分析、机器学习、高频数据，为周期识别、降噪、状态感知和动态风控提供了新的技术路径。

投资实践中，最重要的不是精确预测下一个拐点，而是建立一套周期仪表盘：同时跟踪康波、库兹涅茨、朱格拉、基钦的位置；监测估值、恐贪情绪、信贷和流动性；使用频域分解提取主导周期；使用状态感知模型识别市场状态；使用压力测试和动态风控锁定尾部风险。

只有这样，才能在周期共振时放大收益，在周期断裂时控制回撤，在情绪极端时保持理性。周期不是必然，而是概率；不是机械规律，而是复杂适应系统的涌现模式。理解周期，就是理解市场如何在贪婪与恐惧、扩张与收缩、创新与毁灭之间不断重演，却又从不简单重复。
