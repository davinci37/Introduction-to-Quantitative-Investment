第16章 R 第7节 机器学习

前言

R语言的机器学习生态非常繁荣，拥有大量高质量的包。这些包大致可以分为提供统一工作流的框架和实现特定算法的专用包两大类。

1.统一模型框架

这类包提供了一站式的解决方案，帮助你规范、高效地管理从数据预处理到模型部署的整个机器学习流程。

  • tidymodels：这是R中现代机器学习的首选框架。它基于tidyverse的设计理念，将所有建模步骤整合成一个连贯、易于理解的管道。它的核心包各司其职：

    • rsample：负责数据拆分和重采样。
    • recipes：提供了一套用于特征工程的“配方”。
    • parsnip：为不同算法提供统一的接口，让你无需记忆每个包的具体语法。
    • workflows：将“配方”和“模型”捆绑在一起，方便管理。
    • tune & dials：用于超参数调优。
    • yardstick：用于模型性能评估。
    • broom：将模型输出整理成整洁的数据框。

  • mlr3：一个面向对象、可扩展性极强的机器学习框架。它是mlr包的升级版，专为处理大规模数据和复杂任务而设计。mlr3本身是一个轻量级核心，其强大功能通过庞大的扩展包生态系统（如mlr3learners, mlr3pipelines, mlr3proba等）实现。

  • caret (Classification And REgression Training)：一个老牌且经典的整合包，曾是该领域的标杆。它同样提供了统一的训练、调参和评估接口，集成了上百种算法。虽然tidymodels被视为它的进化版，但caret依然被广泛使用。

实践建议：如果你是初学者或希望快速上手，tidymodels 是当前最推荐的选择，其设计现代且文档完善。如果需要高度定制化的工作流或处理极大规模的数据，mlr3 强大的扩展性会更具优势。而caret 则适合维护现有项目或偏好其经典风格的用户。

2.专用算法包

除了框架，R还有大量实现特定算法的专用包。以下是一些核心代表：

算法类别 核心包 用途与特点
线性模型与正则化 glmnet 实现Lasso、Ridge和弹性网（Elastic Net）正则化，非常高效。
树模型与随机森林 rpart 实现CART决策树，是R的基础包之一。
randomForest 经典、易用的随机森林算法实现。
ranger 高性能的随机森林实现，速度更快，内存效率更高，常作为tidymodels的“引擎”。
xgboost / lightgbm 梯度提升算法（GBDT）的标杆，在竞赛和工业界广泛应用，效率极高。
支持向量机 (SVM) e1071 提供SVM以及Naive Bayes等其他经典算法。
kernlab 基于核函数的机器学习方法，包括SVM、PCA等。
神经网络与深度学习 nnet 实现单隐层前馈神经网络，是R的基础包之一。
keras / tensorflow 提供R语言接口，对接业界流行的Python深度学习框架。
torch 提供对PyTorch底层库libtorch的R接口，实现原生深度学习。
h2o 提供可扩展的、分布式的机器学习算法，包括深度学习。

3.总结与建议

R的机器学习生态强大且选择多样，你可以这样入手：

  1. 明确目标：确定你的任务（分类、回归等）和偏好（如是否需要统一工作流）。
  2. 选择框架：对于新项目，建议从 tidymodels 开始。如果项目复杂或需要高度定制，可探索 mlr3。
  3. 按需补充：对于指定的模型框架，可直接引入 ranger、xgboost、glmnet 等专用包即可。

一、rpart包

1.概述

rpart（Recursive PARTitioning）是R语言中实现递归 partitioning 回归树和分类树的核心包。它实现了1984年Breiman等人所著《Classification and Regression Trees》（CART）一书中的大部分功能。因为”CART”是特定软件商标，且Splus中已有tree函数，故取名rpart。rpart是R的推荐包（recommended package），随R一同安装。

2.核心功能

rpart可构建三种类型的树模型：

模型类型 说明 method参数
分类树 响应变量为因子（分类变量） "class"
回归树 响应变量为连续数值变量 "anova"
生存树 响应变量为生存对象 "exp"

3.核心函数：rpart()

3.1.基本语法

rpart(formula, data, weights, subset, na.action = na.rpart,
      method, model = FALSE, x = FALSE, y = TRUE,
      parms, control, cost, ...)

3.2.主要参数

参数 说明
formula 模型公式，如 y ~ x1 + x2，不含交互项
data 数据框
method 指定模型类型："anova"（回归）、"class"（分类）、"poisson"、"exp"（生存）。若不指定，程序会根据响应变量类型自动推断
weights 可选的大小写权重
subset 选择数据子集进行拟合
na.action 默认 na.rpart：删除响应变量y缺失的观测，但保留预测变量缺失的观测
parms 分裂函数的可选参数
control 控制算法细节的选项列表
cost 每个变量的非负成本向量，默认全为1，用于调整变量被选为分裂变量的优先级

3.3.parms参数详解（分类树）

对于分类树，parms可包含以下组件：

  • prior：先验概率向量，须为正且总和为1，默认与数据计数成比例
  • loss：损失矩阵，对角线为0，非对角线为正
  • split：分裂指标，可选 "gini"（默认）或 "information"（信息增益）
rpart(Species ~ ., data = iris,
      parms = list(prior = c(0.3, 0.3, 0.4), split = "information"))

3.4.控制参数：rpart.control()

通过control参数可以精细控制树的生长过程：

rpart.control(minsplit = 20, minbucket = round(minsplit/3),
              cp = 0.01, maxcompete = 4, maxsurrogate = 5,
              usesurrogate = 2, xval = 10,
              surrogatestyle = 0, maxdepth = 30)
参数 默认值 说明
minsplit 20 节点中最少观测数，小于此值不再尝试分裂
minbucket minsplit/3 任一叶子节点的最少观测数
cp（复杂度参数） 0.01 分裂必须使整体不拟合度下降至少cp倍，否则不尝试。主要作用是节省计算时间
maxdepth 30 树的最大深度（根节点为0）
xval 10 交叉验证折数
maxcompete 4 保留的竞争分裂数量
maxsurrogate 5 保留的代理分裂数量
usesurrogate 2 如何处理缺失值：0=不用代理变量；1=按顺序使用代理变量；2=代理变量全缺失时送往多数方向

4.完整使用示例

library(rpart)


#分类树（以`iris`数据集为例）


# 拟合分类树
fit <- rpart(Species ~ ., data = iris, method = "class")


# 查看模型摘要
summary(fit)


# 预测
predict(fit, newdata = iris[1:5, ], type = "class")


# 回归树（以`car.test.frame`数据集为例）


# 拟合回归树
z.auto <- rpart(Mileage ~ Weight, data = car.test.frame)
summary(z.auto)


# 自定义控制参数


# 限制树深度、提高分裂门槛
fit <- rpart(Kyphosis ~ Age + Number + Start, data = kyphosis,
             control = rpart.control(cp = 0.05, maxdepth = 4))


# 树的可视化


# 基础绘图


plot(fit)
text(fit, use.n = TRUE)


# 增强可视化（推荐`rpart.plot`包）


library(rpart.plot)
rpart.plot(fit)


# rpart.plot`包提供更美观、信息更丰富的决策树可视化。

5.输出对象

rpart()返回一个rpart类的对象，包含：

  • frame：树的框架信息（每个节点的分裂变量、样本数、预测值等）
  • where：每个观测所属的叶子节点编号
  • cptable：复杂度参数表，用于选择合适的剪枝程度
  • splits：分裂信息（含竞争分裂和代理分裂）

可通过summary()、print()、predict()等泛型函数查看和操作。

6.注意事项

  1. 缺失值处理：rpart通过代理分裂（surrogate splits） 优雅地处理预测变量缺失，这是它与早期tree函数的主要区别。usesurrogate=2是Breiman等人推荐的设置。

  2. 过拟合控制：通过cp参数进行预剪枝，或使用printcp()查看复杂度参数表后进行后剪枝（prune()函数）。

  3. 变量重要性：可通过fit$variable.importance查看各变量对模型的重要性。

  4. 用户自定义分裂函数：method参数可传入包含init、split和eval函数的列表，实现自定义分裂准则。

二、Random Forest包

1.概述

randomForest包是R语言中实现随机森林（Random Forest） 算法的核心工具包。它基于Leo Breiman和Adele Cutler的原始Fortran代码实现，由Andy Liaw和Matthew Wiener移植到R语言。

随机森林是一种强大的集成学习方法，通过构建大量决策树并集成其结果，显著提高模型的准确性和鲁棒性。

2.核心功能

randomForest包可构建以下类型的模型：

模型类型 说明 判定方式
分类森林 响应变量为因子 y为factor类型时自动选择
回归森林 响应变量为连续数值 y为数值型时自动选择
无监督模式 仅使用预测变量，不提供响应变量 y参数省略时进入该模式

3.核心函数：randomForest()

3.1.两种调用方式

# 公式（Formula）接口
randomForest(formula, data=NULL, ..., subset, na.action=na.fail)


# 默认（Default）接口
randomForest(x, y=NULL, xtest=NULL, ytest=NULL, ...)

3.2.主要参数详解

参数 说明
x / formula 预测变量，可为数据框、矩阵或公式
y 响应向量。若为factor则执行分类，否则执行回归；若省略则进入无监督模式
xtest / ytest 可选的测试集预测变量和响应变量
ntree 树的数量，默认500。不宜过小，应确保每行数据都被预测若干次
mtry 每棵树的每个节点随机采样的候选变量数，最关键的超参数之一。分类默认sqrt(p)，回归默认p/3（p为变量总数）
replace 是否有放回抽样，默认TRUE（即Bootstrap抽样）
sampsize 每棵树抽取的样本量。若有放回则默认nrow(x)，无放回则默认ceiling(0.632 * nrow(x))
nodesize 终端节点（叶子）的最小样本量。分类默认1，回归默认5。设得越大，树越小、训练越快
maxnodes 每棵树的最大终端节点数。不指定则生长到最大可能
importance 是否计算变量重要性，默认FALSE
localImp 是否计算每个样本的局部变量重要性，默认FALSE
proximity 是否计算样本间的邻近矩阵，默认FALSE
keep.forest 是否保留森林结构（用于后续预测），若有y且无xtest则默认TRUE

3.3.分类模型特有参数

参数 说明
classwt 类别的先验权重，不需要总和为1，回归中忽略
cutoff 分类决策阈值。每个类别的默认值为1/k（k为类别数），即多数投票获胜
strata 用于分层抽样的因子变量

3.4.模型输出与诊断

randomForest()返回一个randomForest类的对象，包含以下主要组件：

组件 说明
type 模型类型："classification"或"regression"
ntree 实际生长的树的数量
mtry 每次分裂的候选变量数
votes （分类）每棵树的投票结果
predicted 训练集的预测值
err.rate （分类）各类别及整体的袋外（OOB）错误率
mse （回归）袋外均方误差
rsq （回归）袋外R²
importance 变量重要性矩阵（需设置importance=TRUE）
proximity 邻近矩阵（需设置proximity=TRUE）

4.实用辅助函数

函数 功能
importance() 提取变量重要性
varImpPlot() 绘制变量重要性图
getTree() 提取森林中某一棵树的结构
combine() 合并多个随机森林模型
classCenter() 基于邻近矩阵计算各类别的原型（prototype） 样本
MDSplot() 基于邻近矩阵进行多维缩放（MDS）可视化
rfcv() 递归特征消除交叉验证，用于变量筛选

5.使用示例

5.1.分类（以iris数据集为例）

library(randomForest)


# 设置随机种子以确保结果可复现
set.seed(71)


# 训练随机森林分类模型
iris.rf <- randomForest(Species ~ .,
                        data = iris,
                        importance = TRUE,
                        proximity = TRUE)


# 查看模型摘要
print(iris.rf)
# 输出：Type of random forest: classification
#       Number of trees: 500
#       No. of variables tried at each split: 2
#       OOB estimate of error rate: 4%
#       Confusion matrix: ...


# 查看变量重要性
importance(iris.rf)


# 绘制变量重要性
varImpPlot(iris.rf)


# 预测新数据
predict(iris.rf, newdata = iris[1:5, ])

5.2.回归示例

# 使用mtcars数据集进行回归
set.seed(123)
rf_reg <- randomForest(mpg ~ .,
                       data = mtcars,
                       ntree = 300,
                       importance = TRUE)


# 查看回归结果
print(rf_reg)
# 输出：Type of random forest: regression
#       Number of trees: 300
#       No. of variables tried at each split: 3
#       Mean of squared residuals: ...
#       % Var explained: ...

5.3.无监督模式

# 仅使用预测变量，不指定响应变量
unsup.rf <- randomForest(iris[, -5],
                         ntree = 100,
                         proximity = TRUE)


# 使用邻近矩阵进行聚类可视化
MDSplot(unsup.rf, iris$Species)

6.注意事项与技巧

  1. 随机种子：随机森林具有随机性，建议使用set.seed()确保结果可复现。

  2. mtry调优：mtry是最关键的超参数。可通过遍历不同值，选择OOB误差最小的mtry。

  3. ntree选择：一般500棵已足够，可观察OOB误差随树数量增加是否收敛来判断。

  4. 类别不平衡：可通过sampsize进行分层抽样，或通过classwt和cutoff调整先验权重和决策阈值。

  5. 缺失值处理：na.action默认为na.fail（遇缺失值报错）。随机森林可通过na.roughfix或rfImpute函数处理缺失值。

  6. 计算效率：nodesize设大可以加速训练（树更小）；maxnodes也可控制树的大小。

  7. 过拟合：随机森林通常不易过拟合，增加ntree不会导致过拟合。

三、ranger

1.概述

ranger是R语言中随机森林算法的一个高速实现包。其名称取自”random fogererator”的缩写。与经典的randomForest包相比，ranger最突出的优势是计算速度快和内存效率高，尤其适合处理高维数据。

ranger的核心由C++ 编写，并通过Rcpp包与R语言对接，这使得它在处理大规模数据时性能远超许多同类包。该包由Marvin N. Wright和Andreas Ziegler开发，其方法论文章发表于《Journal of Statistical Software》。

2.核心特点

  • 速度快、内存效率高：通过大量的运行时间和内存分析进行了优化。相较于randomForest，ranger通常要快数倍甚至更多。

  • 支持高维数据：特别适合处理变量数远超样本数的场景，如全基因组关联研究（GWAS）数据。

  • 多线程支持：默认使用2个线程，用户可指定使用的核心数。

  • 多种森林类型：支持分类、回归、生存分析、概率预测等多种森林。

  • 多种输入格式：除常规数据框外，还支持matrix、dgCMatrix（Matrix包）和gwaa.data（GenABEL包）等格式。

五、lightgbm

1.概述

lightgbm（Light Gradient Boosting Machine）是R语言中实现轻量级梯度提升机算法的核心包。它基于Ke等人2017年发表于NIPS的论文《LightGBM: A Highly Efficient Gradient Boosting Decision Tree》，由微软团队开发并开源。

LightGBM是梯度提升决策树（GBDT） 框架的高效实现，在训练速度、内存占用和准确性方面相比传统实现有显著提升。因其卓越性能，已被广泛应用于众多机器学习竞赛的获胜方案中。其核心为C++库，R包提供了与之交互的接口。

2.核心特点

特点 说明
训练速度极快 基于直方图算法（Histogram-based）和单边梯度采样（GOSS） 技术
内存占用低 直方图算法将连续特征离散化为整数，大幅降低内存消耗
Leaf-wise树生长 采用按叶子生长（best-first）策略，相比传统的按层生长（level-wise）能更快收敛
原生支持类别特征 可直接处理factor类型特征，无需手动独热编码

缺失值自动处理 自动学习缺失值的最优分裂方向
早停机制 支持基于验证集表现的早停，防止过拟合并节省时间

Leaf-wise vs Level-wise：传统GBDT（如XGBoost默认）按层生长，同一层所有节点分裂后再进入下一层。LightGBM按叶子生长，每次选择增益最大的叶子进行分裂，收敛更快，但可能长出较深的树，需通过max_depth限制。

LightGBM vs XGBoost 关键差异

  • 树生长策略：LightGBM的leaf-wise策略收敛更快，但在小数据集上可能过拟合，需用max_depth或num_leaves限制。

  • 直方图算法：LightGBM默认使用直方图算法加速分裂；XGBoost也支持该选项（tree_method='hist'）。

  • 类别特征：LightGBM原生支持类别特征，XGBoost需要手动编码（如One-Hot或目标编码）。

  • 速度与内存：LightGBM在相同硬件上通常更快、内存占用更少，尤其在大数据集上优势明显。

8.注意事项与技巧

  • num_leaves是关键超参数：它是控制模型复杂度最重要的参数，通常应小于2^(max_depth)。

  • 小数据集慎用leaf-wise：在小数据集上，leaf-wise可能过拟合，建议配合max_depth限制或改用xgboost。

  • 类别特征需显式声明：LightGBM虽然支持类别特征，但必须通过categorical_feature参数明确指定。

  • 早停与验证集：使用lgb.train()时，通过valids参数传入验证集，并设置early_stopping_rounds可有效防止过拟合。

  • 多线程设置：可通过num_threads参数控制使用的CPU核心数。

  • 模型序列化：serializable = TRUE（默认）可使模型可通过saveRDS()保存。

    • formula或x, y：指定模型公式或自变量与因变量。
    • data：数据源。
    • type：指定SVM类型，如C-classification（分类）、eps-regression（回归）、one-classification（异常检测）。
    • kernel：核函数，常用选项有linear（线性）、polynomial（多项式）、radial（径向基/RBF，默认）、sigmoid。
    • cost：惩罚参数，控制对误分类的容忍度，是SVM最重要的调优参数之一。
    • gamma：RBF、多项式及sigmoid核的参数，决定单个训练样本的影响范围。
  • 使用示例（分类）：
library(e1071)
# 使用鸢尾花数据集训练SVM分类器
model <- svm(Species ~ ., data = iris, kernel = "radial", cost = 10, gamma = 0.1)
# 查看模型摘要
summary(model)
# 进行预测
pred <- predict(model, iris)
# 查看混淆矩阵
table(pred, iris$Species)

3.2. 朴素贝叶斯：naiveBayes()

一个简单但高效的分类器，基于贝叶斯定理并假设特征之间相互独立。

  • 核心参数：
    • formula或x, y：指定模型。
    • data：数据源。
    • laplace：拉普拉斯平滑参数，默认为0，用于处理零概率问题。
  • 使用示例：
library(e1071)
# 训练朴素贝叶斯模型
model <- naiveBayes(Species ~ ., data = iris)
# 进行预测
pred <- predict(model, iris)
table(pred, iris$Species)

3.3. 模型调优：tune()

提供了一种简便的方法，通过网格搜索和交叉验证来寻找模型的最佳超参数。

  • 核心参数：
    • method：要调优的函数，如svm、randomForest等。
    • train.x和train.y：训练数据。
    • ranges：一个列表，指定各参数的取值范围内核。
    • tunecontrol：控制调优过程的参数，如交叉验证折数。
  • 使用示例（为SVM调参）：
library(e1071)
# 为svm函数调优，寻找最佳的cost和gamma值
tuned <- tune(svm, Species ~ ., data = iris,
               ranges = list(cost = c(0.1, 1, 10), gamma = c(0.01, 0.1, 1)))
# 查看调优结果
summary(tuned)
# 获取最佳模型
best.model <- tuned$best.model

  • 依赖关系：e1071主要依赖于R基础包（如stats、graphics）以及class和proxy包。它建议（Suggests）但不强制依赖cluster、mlbench、randomForest、rpart等包，以支持其tune()等功能。

  • 应用领域：由于其功能广泛，e1071在多个领域都有应用，并被收录在CRAN的机器学习、聚类、心理测量学等多个官方任务视图中。

5.注意事项

  • SVM的预处理：svm()函数默认会对数据进行缩放（scale），这通常是必要的，可以防止数值范围大的变量主导模型。如果不需要，可以通过设置参数scale = FALSE来关闭。

  • 调参的重要性：SVM（svm()）的性能高度依赖于超参数（如cost和gamma）的选择。建议在实际应用中，务必使用tune()函数进行系统性的参数搜索，而不是使用默认值。

  • 版本更新：该包维护活跃，最近一次更新为2025年12月18日。使用时请确保安装最新版本以获得最佳性能和bug修复。

八、tidymodels包生态

1.概述

tidymodels 不是一个单一的R包，而是一个用于建模和机器学习的R包生态系统。它是一个 “元包”（meta-package） ，其设计哲学、语法和数据结构与广为人知的 tidyverse 一脉相承。

tidymodels 项目的目标是为R中的统计和机器学习建模提供一个统一、规范且高效的框架。你可以将它看作是R语言中 scikit-learn 在Python中的对应物。

2.核心设计理念

  1. 一致性：无论是线性回归还是随机森林，整个工作流程（数据划分、预处理、建模、评估）都使用统一、可预测的函数和语法。
  2. 模块化：每个核心功能都由专门的包负责，例如，rsample负责数据拆分，recipes负责特征工程，parsnip负责统一模型接口。这种设计使得代码更清晰、更易于维护和扩展。
  3. 整洁数据（Tidy Data）原则：所有函数的输入和输出都尽量设计为整洁的数据框（tibble）格式，方便与 tidyverse 系列包（如 dplyr、ggplot2）无缝衔接。

3.核心包详解

当你运行 library(tidymodels) 时，它会自动加载一组核心包。这些包构成了建模工作流的基础工具。

包名 功能 核心作用
rsample 数据拆分与重抽样 提供将数据划分为训练集、测试集的方法，以及交叉验证、自助法（Bootstrap）等重抽样工具，用于模型的可靠评估。
recipes 数据预处理与特征工程 提供了一个现代、管道式（pipeable）的API来构建预处理步骤。可以一站式完成缺失值插补、变量编码、特征缩放、创建交互项等任务。
parsnip 统一的模型接口 这是 tidymodels 的核心。它让你用一套统一的语法（如 linear_reg()、rand_forest()）来定义模型，而无需记忆不同R包（如 rpart、randomForest、e1071）的具体函数名和参数，模型的具体实现由“引擎”（engine）参数指定。
workflows 工作流编排 将“数据预处理（recipes）”和“模型定义（parsnip）”绑定成一个整体对象。这确保了在训练、预测或调参时，所有步骤都按正确顺序自动执行。
tune 超参数调优 提供系统性的方法来调整模型和预处理步骤中的超参数（如随机森林的 mtry 或 trees）。
yardstick 模型性能评估 提供了一套全面的、易于使用的指标来计算模型性能，如分类问题的 accuracy、roc_auc，回归问题的 rmse、rsq 等。
broom 结果整理 将R中许多统计函数（如 lm()、t.test()）混乱的输出结果，整理成整洁、结构化的 tibble 数据框。
dials 调参参数管理 用于创建和管理调参时所需的参数集和参数网格，与 tune 包协同工作。

4.典型 tidymodels 工作流

与 caret 的单一函数 train() 不同，tidymodels 鼓励通过组合不同的核心包来构建一个清晰、可复现的建模流水线。

4.1.数据拆分 (rsample):

library(tidymodels)
data("mtcars")
set.seed(123)
# 将数据拆分为训练集 (75%) 和测试集 (25%)
car_split <- initial_split(mtcars, prop = 0.75, strata = mpg)
car_train <- training(car_split)
car_test  <- testing(car_split)

4.2.特征工程 (recipes):

# 定义一个预处理配方：将所有预测变量标准化
car_recipe <- recipe(mpg ~ ., data = car_train) %>%
    step_normalize(all_predictors())

4.3.模型定义 (parsnip):

# 指定一个随机森林模型，并设置其引擎为 'ranger'
rf_model <- rand_forest(mtry = 5, trees = 500) %>%
    set_engine("ranger") %>%
    set_mode("regression")

4.4.创建工作流 (workflows):

# 将预处理和模型绑定在一起
rf_workflow <- workflow() %>%
    add_recipe(car_recipe) %>%
    add_model(rf_model)

4.5.训练模型 (fit):

# 在工作流上调用 fit()，它会自动按顺序执行预处理和模型训练
rf_fit <- rf_workflow %>% fit(data = car_train)

4.6.评估模型 (yardstick):

# 对测试集进行预测
predictions <- rf_fit %>% predict(car_test)
# 将预测值与真实值绑定，并计算RMSE
car_results <- car_test %>%
    select(mpg) %>%
    bind_cols(predictions)
car_results %>% rmse(truth = mpg, estimate = .pred)

除了核心包，tidymodels 生态系统还包含大量专门包，用于处理特定任务：

  • 预处理扩展: textrecipes (处理文本数据), embed (处理高维分类变量), themis (处理类别不平衡数据)。
  • 模型扩展: bonsai (提供LightGBM等树模型引擎), discrim (判别分析模型), censored (生存分析模型)。
  • 后处理: probably (用于调整分类阈值)。
  • 与其他框架集成: agua 包提供了与 h2o 的接口。

九、mlr3

mlr3是R语言中一个现代、面向对象且高效的机器学习框架。它是经典mlr包的重写版本，旨在提供一个统一、可扩展且高效的机器学习工作平台。

mlr3本身是一个基础包，提供了机器学习最核心的“乐高积木”。其强大的功能通过一个庞大的扩展包生态系统来实现，你可以根据需要灵活组装。

1.核心设计理念

  • 面向对象：基于R6类构建，所有核心组件（如任务、学习器）都是可交互、可修改的R6对象。
  • 统一接口：为数据预处理、模型训练、评估等提供一致的语法，降低了在不同算法间切换的学习成本。
  • 模块化与可扩展：采用“乐高”式设计，核心简洁，功能通过扩展包按需添加，且支持自定义组件。
  • 高性能与可扩展性：原生支持并行计算，并支持数据库等“out-of-memory”数据后端，能处理超大数据集。

2.核心组件

  • Task（任务）：封装了数据和要解决的问题（如分类、回归），是分析的起点。
  • Learner（学习器）：代表一个机器学习算法，如决策树、随机森林等。
  • Resampling（重抽样）：定义如何划分数据，如交叉验证、自助法，用于模型评估。
  • Measure（度量）：定义模型性能的评估指标，如准确率、均方误差（MSE）。
  • Benchmark（基准测试）：提供统一框架，用于在不同任务上比较多个学习器的性能。

3.丰富的扩展生态系统

mlr3的强大之处在于其生态系统。以下是一些核心扩展包：

3.1.核心增强

  • mlr3verse：元包，一键安装和加载最重要的扩展包。
  • mlr3pipelines：创建复杂的机器学习流水线（PipeOps），组合预处理、建模等步骤。

3.2.学习器（算法）

  • mlr3learners：官方维护的核心算法集合。
  • mlr3extralearners：社区贡献的更多算法。
  • mlr3torch：基于torch的深度学习支持。

3.3.调参与优化

  • mlr3tuning：超参数调优。
  • mlr3hyperband、mlr3mbo：先进的调参策略。
  • mlr3automl：自动化机器学习。

3.4.特殊任务与数据类型

  • mlr3proba：生存分析与概率预测。
  • mlr3cluster：聚类分析。
  • mlr3spatiotempcv：时空数据重抽样。
  • mlr3fda：函数型数据分析。

4.基本工作流程

一个典型的 mlr3 工作流通常遵循 任务 (Task) -> 学习器 (Learner) -> 重抽样 (Resampling) -> 评估 (Evaluation) 的模式。后文提供一个从基础到进阶的完整案例，展示如何用 mlr3 解决一个分类问题。

4.1. 案例1：训练与评估一个模型

以经典的 iris（鸢尾花）数据集为例，训练一个决策树模型，并用交叉验证评估其性能。

# 安装 mlr3verse，它会自动安装 mlr3, mlr3learners, mlr3tuning 等核心包
# install.packages("mlr3verse")


# 加载 mlr3verse
library(mlr3verse)


# 1. 创建任务 (Task)


# tsk() 函数用于加载 mlr3 内置的数据集，并封装为一个分类任务。
# 从 mlr3 的内置任务字典中加载鸢尾花数据集。
task = tsk("iris")
print(task)
# > <TaskClassif:iris> (153 x 5)


# 2. 选择学习器 (Learner)


# lrn() 函数用于创建一个学习器对象。
# "classif.rpart" 表示用于分类的决策树
# 从学习器字典中选择一个分类决策树。
# predict_type = "prob" 可输出概率
learner = lrn("classif.rpart", predict_type = "prob")


# 3. 定义重抽样策略 (Resampling)


# rsmp() 函数定义重抽样方法。"cv" 代表交叉验证，folds = 5 表示5折
resampling = rsmp("cv", folds = 5)


# 4. 执行重抽样评估 (Resample)


# resample() 函数会将前面定义的 task, learner, resampling 组合起来执行评估
# 执行重抽样，它会自动进行5次训练和预测。
rr = resample(task, learner, resampling)


# 5. 查看评估结果
# 计算所有折叠的平均分类准确率
measure = msr("classif.acc") # msr() 用于选择评估指标


# 从重抽样结果对象 rr 中汇总（平均）出准确率这一指标。
rr$aggregate(measure)
#> classif.acc
#>        0.94

4.2. 案例2：基准测试 (Benchmarking) 比较多个模型

mlr3 的 benchmark() 函数提供了一个统一的框架，可以公平地比较多个学习器在同一个任务上的表现。

# 1. 准备多个学习器


learners = list(
  lrn("classif.rpart", id = "CART"),              # 决策树，并赋予ID
  lrn("classif.ranger", id = "RandomForest")      # 随机森林
)


# 2. 创建基准测试设计 (Benchmark Design)
# 定义要比较的实验组合：一个任务，两个学习器，一种重抽样方法


design = benchmark_grid(
  tasks = task,          # 任务
  learners = learners,   # 学习器列表
  resamplings = resampling # 重抽样策略
)


# 3. 执行基准测试
# 接收这个设计并执行所有实验。
bmr = benchmark(design)


# 4. 查看和比较结果
# 汇总所有学习器的平均性能
# 可以方便地汇总和对比不同模型的性能指标。
bmr$aggregate(msrs(c("classif.acc", "classif.auc"))) # 同时计算准确率和AUC
#>    nr   task_id      learner_id resampling_id iters classif.acc classif.auc
#> 1:  1     iris           CART            cv     5       0.9400      0.9736
#> 2:  2     iris RandomForest            cv     5       0.9533      0.9936

4.3. 案例3：超参数调优 (Hyperparameter Tuning)

使用 mlr3tuning 包，可以自动搜索模型的最佳超参数。

# 加载调优相关的包 (如果之前加载了 mlr3verse，则已包含)
# library(mlr3tuning)


# 1. 定义需要调优的学习器，并设置超参数搜索空间
# 我们对随机森林的 mtry 和 num.trees 进行调优
# to_tune()：标记哪些超参数需要被优化，并指定其搜索范围。
learner_tuned = lrn(
  "classif.ranger",
  predict_type = "prob",
  # to_tune() 函数定义了超参数的搜索范围
  mtry = to_tune(lower = 1, upper = 4),     # 整数，范围1到4
  num.trees = to_tune(lower = 100, upper = 500) # 整数，范围100到500
)


# 2. 创建调优实例 (Tuning Instance)
# 定义调优的目标：使用3折交叉验证，优化分类误差（classif.ce），并设置随机搜索终止条件.
# tune()：执行超参数调优过程。
instance = tune(
  method = "random_search", # 调优方法
  task = task,
  learner = learner_tuned,
  resampling = rsmp("cv", folds = 3),
  measures = msr("classif.ce"),
  term_evals = 10 # 终止条件：尝试10组超参数组合
)


# 3. 查看调优结果
# 打印出最佳性能对应的超参数组合
# instance$result：存储了调优过程中找到的最佳超参数配置及其对应的性能。
print(instance$result)
#>    mtry num.trees learner_param_vals  classif.ce
#> 1:    2       348           <list[2]> 0.04666667


# 4. 将调优后的学习器应用于全数据并评估
# 从调优结果中提取最佳超参数配置的学习器
# 可以直接用于后续的预测或评估。
learner_optimized = instance$result_learner


# 使用5折交叉验证评估这个优化后的学习器
rr_optimized = resample(task, learner_optimized, rsmp("cv", folds = 5))
rr_optimized$aggregate(msr("classif.acc"))
#> classif.acc
#>        0.96
