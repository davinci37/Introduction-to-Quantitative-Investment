第16章 R 第10节 优化算法

前言

在量化投资领域，R语言提供了非常丰富的优化求解包生态，它们各有侧重，可以从不同的角度解决投资组合构建中的核心问题。我将这些包按照其核心功能和应用场景进行了分类介绍。

1.通用优化框架与基础设施

这类包提供了统一的接口或底层求解器，是构建复杂优化模型的基础。

  • CVXR：一个基于凸优化（Convex Optimization）的建模框架。它允许你用自然、数学化的语法描述优化问题，然后自动选择并调用后台的求解器（如 OSQP, ECOS, SCS 等）进行求解。它也支持 CPLEX, GUROBI, MOSEK 等商业求解器。
  • quadprog：一个专门用于二次规划（Quadratic Programming, QP）问题的经典求解器。它常用于求解最小方差组合等经典均值-方差优化问题。
  • Rglpk / lpSolve：专注于线性规划（Linear Programming, LP）和混合整数线性规划（MILP）问题的求解器。在量化投资中，常用于以CVaR（条件风险价值）为目标函数的优化问题。
  • alabama：通过增广拉格朗日自适应屏障算法，专门用于求解带有线性或非线性等式与不等式约束的复杂优化问题。
  • ROI (R Optimization Infrastructure)：这是一个优化问题的基础设施框架。它本身不求解问题，但为各类优化问题（如线性规划LP、二次规划QP等）提供了一个统一的接口。它通过加载不同的插件，我们可以无缝切换底层求解器。

2.专用投资组合优化包

这类包是专门为投资组合优化场景设计的，提供了从问题定义到求解的一站式解决方案。

  • PortfolioAnalytics：这是一个功能非常强大的投资组合优化包，旨在解决带有复杂约束和目标的现实世界问题。它支持多种优化方法：
    • 凸优化求解器：通过 ROI 接口调用 quadprog（QP）或 glpk（LP/MILP）。
    • 启发式/全局优化算法：集成了 DEoptim（差分进化）、pso（粒子群）、GenSA（广义模拟退火）等，用于处理非凸、不连续的复杂问题。
    • 随机搜索：通过生成大量随机组合来探索解空间。
  • fPortfolio：这是一个经典的、专注于投资组合优化的包，提供了丰富的均值-方差模型变体（如高效前沿、最大夏普比率、最小方差等）。
  • riskParityPortfolio 专门用于构建风险平价（Risk Parity）投资组合，可以让不同资产对组合的总风险贡献相等或按指定比例（即风险预算）分配。

3.遗传算法

  • genalg 提供了基于遗传算法（Genetic Algorithm, GA）的优化工具。在量化投资领域，genalg 可以作为一个强大的工具，用于处理那些传统优化方法难以解决的复杂、非凸问题。

  • gramEvol是一个R包，它通过语法进化（Grammatical Evolution）算法，在用户定义的上下文无关语法指导下生成R表达式种群，并对其进行进化优化，以自动发现能实现特定目标的程序。

4. 其他实用工具

  • stats (optim / optimize)：R的基础包中的通用优化函数。optim() 提供了如 Nelder-Mead、CG 等多种算法，可用于解决一些自定义的优化问题。
  • nloptr / optimx：提供了更丰富的非线性优化算法，适合处理更一般的非线性问题。

一、CVXR 包

1.概述

CVXR 是 R 语言中一个用于凸优化（Convex Optimization）的面向对象建模语言包。它提供了一个领域特定语言（DSL），允许用户以接近数学符号的自然语法来构建和求解凸优化问题，而无需将其转化为大多数求解器所要求的标准形式。CVXR 的设计理念与 Python 的 CVXPY、MATLAB 的 CVX 等工具一脉相承。其核心算法发表于 Fu, Narasimhan, and Boyd (2020) 的论文中。

2.核心特性

CVXR 的核心工作流程：

  1. 问题构建：用户通过组合常量（Constants）、变量（Variables）和参数（Parameters），并运用预定义的函数库来指定目标函数和约束条件。

  2. 凸性验证：CVXR 应用** disciplined convex programming (DCP)** 规则集来验证问题的凸性。

  3. 问题转换：验证通过后，CVXR 将问题转换为标准的锥形形式。

  4. 求解：最后，将转换后的问题传递给合适的底层求解器（Solver）以获得解决方案。

除了基础的凸优化（DCP），CVXR 还支持更广泛的数学规划问题：

  • DGP (Disciplined Geometric Programming)：几何规划。

  • DQCP (Disciplined Quasiconvex Programming)：拟凸规划。

  • DNLP (Disciplined Nonlinear Programming)：从 1.9.1 版本开始，CVXR 将建模能力扩展到了非凸的平滑非线性规划问题。

3.基本代码工作流程

  1. 加载包：library(CVXR)
  2. 定义变量：使用 Variable() 函数定义优化变量。
  3. 构建目标函数：使用 Minimize() 或 Maximize() 定义目标。
  4. 设置约束：使用列表 list() 包含所有约束条件。
  5. 创建问题对象：用 Problem() 函数组合目标和约束。
  6. 求解问题：使用 psolve() 函数求解。
  7. 提取结果：使用 value() 函数获取变量的最优值。

4.代码示例：最小二乘问题

library(CVXR)


# 1. 定义变量
betaHat <- Variable(10)


# 2. 构建目标函数 (最小化残差平方和)
objective <- Minimize(sum((Y - X %*% betaHat)^2))


# 3. 创建问题并求解
problem <- Problem(objective)
result <- psolve(problem)


# 4. 提取结果
optimal_value <- result
estimated_beta <- value(betaHat)

更复杂的带约束问题（如非负最小二乘）只需简单添加约束即可：

# 添加 beta >= 0 的约束
problem <- Problem(objective, constraints = list(betaHat >= 0))
result <- psolve(problem, solver = "CLARABEL")

5.支持的求解器

CVXR 本身不是一个求解器，而是一个建模框架，它支持多种后端求解器。CVXR 1.8.2 及以上版本共支持 15 种求解器，其中 4 个为内置。

求解器 R 包 支持问题类型
CLARABEL clarabel LP, QP, SOCP, SDP, EXP
SCS scs LP, QP, SOCP, SDP, EXP, MIP
OSQP osqp LP, QP
ECOS ECOSolveR LP, QP, SOCP, EXP
MOSEK Rmosek LP, QP, SOCP, SDP, EXP, MIP
GUROBI gurobi LP, QP, SOCP, MIP
HiGHS highs LP, QP, MIP
GLPK Rglpk LP, MIP
  • CLARABEL 是默认求解器，能处理最广泛的内置问题类型。
  • 用户可以通过 psolve(problem, solver = "SOLVER_NAME") 手动指定求解器。

二、quadprog 包

1.概述

quadprog 是 R 语言中用于求解二次规划（Quadratic Programming, QP） 问题的经典包。它由 Berwin A. Turlach 最初为 S 语言编写，后由 Andreas Weingessel 移植到 R。

该包的核心算法实现了 Goldfarb 和 Idnani（1982, 1983）提出的对偶方法（dual method），专门用于求解严格凸的二次规划问题。

2.核心函数

2.1. solve.QP() 主求解函数

这是 quadprog 包最核心的函数，用于求解如下形式的二次规划问题：

\[ \min \left(-d^T b + \frac{1}{2} b^T D b\right) \]

满足约束条件：

\[ A^T b \geq b_0 \]

其中前 meq 个约束为等式约束，其余为不等式约束。

函数形式：

solve.QP(Dmat, dvec, Amat, bvec, meq=0, factorized=FALSE)

参数说明：

参数 说明
Dmat 二次项矩阵（需为正定矩阵）
dvec 一次项系数向量
Amat 约束矩阵（每列对应一个约束）
bvec 约束右端向量
meq 前 meq 个约束为等式约束，默认为 0
factorized 若为 TRUE，则 Dmat 传入的是 \(R^{-1}\)（其中 \(D = R^T R\)）

返回值：

成分 说明
solution 最优解向量
value 目标函数在最优解处的值
unconstrained.solution 无约束最小化解
iterations 迭代次数（第一个为算法迭代数，第二个为约束失活次数）
Lagrangian 拉格朗日乘子
iact 活跃约束的索引

2. solve.QP.compact() 稀疏格式版本

当约束矩阵较为稀疏时，可使用此函数的紧凑格式来节省内存和提高效率。它采用 Aind 参数来指定非零元素的位置。

3.使用示例

3.1.示例 1：基本二次规划

求解最小化 \(\frac{1}{2}x^T x - (0, 5, 0) \cdot x\)，约束条件为 \(A^T x \geq b\)：

library(quadprog)


# 二次项矩阵 D (单位矩阵)
Dmat <- diag(1, 3)
# 一次项系数 d
dvec <- c(0, 5, 0)


# 约束矩阵 A (每列为一个约束): A^T b >= b0
Amat <- matrix(c(-4, -3, 0,    # 第一列
                  2,  1, 0,    # 第二列
                  0, -2, 1),   # 第三列
               nrow = 3, byrow = FALSE)


bvec <- c(-8, 2, 0)   # 约束右端


# 求解
sol <- solve.QP(Dmat, dvec, Amat, bvec)
print(sol$solution)

3.2.示例 2：带等式约束

在上述问题基础上增加等式约束 \(3x_1 + 2x_2 + x_3 = 1\)：

# 新增等式约束作为 Amat 的第一列，并设置 meq = 1
Amat_eq <- cbind(c(3, 2, 1), Amat)
bvec_eq <- c(1, bvec)


sol_eq <- solve.QP(Dmat, dvec, Amat_eq, bvec_eq, meq = 1)
print(sol_eq$solution)

3.3.示例 3：全局最小方差问题投资组合优化

这是 quadprog 最经典的应用场景之一：

library(quadprog)


# 假设有三只资产的收益率数据
returns <- matrix(rnorm(300, mean = 0.01, sd = 0.02), ncol = 3)
n <- ncol(returns)


# 协方差矩阵 (二次项)
Dmat <- cov(returns)
# 一次项系数 (最小方差组合中 dvec = 0)
dvec <- rep(0, n)


# 约束：权重之和为 1 (等式约束)
Amat <- matrix(rep(1, n), nrow = n)
bvec <- 1
meq <- 1


# 求解最小方差组合
sol <- solve.QP(Dmat, dvec, Amat, bvec, meq = 1)
weights <- sol$solution
print(weights)

如需添加权重下限（如不允许卖空，\(w_i \geq 0\)），只需在 Amat 中添加单位矩阵的列：

# 添加下限约束 w_i >= 0
Amat <- cbind(rep(1, n), diag(n))
bvec <- c(1, rep(0, n))
meq <- 1  # 只有第一个约束（和为1）是等式


sol <- solve.QP(Dmat, dvec, Amat, bvec, meq = 1)

4.注意事项

  • 默认求极小值：quadprog 默认求解极小值问题。若原问题是求极大值，需通过乘以负号转化为极小值问题。

  • 约束方向：约束形式固定为 \(A^T b \geq b_0\)。若原约束为 \(\leq\) 形式，需通过乘以 \(-1\) 转化。

  • 正定性要求：Dmat 必须为正定矩阵，否则算法可能失败。

三、Rglpk 包

1.概述

Rglpk 是 R 语言中一个用于求解线性规划（LP） 和混合整数线性规划（MILP） 问题的高性能工具包。它提供了对开源求解器 GLPK（GNU Linear Programming Kit）的 R 语言接口。

对于 R 语言用户而言，Rglpk 是解决线性规划和混合整数规划问题的首选工具之一。Rglpk 的优势在于：

  • 简单易用：核心函数只需 5-6 个参数即可完成模型定义

  • 功能强大：支持 LP、MILP 以及从多种标准格式读取模型

  • 高效可靠：基于成熟的 GLPK 开源求解器

  • 适合大规模问题：支持稀疏矩阵，内存效率高

2.核心功能

Rglpk 主要用于求解以下两类问题：

问题类型 说明
线性规划（LP） 所有决策变量均为连续实数
混合整数线性规划（MILP） 部分决策变量为整数，部分为连续实数（纯整数规划可视为其特例）

3.核心函数

Rglpk_solve_LP()是 Rglpk 最核心的求解函数，其语法如下：

Rglpk_solve_LP(obj, mat, dir, rhs, bounds = NULL, types = NULL,
               max = FALSE, control = list(), ...)

3.1.参数详解

参数 类型 说明
obj 数值向量 目标函数的系数
mat 矩阵或稀疏矩阵 约束条件的系数矩阵
dir 字符向量 约束方向，可取 "<", "<=", ">", ">=", "=="
rhs 数值向量 约束条件的右端项
bounds 列表 变量的上下界约束（默认每变量 ≥ 0）
types 字符向量 变量类型："B"（0-1 二进制）、"I"（整数）、"C"（连续）
max 逻辑值 TRUE 求最大值，FALSE（默认）求最小值
control 列表 求解器控制参数（详见下文）

3.2.控制参数（control 列表）

参数 说明
verbose TRUE 输出求解过程，FALSE（默认）静默运行
presolve TRUE 启用预求解器（默认 FALSE）
tm_limit 时间限制（毫秒），0 表示使用 GLPK 默认值
canonicalize_status TRUE（默认）将状态码标准化（成功返回 0）

3.3.返回值

组件 说明
solution 最优解向量
objval 目标函数最优值
status 状态码（0 表示求解成功）
solution_dual 对偶变量值（如有）
auxiliary 约束对应的辅助变量值

3.4.文件读取函数：Rglpk_read_file()

除了直接定义模型，Rglpk 还支持从标准格式文件中读取模型：

Rglpk_read_file(file, type = c("MPS_fixed", "MPS_free", "CPLEX_LP", "MathProg"),
                ignore_first_row = FALSE, verbose = FALSE)

支持的格式包括： - MPS（固定/自由格式） - CPLEX LP 格式 - GNU MathProg 格式（类似 AMPL 的建模语言）

读取后返回的对象可直接传入 Rglpk_solve_LP() 进行求解。

4.使用示例

4.1.示例 1：简单线性规划

最大化：2x₁ + 4x₂ + 3x₃
约束： - 3x₁ + 4x₂ + 2x₃ ≤ 60 - 2x₁ + x₂ + 2x₃ ≤ 40 - x₁ + 3x₂ + 2x₃ ≤ 80 - x₁, x₂, x₃ ≥ 0

library(Rglpk)


obj <- c(2, 4, 3)
mat <- matrix(c(3, 2, 1, 4, 1, 3, 2, 2, 2), nrow = 3, byrow = TRUE)
dir <- c("<=", "<=", "<=")
rhs <- c(60, 40, 80)
max <- TRUE


result <- Rglpk_solve_LP(obj, mat, dir, rhs, max = max)
print(result$solution)   # 最优解
print(result$objval)     # 最优值

4.2.示例 2：混合整数规划

如果要求 x₁ 和 x₃ 为整数，只需添加 types 参数：

types <- c("I", "C", "I")
result <- Rglpk_solve_LP(obj, mat, dir, rhs, types = types, max = TRUE)

4.3.示例 3：从文件读取模型

# 读取 CPLEX LP 格式文件
x <- Rglpk_read_file(
    system.file(file.path("examples", "plan.lp"), package = "Rglpk"),
    type = "CPLEX_LP"
)
# 直接求解
result <- Rglpk_solve_LP(x$objective, x$constraints[[1]],
                         x$constraints[[2]], x$constraints[[3]],
                         x$bounds, x$types, x$maximum)

5.注意事项

  • 严格不等式：GLPK 只支持非严格不等式（≤、≥），严格不等式（<、>）会被当作非严格不等式处理。

  • 变量默认边界：如果不指定 bounds，所有变量默认下界为 0、上界为无穷。

  • 稀疏矩阵支持：mat 和 obj 可以使用 slam 包提供的稀疏矩阵类型（simple_triplet_matrix），在处理大规模问题时能显著提升效率。

四、PortfolioAnalytics 包

1.概述

PortfolioAnalytics 是一个功能非常强大的投资组合优化包，旨在解决带有复杂约束和目标的现实世界问题。它支持多种优化方法：

  • 凸优化求解器：通过 ROI 接口调用 quadprog（QP）或 glpk（LP/MILP）。

  • 启发式/全局优化算法：集成了 DEoptim（差分进化）、pso（粒子群）、GenSA（广义模拟退火）等，用于处理非凸、不连续的复杂问题。

2.凸优化求解器 (Convex Optimization)

这类方法适合目标函数和约束条件都是凸函数的问题，能保证找到全局最优解，计算效率高。PortfolioAnalytics 通过 ROI（R Optimization Infrastructure）包来统一调用这些求解器。

求解器 问题类型 说明
quadprog 二次规划 (QP) 用于解决带有二次目标函数（如最小化方差）和线性约束的问题。
glpk 线性规划 (LP) / 混合整数线性规划 (MILP) 用于解决目标函数和约束都是线性的问题。

你可以通过 optimize_method 参数来指定使用哪种方法：

  • 自动选择：设置 optimize_method = "ROI"，包会根据问题类型自动选择 quadprog（QP）或 glpk（LP/MILP）。

  • 手动指定：也可以直接设置 optimize_method = "quadprog" 或 "glpk"。

需要注意的是，使用前需安装并加载对应的 ROI 插件包，例如 ROI.plugin.quadprog 和 ROI.plugin.glpk。

3.启发式/全局优化算法 (Heuristic/Global Optimization)

当问题非凸、不连续或存在非解析的复杂约束（如基数约束）时，传统凸优化方法失效。此时，PortfolioAnalytics 集成了多种随机全局优化算法，它们不依赖梯度信息，通过启发式搜索寻找近似最优解。

算法 核心思想 特点
DEoptim 差分进化 (Differential Evolution) 一种强大的随机全局优化算法，适用于连续空间的复杂优化问题。
pso 粒子群优化 (Particle Swarm Optimization) 模拟鸟群觅食行为，通过粒子间的信息共享来寻找最优解。
GenSA 广义模拟退火 (Generalized Simulated Annealing) 模拟金属退火过程的随机搜索算法，能有效跳出局部最优。

使用这些算法时，可以通过 search_size 参数控制随机搜索的规模。

4.随机搜索 (Random Search / Random Portfolios)

这是一种探索解空间的基础方法，通过生成大量满足约束条件的随机投资组合来寻找可行解。它主要有三种生成方法：

  • sample 方法：最灵活，但速度最慢。可以处理杠杆、上下限、分组和头寸限制等多种约束。
  • simplex 方法：基于 W. T. Shaw 的论文，能有效生成满足满额投资（权重和为1）和下限约束的组合。
  • grid 方法：基于 NMOF 包的网格搜索，但仅能满足权重的上下限约束。

使用随机搜索时，需设置 optimize_method = "random"，并通过 search_size 指定生成的组合数量。

5.如何选择

  • 首选凸优化：如果你的问题是凸的（如最小化方差、最大化收益），优先使用 "ROI"、"quadprog" 或 "glpk"，它们能保证找到全局最优解。
  • 复杂问题用启发式：当问题涉及非凸目标、复杂约束（如头寸限制、周转率约束）或需要优化CVaR等风险指标时，应选择 "DEoptim"、"pso" 或 "GenSA"。
  • 探索或初始化用随机搜索："random" 方法适合在优化前探索解空间，或作为基准来评估其他算法的表现。

五、riskParityPortfolio 包

riskParityPortfolio 是一个用于快速构建风险平价（Risk Parity）投资组合的 R 包。它的核心目标是均衡配置不同资产的风险贡献，而非简单地分散资金。该包为我们使用的风险平价策略提供了高效、灵活的实现工具。

1.核心算法

riskParityPortfolio 针对不同复杂度的优化问题，集成了多种高效算法：

  • 基础凸优化：对于无卖空和预算约束的经典风险平价问题，采用由 Spinu (2013) 提出的凸优化公式，可保证获得唯一最优解。
  • 循环算法：使用由 Griveau-Billion 等人提出的循环方法进行快速求解，尤其适合高维度的投资组合。
  • 非凸优化：当问题涉及更复杂的约束（如下界限制、期望收益目标等）时，问题通常变为非凸的。此时，包会采用 Feng & Palomar (2015) 提出的连续凸近似方法 (SCRIP) 进行求解。

2.主要功能

该包通过统一的 riskParityPortfolio() 函数，提供了从基础到进阶的多种功能：

  • 标准风险平价：默认情况下，只需输入资产收益率的协方差矩阵，即可计算等风险贡献的投资组合权重。
  • 风险预算 (Risk Budgeting)：你可以通过 b 参数，为不同资产指定具体的风险贡献目标，构建风险预算组合。
  • 集成均值-方差目标：允许在优化目标中加入期望收益或组合方差项，实现风险平价与均值-方差框架的融合。
  • 丰富的约束条件：支持卖空限制、头寸上下限（box constraints）等实际投资中常见的约束。
  • 可视化分析：提供了 barplotPortfolioRisk() 函数，可直观地对比展示组合的资金配置与风险贡献分配。

3.使用示例

以下是一个简单的 R 代码示例，演示了如何构建一个标准风险平价组合：

# 加载包
library(riskParityPortfolio)


# 生成模拟数据 (5个资产)
set.seed(42)
N <- 5
V <- matrix(rnorm(N^2), ncol = N)
Sigma <- cov(V)


# 计算标准风险平价组合
res <- riskParityPortfolio(Sigma)


# 查看结果
names(res)  # 返回 "w", "relative_risk_contribution", "is_feasible"
print(res$w)  # 输出最优权重

riskParityPortfolio 的强大之处在于其灵活性。你可以通过调整参数构建更符合实际需求的组合。

加入期望收益目标：通过 mu 和 lmd_mu 参数，可以在风险平价的基础上追求更高的期望收益。

# mu 为期望收益向量, lmd_mu 为权衡参数
rpp <- riskParityPortfolio(Sigma, mu = mu, lmd_mu = 0.1)

控制组合波动率：通过 lmd_var 参数，可以在优化中额外加入对组合总方差（波动率）的惩罚或偏好。

# lmd_var 控制方差项的影响程度
rpp <- riskParityPortfolio(Sigma, lmd_var = 0.01)

总的来说，riskParityPortfolio 是一个专注、高效且灵活的 R 包。它从基础的凸优化问题出发，通过集成先进的算法，能够处理从标准风险平等到包含多种实际约束和目标的复杂问题，是进行量化资产配置的有力工具。

六、genalg 包

1.概述

genalg 是一个用于解决优化问题的 R 语言遗传算法（Genetic Algorithm, GA）包。它由 Egon Willighagen 和 Michel Ballings 开发，其核心理念是模拟生物进化中的“适者生存”原则，通过选择（Selection）、交叉（Crossover）和变异（Mutation）等操作，迭代地寻找问题的最优解。

genalg 通过 rbga() 和 rbga.bin() 两个核心函数，让用户能够轻松地将遗传算法应用于各种自定义的优化问题，并提供了丰富的监控和可视化工具来辅助分析。

2.核心功能

genalg 的核心是 rbga() 函数，它支持两种主要的数据类型：

  • 二进制染色体 (Binary Chromosomes)：通过 rbga.bin() 实现，每个基因位只能取 0 或 1，常用于特征选择等场景。
  • 浮点数染色体 (Floating Point Chromosomes)：通过 rbga() 实现，每个基因位可以取一个连续的实数值，适用于参数优化等问题。

3.主要参数

rbga() 函数提供了丰富的参数来控制优化过程：

参数 说明
stringMin, stringMax （必需） 分别指定每个基因的最小值和最大值的向量。
popSize 种群大小，即每一代中包含的染色体数量，默认为 200。
iters 迭代次数，即算法运行的代数，默认为 100。
mutationChance 变异概率，即每个基因发生变异的几率。默认值为 1/(size+1)（size 为染色体长度）。该值影响算法的收敛速度与搜索范围。
elitism 精英主义，指每一代中直接保留到下一代的优秀染色体数量，默认为种群大小的 20%。
evalFunc （必需） 用户自定义的评估函数，用于计算每个染色体的适应度（fitness）。算法会最小化该函数的返回值。
monitorFunc 监控函数，可在每一代结束后被调用，用于实时观察优化过程。
suggestions 可选参数，用于提供初始种群的建议染色体。

4.可视化与结果分析

genalg 提供了专门用于分析优化结果的可视化功能：

  • 默认图 (type="default")：展示每一代中最小和平均的评估值，直观反映算法的收敛情况。
  • 直方图 (type="hist")：
    • 对于二进制染色体，展示每个基因被选中的频率。
    • 对于浮点数染色体，为每个变量绘制直方图，展示其在种群中的取值分布。
  • 变量关系图 (type="vars")：绘制评估函数值与变量值的关系图，有助于发现变量与目标函数之间的相关性。

5.代码示例

下面是一个简单的示例，演示如何使用 genalg 来寻找两个目标值（π 和 √50）。

# 加载包
library(genalg)


# 1. 定义评估函数：计算染色体与目标值的绝对误差之和
evaluate <- function(string=c()) {
    # 本例中，染色体长度为2
    returnVal = abs(string[1] - pi) + abs(string[2] - sqrt(50))
    returnVal
}


# 2. 定义监控函数：实时绘制每一代种群在二维空间的位置
monitor <- function(obj) {
    xlim = c(obj$stringMin[1], obj$stringMax[1])
    ylim = c(obj$stringMin[2], obj$stringMax[2])
    plot(obj$population, xlim=xlim, ylim=ylim,
         xlab="pi", ylab="sqrt(50)")
}


# 3. 运行遗传算法
# 第一个基因在 [1, 5] 间寻优，第二个基因在 [1, 10] 间寻优
rbga.results = rbga(c(1, 1), c(5, 10),
                    monitorFunc=monitor,
                    evalFunc=evaluate,
                    verbose=TRUE,
                    mutationChance=0.01)


# 4. 查看和绘制结果
plot(rbga.results)          # 默认收敛图
plot(rbga.results, type="hist") # 变量分布直方图
plot(rbga.results, type="vars") # 变量与目标值关系图

6.典型应用场景

由于其灵活性和对自定义评估函数的支持，genalg 适用于广泛的优化问题：

  • 特征选择 (Feature Selection)：使用二进制染色体，选择对模型预测最重要的特征子集。
  • 参数调优 (Parameter Tuning)：使用浮点数染色体，优化机器学习模型或仿真模型的超参数。
  • 实验设计优化：如在生物、化学等领域，优化培养基成分、反应条件等实验参数。

七、gramEvol 包

1.概述

gramEvol 是 R 语言中实现语法进化（Grammatical Evolution, GE） 算法的工具包。该包的作者是 Farzad Noorian 和 Anthony Mihirana de Silva.它允许用户通过自定义的上下文无关文法（Context-Free Grammar, CFG） 定义程序结构，然后利用进化算法在由该文法生成的所有 R 表达式空间中进行搜索，以发现能够达到特定目标的最佳程序。

2.语法进化（GE）

语法进化是一种程序自动发现技术，核心思想和工作流程是：

  1. 定义语法：用户通过上下文无关文法描述候选程序的可能结构
  2. 进化搜索：算法维护一个候选程序群体，通过迭代（选择、交叉、变异）不断优化
  3. 适应度评估：每个候选程序通过用户定义的代价函数（cost function）评估其表现
  4. 输出最优解：最终返回适应度最高的 R 表达式

与遗传编程（Genetic Programming）相比，GE 的优势在于语法约束更灵活，可以确保生成的所有程序在语法上都是有效的。

3.核心函数与语法定义

3.1. 创建语法规则

gramEvol 提供了三种创建语法规则（GERule）的函数：

函数 用途 示例
grule() 定义 R 表达式规则（Grammar Rule） grule(sin, cos, log)
gsrule() 定义字符串规则（Grammar String Rule），可生成非 R 语法的序列 gsrule("+", "-", "*")
gvrule() 定义向量规则（Grammar Vector Rule），从向量中取元素作为规则 gvrule(1:4)

3.2. 创建文法对象

CreateGrammar(ruleDef, startSymb)
  • ruleDef：一个命名列表，每个元素是一个 GERule 对象，名称即非终结符（non-terminal symbol）
  • startSymb：起始符号（默认为 ruleDef 的第一个规则）

3.3. 核心求解函数：GrammaticalEvolution()

GrammaticalEvolution(grammarDef, costFunc, ...)
参数 说明
grammarDef 由 CreateGrammar 创建的文法对象
costFunc 代价函数，接受一个 R 表达式作为输入，返回数值（越小越好）
iterations 进化迭代次数
populationSize 种群大小（默认 50）
elitism 精英保留数量
mutationChance 变异概率
codonLength 每个个体的密码子长度

3.4. 辅助函数

函数 用途
GrammarMap(codon, grammarDef) 将整数序列（密码子）映射为对应的 R 表达式
GrammarRandomExpr(grammarDef, numExpr) 从文法中随机生成表达式

4.使用示例：开普勒定律的符号回归

以下示例演示如何使用 gramEvol 通过符号回归重新发现开普勒第三定律（行星公转周期与轨道半径的关系）。

4.1. 步骤 1：定义文法

library("gramEvol")


grammarDef <- CreateGrammar(list(
    expr = grule(op(expr, expr), func(expr), var),
    func = grule(sin, cos, log, sqrt),
    op = grule(`+`, `-`, `*`),
    var = grule(distance, distance^n, n),
    n = gvrule(1:4)  # 等价于 grule(1, 2, 3, 4)
))

这个文法定义了表达式可以递归地由二元运算、函数或变量组成，变量可以是 distance、distance^n 或常数 n。

4.2. 步骤 2：准备数据和代价函数

# 太阳系行星数据（距离和公转周期）
distance <- c(0.72, 1.00, 1.52, 5.20, 9.53, 19.10)
period   <- c(0.61, 1.00, 1.84, 11.90, 29.40, 83.50)


# 代价函数：评估表达式预测周期与实际周期的误差
SymRegCostFunc <- function(expr) {
    result <- eval(expr)
    if (any(is.na(result))) return(Inf)
    return(mean(log(1 + abs(period - result))))
}

4.3. 步骤 3：运行语法进化

ge <- GrammaticalEvolution(grammarDef, SymRegCostFunc, iterations = 50)
print(ge)

4.4. 步骤 4：查看结果

# 提取最优表达式
best.expression <- ge$best$expression
print(best.expression)


# 比较真实周期、开普勒定律预测值和 GE 发现表达式
print(data.frame(
    distance,
    period,
    Kepler = sqrt(distance^3),  # 开普勒第三定律
    GE = eval(best.expression)
))

运行后，GE 算法可能会发现类似于 sqrt(distance^3) 的表达式，即重新发现开普勒第三定律。

5.高级特性

5.1. 使用 gsrule() 生成非 R 语法序列

当需要生成不是合法 R 语法的字符串（如 "A+B"）时，使用 gsrule()：

ruleDef <- list(
    expr = gsrule("<var><op><var>"),
    op   = gsrule("+", "-", "*"),
    var  = gsrule("A", "B")
)
grammarDef <- CreateGrammar(ruleDef)

5.2. 保留逗号和赋值运算符

在使用 grule() 时，如果规则中包含逗号或赋值符（=），需要用 .() 包裹以保留它们：

ruleDef <- list(
    expr = grule(data.frame(dat)),
    dat  = grule(.(x = 1, y = 2), .(x = 5, y = 6))
)

5.3. 从 .bnf 文件读取文法

CreateGrammar() 也支持直接从 Backus-Naur Form（BNF）格式的文件读取文法：

grammarDef <- CreateGrammar("path/to/grammar.bnf")

6.注意事项

  1. 代价函数需返回数值：gramEvol 通过最小化代价函数来搜索最优解，代价函数必须接收一个 R 表达式并返回一个数值（越小越好）。

  2. 处理无效表达式：在代价函数中应处理可能导致错误或 NaN 的表达式（如对负数取对数），通常返回 Inf 以淘汰该个体。

  3. 随机种子：为获得可重复的结果，建议在运行前设置 set.seed()。

  4. 性能考虑：对于大规模问题，可增加 iterations 和 populationSize，但需权衡计算时间。

7.核心优势

gramEvol 的核心优势在于：

特点 说明
声明式编程 用户只需定义文法和代价函数，无需手动设计搜索算法
灵活性高 支持 R 表达式和字符串两种规则形式，适用场景广泛
原生 R 实现 完全在 R 环境中运行，无需外部依赖
教学资源丰富 提供详细的 vignette 教程和 JSS 论文

该包适用于符号回归、自动编程、参数优化、方程发现等场景，是 R 语言生态中实现语法进化算法的首选工具。

八、alabama包

1.概述

alabama 是 R 语言中一个专门用于带约束非线性优化的工具包。由 Ravi Varadhan 开发（Gabor Grothendieck 亦有贡献），首次发布于 2010 年。它实现了增广拉格朗日自适应障碍最小化算法（Augmented Lagrangian Adaptive Barrier Minimization Algorithm），能够有效处理带有线性或非线性等式与不等式约束的平滑非线性目标函数优化问题。

2.核心函数

alabama 提供了两个主要函数：

函数 说明
auglag() 增广拉格朗日最小化算法，允许初始值不满足不等式约束（即不可行初始点）
constrOptim.nl() 与 auglag() 类似，但要求初始值满足不等式约束（可行初始点）

两者核心算法相同，主要区别在于对初始值的约束要求不同。实际使用中，auglag() 更为灵活，因为无需事先寻找可行初始点。

3.核心参数详解

以 auglag() 为例（constrOptim.nl() 参数与之相同）：

auglag(par, fn, gr, hin, hin.jac, heq, heq.jac,
       control.outer = list(), control.optim = list(), ...)
参数 类型 说明
par 数值向量 初始参数值。auglag() 允许违反不等式约束
fn 函数 目标函数，接受向量参数返回标量值
gr 函数 目标函数的梯度向量函数。默认为 NULL，使用数值微分
hin 函数 不等式约束函数，要求 hin[j] > 0 对所有 j 成立
hin.jac 函数 hin 的雅可比矩阵。默认数值微分
heq 函数 等式约束函数，要求 heq[j] = 0 对所有 j 成立
heq.jac 函数 heq 的雅可比矩阵。默认数值微分
control.outer 列表 外层循环控制参数

4.使用示例

4.1.带不等式约束的优化

最小化目标函数 (x₁ + 3x₂ + x₃)² + 4(x₁ - x₂)²，约束条件为 x₁ + x₂ + x₃ ≥ 1：

library(alabama)


# 目标函数
fn <- function(x) (x[1] + 3*x[2] + x[3])^2 + 4 * (x[1] - x[2])^2


# 梯度（可选，提供后可大幅加速高维问题）
gr <- function(x) {
  g <- rep(NA, 3)
  g[1] <- 2 * (x[1] + 3*x[2] + x[3]) + 8 * (x[1] - x[2])
  g[2] <- 6 * (x[1] + 3*x[2] + x[3]) - 8 * (x[1] - x[2])
  g[3] <- 2 * (x[1] + 3*x[2] + x[3])
  g
}


# 不等式约束：hin(x) > 0，即 x1 + x2 + x3 - 1 > 0
hin <- function(x) x[1] + x[2] + x[3] - 1


# 求解
result <- auglag(par = c(1, 1, 1),   # 初始值
                 fn = fn,
                 gr = gr,
                 hin = hin,
                 control.outer = list(trace = TRUE))  # 开启迭代日志


print(result$par)      # 最优解
print(result$value)    # 最优目标值
print(result$convergence)  # 0 表示成功收敛

4.2.带等式约束的优化

若需同时添加等式约束 x₁ + 2x₂ - x₃ = 2：

# 等式约束：heq(x) = 0
heq <- function(x) x[1] + 2*x[2] - x[3] - 2


result <- auglag(par = c(1, 1, 1),
                 fn = fn,
                 gr = gr,
                 hin = hin,
                 heq = heq)

4.3.返回值

函数返回一个列表，包含以下关键组件：

组件 说明
par 最优参数向量
value 最优目标函数值
convergence 收敛代码：0 表示成功，正数表示失败
counts 目标函数和梯度的评估次数
outer.iterations 外层迭代次数
ineq 收敛时不等式约束的值（应全部 ≥ 0）
equal 收敛时等式约束的值（应全部接近 0）
kkt1 一阶 KKT 条件是否满足
kkt2 二阶 KKT 条件是否满足

5.重要注意事项

  • 约束函数的符号约定：

    • 不等式约束要求 hin(x) > 0。若希望表达 g(x) ≤ 0，需定义为 hin(x) = -g(x)。
    • 等式约束要求 heq(x) = 0。

  • 梯度与雅可比矩阵：虽然默认使用数值微分，但在高维问题中提供精确梯度可显著提升计算速度。

  • 初始值容忍度：auglag() 允许初始值违反不等式约束，而 constrOptim.nl() 则要求初始值可行。

  • KKT 条件检查：默认会检查二阶 KKT 条件，若 Hessian 计算耗时，可将 kkt2.check = FALSE 关闭。

6.核心优势

alabama 的核心优势在于：

特点 说明
约束类型全面 同时支持线性和非线性、等式和不等式约束
初始值要求宽松 auglag() 允许不可行初始点，大幅降低使用门槛
算法稳健 增广拉格朗日 + 自适应障碍方法，对复杂约束问题有较好表现
梯度支持 支持用户提供精确梯度以加速计算
可观测性强 trace = TRUE 可实时查看迭代过程
ROI 生态集成 可作为 ROI 框架的求解插件

alabama 可作为 ROI（R Optimization Infrastructure）的插件使用。通过 ROI.plugin.alabama 包，可在 ROI 框架中调用 alabama 求解器。此外，alabama 被多个 R 包依赖或建议使用，包括 GDINA、gllvm、metafor、tramME 等。

该包适用于经济学建模、工程优化、统计估计等需要处理复杂约束的数值优化场景，是 R 语言中处理带约束非线性优化问题的重要工具。
