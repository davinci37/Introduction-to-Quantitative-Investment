第21章 参考书籍和文献 第一节 参考书籍

本书各章涉及的工具、方法与领域各不相同。本书正文受篇幅所限，只能点到为止。本章后文，我把各章背后值得继续自学的书单集中列出。读者如果需要深入某一方面知识，只需要找到对应的书籍自行学习即可，不必按书单顺序阅读。 书目不求全，只收录了我认为最经典的、值得花时间深入学习的书籍名单。版本信息以写作时所见为准，技术类资料更新较快，使用前请核对最新版本。

一、R 语言

1. 《R in Action》 Rob Kabacoff 著，面向商业与科研场景的 R 实战指南。第二版涵盖完整语言教程、数据管理、回归、方差分析、广义线性模型、主成分与因子分析、时间序列、聚类、分类及缺失数据处理，并含 ggplot2 高级图形与包创建等内容。第三版（2022）进一步融入 tidyverse 工作流与 ggplot2 可视化。定位是用 R 解决实际数据分析问题，而非单纯语法讲解。

2. 《Advanced R》 Hadley Wickham 著，面向中高级 R 用户与包开发者。全书分四部分：R 语言基础、函数式编程、R 语言计算、R 性能分析。重点不在数据分析，而在 R 作为编程语言的底层机制——函数式编程框架、元编程的利弊、如何写出快速且内存高效的代码。适合想深入理解 R 语言设计、提升代码质量的读者。

3. 《R in a Nutshell》 O’Reilly 速查手册风格。介绍 R 环境（GUI 与控制台）、面向对象语言基础，教读者编写 R 函数与构建包，并帮助寻找统计建模、可视化、生物信息学领域的合适第三方包。附带医学、商业、体育等领域的实用示例，涉及 lattice 图形包与 Bioconductor。定位为桌面参考书，适合日常查阅而非从头通读。

4. 《Introduction to R - tidyverse》 以 tidyverse 为核心的 R 入门材料（PDF 教程）。从标量、向量、矩阵等基础数据类型与算术操作讲起，介绍对象赋值、函数调用、向量创建与序列生成，全程使用 tidyverse 包并借助 RMarkdown 编写。定位为初学者快速上手 tidyverse 工作流的引导材料。

5. 《R for Data Science》（2e） Hadley Wickham、Mine Çetinkaya-Rundel、Garrett Grolemund 合著。第二版大幅重构，以“Whole game”开篇让读者先把握数据科学全貌，随后分 Visualize、Transform、Import、Program、Communicate 五部分深入。新增电子表格与数据库导入、层级数据矩形化、网页抓取等内容，沟通部分改用 Quarto 替代 R Markdown。建模部分已移除，官方建议转读《Tidy Modeling with R》。

6. 《Tidy Modeling with R》 Max Kuhn 与 Julia Silge 合著，tidymodels 框架的实操指南。覆盖建模全流程：数据预处理与特征工程、模型拟合、调参以优化性能、防范过拟合、模型比较与评估选择。核心理念是用 tidyverse 的一致设计与语法贯穿建模工作，降低学习成本。

7. 《Introduction to data.table》 data.table 包官方入门 vignette。介绍这一高性能数据操作包的核心语法，包括 by 分组中表达式的使用、.SD（Subset of Data）特殊符号配合 lapply 对多列批量运算、链式表达式以及内部基数排序优化。适合需要处理大规模数据、追求 R 中运算效率的读者。

二、torch / 深度学习

8. 《Deep Learning and Scientific Computing with R torch》 Sigrid Keydana 著，Chapman & Hall/CRC 2023 年出版。介绍 R 的 torch 包——PyTorch 的纯 R 接口，无需安装 Python 即可使用。全书三部分：第一部分（1–11 章）讲张量、自动微分、模块与优化器，从零搭建一个小神经网络；第二部分（12–22 章）覆盖数据批加载、luz 高级封装、CNN、过拟合应对等深度网络实现；第三部分（23–28 章）展示 torch 在深度学习之外的科学计算用途。

9. 《A Minimal rTorch Book》 以 rTorch 包（通过 reticulate 调用 PyTorch）为主题的极简实操材料。动机是在 RMarkdown 中同时使用 R 与 Python 代码，兼顾可复现性与 literate programming。演示了 PyTorch 版本查询、配置、torchvision 数据集下载（如 MNIST）、numpy 互操作等基础操作。定位为轻量指南，适合想在 R 工作流中嵌入 PyTorch 的读者。

三、LLM

10. 《Build a Large Language Model (From Scratch)》 Sebastian Raschka 著，Manning 2025 年出版。不依赖任何现有 LLM 库，从零编写基础模型，逐步演化为文本分类器，最终构建能遵循对话指令的聊天机器人。强调通过亲手实现来真正理解 LLM 的内部原理。

四、爬虫

11. 《基于 R 语言的自动数据收集：网络抓取和文本挖掘实用指南》 Simon Munzert 等著，机械工业出版社 2016 年中文版。全书 17 章：第 2–8 章介绍 HTTP、HTML、XML、JSON、AJAX、SQL 等网络技术基础及 XPath 与正则表达式；第 9–11 章是核心工具箱，涵盖多种抓取技术、统计性文本处理、用 R 管理数据的常见问题；第 12–17 章为案例分析，包括美国参议院合作网络、Twitter 预测奥斯卡、姓氏地理分布、产品评论情绪分析等。

五、Python

12. 《Python 数据科学手册》（中文版） Jake VanderPlas 著。基于 GitHub 热门开源项目，全书五部分对应数据科学核心工具链：IPython/Jupyter（计算环境）、NumPy（高效数组存储与操作）、pandas（带标签列式数据）、Matplotlib（可视化）、Scikit-Learn（机器学习算法实现）。定位全面且偏参考手册性质。

13. 《利用 Python 进行数据分析》（第二版） Wes McKinney（pandas 创始人）著，针对 Python 3.6 全面修订。系统讲解用 Python 操作、处理、清洗、规整数据，涵盖新版 pandas、NumPy、IPython、Jupyter，新增高级 pandas 工具章节及 statsmodels/scikit-learn 简明介绍。是 Python 数据分析领域最经典的入门与实战参考书之一。

六、机器学习

14. 《机器学习导论》（Ethem Alpaydin） 土耳其学者 Ethem Alpaydin 著，原书第 2 版中文译本。全面论述机器学习主题，统一处理来自统计学、模式识别、神经网络、人工智能、信号处理等不同领域的方法。涵盖监督学习、贝叶斯决策、参数/非参数方法、多元方法、维度归约、聚类、决策树、多层感知器、隐马尔可夫模型、分类算法评估与组合学习器等。第 2 版将核方法、贝叶斯估计、图模型各扩为一整章，并加强了实验设计与分析的内容。定位为高年级本科生/研究生教材。

15. 《Advances in Financial Machine Learning》 Marcos López de Prado 著。讨论如何将金融大数据结构化为适合 ML 算法处理的形式、如何用 ML 算法开展研究、如何利用超算方法，以及如何回测发现结果同时避免假阳性。面向从业者日常面对的真实问题，用数学解释科学上可靠的解决方案，辅以代码与示例。适合有一定 ML 与金融基础的进阶读者。

16. 《ML for Trading》（Chapters | ML for Trading） 该书的第三版已从零重建，以完整的研究到生产工作流贯穿全书，覆盖九大跨资产类别案例（美股特征、S&P 500 及期权、CME 期货、ETF、加密永续、外汇、NASDAQ-100 日内微结构等）。新增合成金融数据、策略研究框架、基于模型的特征提取、深度学习时间序列、因果机器学习、强化学习执行与对冲、RAG 金融研究、知识图谱、自主智能体、实盘系统与 MLOps 治理等章节。定位为量化交易与 ML 结合的综合性实操指南。

七、Alpha 因子

17. 《Global Factor Data Documentation》 全球因子数据集的配套文档。底层数据来自 Jensen、Kelly、Pedersen 的“Is there a replication crisis in finance?”（Journal of Finance, 2023），覆盖 93 个国家、13 个主题、153 个因子。文档说明因子收益（long-short、hml、pfs 三种方法）、市场收益、GICS 行业收益、国家/地区分类、主题聚类等数据的获取方式与字段含义。属于数据文档而非教程，适合需要理解或使用全球多因子数据的研究者。

八、资产配置

18. 《预期收益：投资者的获利指南》 Antti Ilmanen 著，格致出版社 2018 年中文版。作者为 AQR 资深投资经理。全书覆盖主要资产类别（股票、债券、另类资产）、主要投资策略（价值、利差、趋势、波动率）以及底层风险因素（成长、通胀、低流动性、尾部风险）。核心主张是跳出狭隘的资产类别视角或仅关注历史业绩，综合评价预期收益需权衡历史收益、理论逻辑与当前市场条件。兼具学术梳理与实战经验。

19. 《资产配置的艺术（完整版）》 David M. Darst 著，中国人民大学出版社 2014 年中文版。讲述如何使用现代资产配置理念和工具，在牛市、熊市、平衡市等不同市场环境下增加回报、控制风险。内容分六部分：理解资产配置、配置方法、配置基础、资产种类特征、金融市场分析与投资洞见、战略与战术。

20. 《Balanced Asset Allocation: How to Profit in Any Economic Climate》 Alex Shahidi 著，Wiley 2014 年出版。核心观点是传统组合因未针对不同经济结果实现平衡而容易遭受频繁且严重的损失。作者基于 15 年服务大型养老金、基金会、家族办公室的经验，阐述真正平衡的组合框架，并给出逐步构建方法。书中讨论了股票、国债、TIPS、商品在平衡框架中的角色。适合希望从更深层的经济环境对冲视角理解资产配置的读者。

九、风险管理

21. 《风险预算》 Neil D. Pearson 著，中文版由詹原瑞、奚胜田翻译。介绍风险预算的概念及其背后的工具与方法，重点讲风险价值（VaR）和风险分解在组合管理中的运用，为机构投资者、基金经理和投资组合经理提供 VaR 用于风险预算的实操知识。

十、CTA

22. 《海龟交易法则》 Curtis Faith 著。记录 1983 年理查德·丹尼斯与威廉·埃克哈特的著名“海龟试验”：从 1000 名报名者中甄选 13 人，用两周传授交易理念与法则，随后四年海龟们凭借这些法则取得年均 80% 的收益。属于趋势跟踪/系统化交易的经典读本。

十一、计量经济学

23. 《计量经济学》（李子奈） 李子奈、潘文卿编著，高等教育出版社。融理论、方法与应用为一体，以中级水平为主。详细论述经典单方程计量经济学模型的理论方法，适当介绍现代时间序列模型和几类非经典横截面数据模型。重点不在数学推导，而在实际应用中出现的问题处理，并尽可能与中国模型实例结合。定位为高校经济管理学科本科生教材或参考书。

第16章 R 第17节 其它重要问题
