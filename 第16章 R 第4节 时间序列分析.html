第16章 R 第4节 时间序列分析

引言

时间序列分析是数据科学中最重要且应用最广泛的领域之一。R语言凭借其丰富而强大的生态系统，已经成为时间序列数据处理和分析的首选工具。本文将从时间计算、数据结构、数据处理到统计建模，系统性地介绍R语言在时间序列分析中的核心功能与应用。

一、时间计算

时间序列分析的基础在于对时间本身的操作与计算。R语言提供了多个专门处理日期和时间的包，其中timeDate和lubridate是最具代表性的两个。

1. timeDate包

timeDate包是Rmetrics套件的核心基础组件，专为金融时间序列分析中的日期和时间管理而设计。它通过提供标准、严谨且功能丰富的时间日期对象，为上层的高级金融分析（如timeSeries、fGarch等）奠定了坚实基础。

核心特性包括：

遵循国际标准：timeDate类完全遵循ISO 8601、ANSI C和POSIX标准，确保了时间数据表示的规范性和跨平台的一致性。

独创的“金融中心”概念：这是timeDate区别于R中其他时间包的核心特性。它能处理不同时区收集的数据，并允许用户设置一个“金融中心”（如”Zurich”、“NYC”），所有时间戳都会基于此进行转换和显示。这对于处理来自全球不同交易所的金融数据至关重要。

强大的日历工具：除了基本的日期时间功能，它还提供了复杂的日历操作，如判断是否为工作日、周末，以及管理公共假日和宗教节日（如复活节）等。

核心概念：S4类 timeDate

timeDate包基于R的S4面向对象系统构建。timeDate类：其对象包含三个核心槽（slot）：

  • @Data：以POSIXct格式存储的时间戳。
  • @format：时间戳的格式。
  • @FinCenter：该时间戳所属的“金融中心”。

主要功能与应用包括：

1.1. 创建 timeDate 对象

包提供了多种创建对象的便捷函数：

  • timeDate()：从字符向量或其它日期对象创建。
  • timeSequence()：生成规则的时间序列。
  • timeCalendar()：从年、月、日等日历元素创建。
  • Sys.timeDate()：获取当前的系统时间。
library(timeDate)


# 1. 从字符向量创建，默认使用"GMT"时区
my_dates <- timeDate(c("2026-09-03 10:00:00", "2026-09-04 14:30:00"))
print(my_dates)


# 2. 设置金融中心为"Zurich"（苏黎世）
my_dates_zurich <- timeDate(c("2026-09-03 10:00:00", "2026-09-04 14:30:00"),
                            zone = "Zurich")
print(my_dates_zurich)


# 3. 生成一个日期序列
my_sequence <- timeSequence(from = "2026-09-01", to = "2026-09-10", by = "day")
print(my_sequence)


# 4. 从日历元素创建
my_calendar <- timeCalendar(year = 2026, month = 9, day = 3)
print(my_calendar)

1.2. 与时区和“金融中心”协同工作

这是timeDate最独特的功能。通过设置全局或局部的金融中心，可以轻松地在不同时区间转换时间。

# 查看默认的金融中心（通常为"GMT"）
getRmetricsOptions("myFinCenter")


# 设置全局金融中心为纽约
setRmetricsOptions(myFinCenter = "America/New_York")


# 创建一个时间戳，并指定其原始时区为"GMT"，但显示时会根据全局设置转换
ts_ny <- timeDate("2026-09-03 14:00:00", zone = "GMT", FinCenter = "America/New_York")
print(ts_ny)

1.3. 复杂的日期计算与日历操作

timeDate提供了丰富的函数用于日期计算和判断。

日期计算：支持日期的加减、排序、取整（round）、去重（unique）等。

工作日与假日判断：这是金融分析中的高频操作。

# 创建一个日期向量
my_dates <- timeDate(c("2026-09-03", "2026-09-04", "2026-09-05", "2026-09-06"))


# 判断是否为周末
isWeekend(my_dates)


# 判断是否为工作日（周一至周五）
isWeekday(my_dates)


# 获取特定年份的复活节日期
easter(2026)

包中还内置了多个主要金融中心的假日日历（如纽约证券交易所NYSE），可以方便地判断某天是否为交易日：

# 判断日期是否为纽约证券交易所的交易日
isBizday(my_dates, holidays = holidayNYSE(2026))

timeDate包函数可快速计算给定日期所在月份或季度的第一天和最后一天，特别适合在金融时间序列中生成日历边界，比如月度/季度报表的起止日期。

library(timeDate)


# 给定日期
my_date <- "2026-09-03"


# 月份第一天/最后一天
timeFirstDayInMonth(my_date)   # "2026-09-01"
timeLastDayInMonth(my_date)    # "2026-09-30"


# 季度第一天/最后一天
timeFirstDayInQuarter(my_date) # "2026-07-01"（第三季度）
timeLastDayInQuarter(my_date)  # "2026-09-30"


# 支持向量化操作
dates <- c("2026-09-03", "2026-02-15", "2026-12-01")
timeLastDayInMonth(dates)      # "2026-09-30" "2026-02-28" "2026-12-31"

2. lubridate包

lubridate 是 R 语言中处理日期和时间（date-time）数据的核心包之一，也是 tidyverse 生态系统的重要成员。它旨在解决基础 R 中日期时间处理“通常不直观，且会随对象类型变化而改变”的痛点，提供了一套 “一致且易于记忆的语法” ，让处理日期变得“简单又有趣”。

2.1. 智能解析

lubridate 提供了一系列以 y (年)、m (月)、d (日)、h (时)、m (分)、s (秒) 顺序命名的解析函数，函数名即数据的排列顺序，省去了记忆复杂的 format 参数。

# 解析日期
ymd("2026-09-03")        # "2026-09-03"
mdy("September 3, 2026") # "2026-09-03"
dmy("03/09/2026")        # "2026-09-03"


# 解析日期时间
ymd_hms("2026-09-03 14:30:00") # "2026-09-03 14:30:00 UTC"
mdy_hms("09/03/2026 2:30 PM")  # "2026-09-03 14:30:00 UTC"

对于未知格式，可使用 guess_formats() 进行试探。

2.2. 提取与修改组件

使用与组件同名的函数即可提取或修改日期的各个部分。

dt <- ymd_hms("2026-09-03 14:30:00")


# 提取组件
year(dt)   # 2026
month(dt)  # 9
mday(dt)   # 3 (一个月中的第几天)
wday(dt, label = TRUE, abbr = FALSE) # "星期四" (带标签的星期几)
hour(dt)   # 14
minute(dt) # 30
second(dt) # 0


# 修改组件 (在原始对象上直接修改)
month(dt) <- 12
dt # "2026-12-03 14:30:00 UTC"


# 向量化操作也完全支持
dates <- ymd(c("2026-09-01", "2026-09-02", "2026-09-03"))
wday(dates, label = TRUE) # "周二" "周三" "周四"

2.3. 时区处理

lubridate 提供了两个核心函数来处理时区。 * with_tz()：更改显示时区，将时间从当前时区转换到目标时区。 * force_tz()：强制更改时区属性，而不改变底层时刻，适用于纠正错误时区标签。

time <- ymd_hms("2026-09-03 14:30:00", tz = "UTC")
time
# [1] "2026-09-03 14:30:00 UTC"


# 转换到纽约时区显示 (时间发生相应变化)
with_tz(time, "America/New_York")
# [1] "2026-09-03 10:30:00 EDT"


# 强制将时区改为纽约 (时间戳本身不变，只是标签变了)
force_tz(time, "America/New_York")
# [1] "2026-09-03 14:30:00 EDT"

2.4. 时间跨度

这是 lubridate 最强大的设计之一，它将时间跨度（timespan）分为三类，以应对不同的计算场景。

Periods (时期)：关注“时钟时间”。它按“人类单位”（年、月、日等）进行计算。加减月份时会自动处理月份天数不同的问题。

jan31 <- ymd("2026-01-31")     jan31 + months(1) # "2026-02-28" (自动滚到2月最后一天)

Durations (时长)：关注“物理时间”。它总是以秒为单位进行精确计算。

jan31 + ddays(1) # "2026-02-01" (固定增加86400秒)

Intervals (区间)：由两个具体的日期时间界定。它是最精确的表示，可安全地转换为 Period 或 Duration。

start <- ymd_hms("2026-01-01 00:00:00")    
end <- ymd_hms("2026-01-02 12:00:00")     
span <- start %--% end # 创建一个区间     
as.duration(span) # "129600s (~1.5 days)"    
as.period(span)  # "1d 12H 0M 0S"

2.5. 日期时间运算

为解决“1月31日加1个月”这类问题，lubridate 提供了 %m+% 和 %m-% 运算符，它们会智能地将不存在的日期滚动到该月的最后一天。

jan31 <- ymd("2026-01-31")
jan31 %m+% months(1) # "2026-02-28"
jan31 %m-%% months(1) # "2025-12-31"

2.6. 舍入与回滚

  • 舍入：round_date(), floor_date(), ceiling_date() 可将日期时间舍入到指定单位（如 week, month）。
  • 回滚：rollback() 可将日期回滚到上个月的最后一天。

2.7. 总结

lubridate 通过其直观的解析函数、一致的组件访问接口以及精确的时间跨度模型，极大地降低了 R 语言中日期时间处理的复杂度，让分析师能更专注于问题本身而非数据格式的细节。

与timeDate的严谨和标准化不同，lubridate的设计哲学是易用性和直观性。作为tidyverse生态系统的核心成员之一，lubridate使得日期时间的处理变得更加直观和愉悦。

二、时间序列数据结构

R语言中有多种用于存储时间序列数据的结构，其中zoo、xts和timeSeries是最为重要的三个。

1. zoo（Z’s Ordered Observations）

zoo包提供了S3类zoo，是R语言中处理规则和不规则时间序列的基础设施。zoo的核心设计理念是创建一个通用的、完全有序的索引观测值容器。

zoo对象的特点：

  • 灵活的索引类型：索引可以是Date、POSIXct、chron、yearmon、yearqtr等任意有序类型
  • 数据存储灵活：核心数据可以是数值向量、矩阵，甚至任意类的对象
  • 支持规则和不规则序列：这是zoo相对于基础ts类的最大优势
library(zoo)


# 创建规则时间序列
z_regular <- zoo(1:10, order.by = seq.Date(from = as.Date("2026-01-01"),
                                            by = "day", length.out = 10))


# 创建不规则时间序列
dates_irregular <- as.Date(c("2026-01-01", "2026-01-03", "2026-01-07", "2026-01-15"))
z_irregular <- zoo(c(10, 20, 30, 40), order.by = dates_irregular)


# 查看索引和时间频率
index(z_irregular)
frequency(z_irregular)  # 不规则序列返回1

zoo包还提供了大量与基础R统计函数兼容的方法，如plot()、summary()、merge()、aggregate()等。

2. xts（eXtensible Time Series）

xts包在zoo的基础上进行了扩展，提供了更强大、更高效的时间序列处理能力。xts继承了zoo的所有方法，并增加了许多针对时间序列的优化和扩展功能。

xts的核心优势：

  • C级优化：许多核心操作在C语言级别实现，性能卓越
  • 统一的时间处理：提供对R中多种时间数据类的统一处理接口
  • 丰富的索引操作：支持按日期范围、按时间点等灵活的子集提取
  • 原生格式信息保留：最大化保留数据的格式信息
library(xts)


# 创建xts对象
x <- xts(1:10, order.by = seq.Date(from = as.Date("2026-01-01"),
                                    by = "day", length.out = 10))


# 按日期范围提取子集
x["2026-01-03/2026-01-07"]


# 按年份/月份提取
x["2026-01"]  # 提取2026年1月所有数据


# 滞后操作
lag(x, k = 1)  # 滞后1期


# 差分操作
diff(x)

xts与zoo的高度兼容性意味着大多数zoo函数可以直接用于xts对象，这使得从zoo迁移到xts几乎零成本。

3. timeSeries

timeSeries是Rmetrics套件中的S4类时间序列对象，特别针对金融数据分析而设计。

timeSeries的特点：

  • S4类系统：采用严格的面向对象设计
  • 金融数据专用：提供了大量金融时间序列分析所需的专门方法
  • 丰富的工具集：包括缩放、排序、子集提取、数学运算和统计函数等
library(timeSeries)


# 创建timeSeries对象
ts <- timeSeries(data = matrix(rnorm(100), ncol = 2),
                 charvec = as.character(seq.Date(from = as.Date("2026-01-01"),
                                                  by = "day", length.out = 50)))

在实际应用中，三者各有侧重：zoo是通用基础，xts是性能优化版，timeSeries则专注于金融分析场景。

三、时间序列数据计算

1. 滚动计算

在R的时间序列分析中，滚动计算（Rolling/Running Window Calculation）是一种核心操作，用于在数据的一个固定大小的滑动窗口上反复应用某个函数。`zoo`包提供了最通用和灵活的框架，而`timeSeries`包则在此基础上提供了针对其对象结构的封装。

zoo包提供了两种主要的滚动计算函数：通用的rollapply()和针对特定统计量优化的专用函数。

rollapply()是zoo包中最核心、最通用的滚动计算函数。你可以将任何R函数应用到滚动窗口上，这使其无比灵活。

library(zoo)


z <- zoo(1:20, as.Date(1:20))


# 滚动均值（窗口宽度为3）
rollapply(z, width = 3, FUN = mean)


# 滚动标准差
rollapply(z, width = 5, FUN = sd)


# 非重叠分组计算（by参数控制步长）
rollapply(z, width = 3, FUN = mean, by = 3)  # 每3个一组计算均值


# 滚动回归
rollapply(z, width = 10, FUN = function(x) coef(lm(x ~ index(x))))

对于均值、最大值、中位数和求和这四种最常见的滚动操作，zoo提供了专门的函数。它们和rollapply()功能类似，但针对特定操作进行了速度优化，在处理大型数据时效率更高。

以rollmean为例，基本语法：

rollmean(x, k, fill = if (na.pad) NA, na.pad = FALSE,
         align = c("center", "left", "right"), ...)
rollmax(x, k, ...)
rollmedian(x, k, ...) # 注意：k必须为奇数
rollsum(x, k, ...)

重要区别与注意事项：

  • 性能：这些专用函数比使用rollapply(x, k, mean)要快得多。

  • NA值处理：rollmean和rollsum的默认方法不处理输入数据中包含的NA值。如果数据中有NA，应使用rollapply(x, k, mean, na.rm = TRUE)。

  • rollapply的智能优化：当FUN = mean且满足一定条件时，rollapply会自动调用优化版的rollmean来提速。

# rollmean vs rollapply
xm <- zoo(matrix(1:12, 4, 3), as.Date("2026-01-01") + 0:3)


# 这两行代码效果相同，但rollapply会自动使用更快的rollmean方法
rollapply(xm, 3, mean)                 # 会使用rollmean优化
rollapply(xm, 3, function(x) mean(x)) # 不会使用rollmean优化

timeSeries包也提供了滚动计算功能，其底层代码实际上直接借鉴并封装自zoo包。主要函数包括：

rollStats(): 最通用的函数，允许通过FUN参数指定任意函数。

rollMean(), rollMin(), rollMax(), rollMedian(): 分别计算滚动均值、最小值、最大值和中位数。

rollStats(x, k, FUN = mean, na.pad = FALSE,
          align = c("center", "left", "right"), ...)
rollMean(x, k, na.pad = FALSE, align = c("center", "left", "right"), ...)
# rollMin, rollMax, rollMedian 用法类似

函数对比总结

特性 rollapply() rollmean等 timeSeries 函数
通用性 最高，可应用任何R函数 低，仅限特定统计量 中等，rollStats()通用，其他专用
性能 较慢，特别是自定义函数 非常快，经过优化 与zoo函数性能相当
适用对象 zoo, ts, 向量, 矩阵 zoo, ts timeSeries
NA值处理 通过...传递给FUN rollmean/rollsum默认不处理NA 通过...传递给FUN
核心特点 功能强大，极其灵活 为常用操作提供高速通道 为timeSeries对象提供便捷封装

实践中，一般首选zoo专用函数。当你的需求是计算滚动均值、和、最大值或中位数时，应优先使用rollmean()、rollsum()等专用函数，以获得最佳性能。 复杂计算用rollapply()。当需要计算滚动标准差、相关系数、自定义回归等专用函数无法实现的操作时，rollapply()是唯一且强大的选择。如果你的数据本身就是timeSeries对象，为了保持代码风格一致或简化操作，可以直接使用timeSeries包提供的rollMean()等函数。

2. 缺失值处理

时间序列数据中缺失值极为常见，zoo包提供了多种缺失值填充方法：

前向填充（Last Observation Carried Forward）

library(zoo)


z <- zoo(c(1, NA, 3, NA, 5), as.Date(1:5))


# 用最后一个非缺失值填充NA
na.locf(z)
# 结果：1, 1, 3, 3, 5


# 从末尾向前填充
na.locf(z, fromLast = TRUE)
# 结果：1, 3, 3, 5, 5

线性插值

# 线性插值
na.approx(z)
# 结果：1, 2, 3, 4, 5

样条插值

# 样条插值
na.spline(z)

na.locf()、na.approx()和na.spline()分别适用于不同的场景：前向填充适用于金融数据中“价格不变”的假设；线性插值适用于趋势较为平滑的序列；样条插值则适用于需要更平滑拟合的情况。

3. 提前和滞后

时间序列分析中，滞后（lag）和提前（lead）操作是构建预测模型的基础。

zoo包和xts包的操作：

library(zoo)


z <- zoo(1:10, as.Date(1:10))


# 滞后1期（将序列向后移动，即t期的值对应原序列t-1期的值）
lag(z, k = 1)


# 提前1期（将序列向前移动，即t期的值对应原序列t+1期的值）
lag(z, k = -1)

dplyr包的lag和lead：

对于数据框中的时间序列数据，dplyr包的lag()和lead()函数分别用于将向量滞后（向后移动）和提前（向前移动）指定的位置数。在数据框内创建时间序列的滞后/领先变量，且默认按行顺序操作，不依赖时间索引。

# 滞后1期
dplyr::lag(value, n = 1)


# 提前1期
dplyr::lead(value, n = 1)


dplyr::lag(value, n = -1) # t提示错误

4. 合并

基于时间索引的合并是时间序列数据整合的核心操作。

zoo的合并：

library(zoo)


z1 <- zoo(1:5, as.Date(c("2026-01-01", "2026-01-02", "2026-01-03",
                          "2026-01-04", "2026-01-05")))
z2 <- zoo(10:12, as.Date(c("2026-01-01", "2026-01-03", "2026-01-05")))


# 合并（默认外连接，缺失值填充NA）
merge(z1, z2)

xts的合并：

xts的merge()方法在zoo的基础上进行了C级优化，性能更高。xts还支持类似数据库的join操作：

library(xts)


x <- xts(1:5, as.Date("2026-01-01") + 0:4)
y <- xts(10:12, as.Date("2026-01-01") + c(0, 2, 4))


# 内连接（仅保留时间索引匹配的行）
merge(x, y, join = "inner")


# 左连接
merge(x, y, join = "left")


# 外连接（默认）
merge(x, y, join = "outer")  # 等同于 merge(x, y)

5. 聚合

聚合（aggregation）是将高频数据转换为低频数据的过程，是时间序列分析中的常见需求。

zoo的aggregate()方法将序列按照更粗的索引网格分割，对每个子集应用汇总函数，然后返回缩减后的zoo对象。

library(zoo)


# 创建日度数据
z_daily <- zoo(rnorm(365),
               order.by = seq.Date(from = as.Date("2025-01-01"),
                                   by = "day", length.out = 365))


# 按月聚合（计算月均值）
z_monthly <- aggregate(z_daily, by = as.yearmon, FUN = mean)


# 按季度聚合
z_quarterly <- aggregate(z_daily, by = as.yearqtr, FUN = sum)

对于xts对象，可以利用period.apply()或apply.daily()、apply.monthly()等系列函数进行聚合：

library(xts)


x <- xts(rnorm(365), order.by = seq.Date(from = as.Date("2025-01-01"),
                                          by = "day", length.out = 365))


# 按月聚合
apply.monthly(x, FUN = mean)


# 按周聚合
apply.weekly(x, FUN = sum)


# 自定义周期聚合
ep <- endpoints(x, on = "months")
period.apply(x, INDEX = ep, FUN = mean)

四、统计分析和建模

1. ARIMA模型

stats::arima() 是 R 语言基础包 stats 中用于拟合单变量（univariate）时间序列 ARIMA 模型的核心函数。其基本语法如下：

arima(x, order = c(0L, 0L, 0L),
      seasonal = list(order = c(0L, 0L, 0L), period = NA),
      xreg = NULL, include.mean = TRUE,
      transform.pars = TRUE,
      fixed = NULL, init = NULL,
      method = c("CSS-ML", "ML", "CSS"),
      ...)
  • x: 一个单变量时间序列。
  • order: 一个长度为3的数值向量 (p, d, q)，分别指定模型的自回归(AR)阶数、差分阶数和移动平均(MA)阶数。
  • seasonal: 一个列表，用于指定季节性ARIMA（SARIMA）模型。它包含两个组件：
    • order: 长度为3的向量 (P, D, Q)，含义与 order 类似，但作用于季节性部分。
    • period: 季节性周期。默认值为 frequency(x)。
  • xreg: 可选的外部回归变量（向量或矩阵），用于构建带有ARIMA误差的回归模型。
  • include.mean: 逻辑值，控制是否包含均值/截距项。
  • method: 拟合方法，可选 "CSS-ML"（默认，先条件最小二乘后最大似然）、"ML"（最大似然）或 "CSS"（条件最小二乘）。

功能与特点

  • 处理缺失值：与较旧的 arima0 函数不同，arima() 能精确处理差分后模型中的缺失值。

  • 包含外部变量：通过 xreg 参数，可以轻松构建带有ARIMA误差的回归模型（即 arimax 模型）。

  • 参数固定：通过 fixed 参数，可以固定模型中某些系数为特定值，只估计其他系数。

  • 参数变换：transform.pars = TRUE（默认）会对AR参数进行变换，以确保其始终落在平稳性区域内。

library(stats)


# 拟合一个 ARIMA(1,1,1) 模型
fit <- arima(AirPassengers, order = c(1, 1, 1))
summary(fit)


# 拟合一个带有季节性的 SARIMA(0,1,1)(0,1,1)₁₂ 模型
fit_sarima <- arima(log(AirPassengers),
                    order = c(0, 1, 1),
                    seasonal = list(order = c(0, 1, 1), period = 12))
summary(fit_sarima)

作为补充，forecast包的Arima()函数在stats::arima()基础上进行了改进，提供了更友好的接口和更丰富的输出。主要区别在于：forecast::Arima() 允许在模型包含差分时，通过 include.drift 参数包含一个漂移项（线性趋势）。forecast::Arima() 提供了 Box-Cox 变换等额外功能。

2. 平稳检验

ADF检验（Augmented Dickey-Fuller Test，增广迪基-福勒检验）是时间序列分析中用于判断序列是否平稳（即是否存在单位根）的一种统计检验方法。tseries::adf.test() 函数，是最常用、最简便的ADF检验函数之一。

library(tseries)     


adf.test(x, alternative = c("stationary", "explosive"),
         k = trunc((length(x)-1)^(1/3)))

其中： x：数值型向量或时间序列。 alternative：备择假设，默认为 "stationary"（平稳）。 k：计算检验统计量时使用的滞后阶数，默认值是一个基于数据长度的建议上限。



library(tseries)
# 对平稳序列进行检验
x <- rnorm(1000)
adf.test(x)


# 对非平稳（单位根）序列进行检验
y <- diffinv(x)
adf.test(y)

urca 是一个用于时间序列分析的 R 语言包，专注于执行单位根检验和协整分析。它是进行计量经济学分析，特别是处理金融、经济等时间序列数据的重要工具。其核心功能包括：

  • 单位根检验：用于检测时间序列数据是否平稳（即是否存在单位根）。主要函数包括：
    • ur.df(): 执行增广迪基-福勒 (Augmented Dickey-Fuller, ADF) 检验。
    • ur.pp(): 执行菲利普斯-佩龙 (Phillips-Perron) 检验。
    • ur.kpss(): 执行KPSS 检验，其原假设与ADF检验相反，为序列平稳。
  • 协整检验：用于分析多个非平稳时间序列之间是否存在长期稳定的均衡关系。
    • ca.jo(): 执行约翰森 (Johansen) 协整检验。

以下是一个使用 ur.df() 函数进行ADF单位根检验的简单示例：

library(urca)


# 假设你的时间序列数据为 y
# type: 指定模型形式
#   - "none": 无常数项和趋势项
#   - "drift": 有常数项
#   - "trend": 有常数项和趋势项
# lags: 指定滞后阶数
# selectlags: 可用 "AIC" 或 "BIC" 自动选择最优滞后阶数


# 示例：包含常数项和趋势项，最大滞后阶数设为3
test_result <- ur.df(y, type = "trend", lags = 3, selectlags = "AIC")
summary(test_result)

3. 协整分析

协整（Cointegration）分析用于检验多个非平稳时间序列之间是否存在长期稳定的均衡关系。urca 和 tseries 都是R语言中执行协整检验的核心包，但它们在方法论和功能侧重上有显著不同。简单来说：tseries 提供了一个基于残差的Phillips-Ouliaris (PO) 检验；而 urca 功能更全面，既提供了基于残差的PO检验，也提供了基于向量自回归 (VAR) 模型的Johansen 检验。后者是更为现代和主流的方法。

# urca包提供更完整的协整分析框架
library(urca)
ca.jo()  # Johansen协整检验
ca.po()  # Phillips-Ouliaris协整检验


# 使用tseries包的po.test进行协整检验
library(tseries)
po.test(x)  # x为包含多个时间序列的矩阵

urca 包（Unit Root and Cointegration Tests）提供了单位根和协整检验的完整工具集，其核心优势在于 Johansen 检验。

3.1. Johansen 检验：ca.jo() 函数

这是 urca 包最核心的函数，用于检验多个时间序列之间是否存在长期稳定的线性关系。

  • 核心参数：

    • x：待检验的数据矩阵。
    • type：检验统计量类型，可选择 "eigen"（最大特征值检验）或 "trace"（迹检验）。
    • ecdet：协整方程中确定性部分的形式，如 "none"（无）、"const"（有常数项）或 "trend"（有趋势项）。
    • K：VAR模型的滞后阶数。
    • spec：指定VECM（向量误差修正模型）的形式，"longrun" 或 "transitory"。
    • season 和 dumvar：用于包含季节虚拟变量或其他外生变量。

  • 结果解读： 运行 summary(ca.jo(...)) 后，主要关注 teststat（检验统计量）和 cval（临界值）。通过比较它们，可以判断在给定显著性水平下应拒绝多少个协整向量（即协整秩 r）的原假设。

3.2. Phillips-Ouliaris 检验：ca.po() 函数

与 tseries 包中的 po.test() 功能相同，但作为 urca 包的一部分，提供了更一致的输出格式和类结构。

  • 核心参数：
    • z：数据矩阵。
    • demean：是否包含截距项。
    • lag：用于方差-协方差修正的滞后阶数选择（"short" 或 "long"）。
    • type：检验统计量类型，"Pu" 或 "Pz"。

3.3.简洁的经典协整检验：tseries::po.test()函数

tseries 包主要通过 po.test() 函数提供 Phillips-Ouliaris 协整检验。

  • 核心函数：po.test(x, demean = TRUE, lshort = TRUE)
    • 原假设：x 不存在协整关系。
    • 参数：
      • x：一个矩阵或多变量时间序列。
      • demean：逻辑值，是否在协整回归中包含截距项。
      • lshort：逻辑值，用于控制计算残差方差时使用的截断滞后参数。
    • 原理：该函数通过对 x 的第一列对剩余列进行回归，然后对回归残差进行单位根检验（Phillips-Perron 类型），来判断是否存在协整关系。
  • 局限性：po.test() 一次最多只能处理六个变量，且其结果不如 Johansen 检验稳健和全面。

对于严谨的学术研究或复杂的实证分析，强烈推荐使用 urca 包。其 ca.jo() 函数提供的 Johansen 检验是行业标准，功能强大且结果可靠。对于快速、初步的探索性分析，或仅需使用经典的 PO 检验时，tseries 包的 po.test() 是一个简洁的选择。

4 GARCH族模型

金融时间序列通常表现出波动率聚集（volatility clustering）现象，广义自回归条件异方差（GARCH）模型是刻画这一特征的标准工具。在R语言中，实现GARCH族模型最主流、最强大的工具是 rugarch 包，此外 fGarch 和 tseries 包等也提供了相关功能。

4.1. rugarch 包

rugarch 是R中实现单变量GARCH模型的事实标准，支持 sGARCH、eGARCH、gjrGARCH、apARCH、iGARCH、FIGARCH 等数十种变体。

library(rugarch)


# 1. 模型设定（specification）
spec <- ugarchspec(
    variance.model = list(
        model = "sGARCH",        # 标准GARCH，可换为 "eGARCH", "gjrGARCH" 等
        garchOrder = c(1, 1)     # ARCH阶=1, GARCH阶=1
    ),
    mean.model = list(
        armaOrder = c(0, 0),     # 均值方程：常数均值（无ARMA项）
        include.mean = TRUE
    ),
    distribution.model = "norm"  # 误差分布："norm", "std", "ged", "snorm"等
)


# 2. 模型拟合
data(dmbp)  # 示例数据
fit <- ugarchfit(spec = spec, data = dmbp[, 1])


# 3. 查看结果
fit                      # 简要输出
coef(fit)                # 提取系数
sigma(fit)               # 提取条件标准差序列
head(sigma(fit))         # 查看前几项


# 4. 预测
forecast <- ugarchforecast(fit, n.ahead = 10)
forecast


# 更多模型选项


# EGARCH(1,1) 模型,可捕捉杠杆效应
spec_egarch <- ugarchspec(
    variance.model = list(model = "eGARCH", garchOrder = c(1, 1)),
    distribution.model = "std"   # 使用学生t分布
)
fit_egarch <- ugarchfit(spec_egarch, data)


# GJR-GARCH(1,1) 模型
spec_gjr <- ugarchspec(
    variance.model = list(model = "gjrGARCH", garchOrder = c(1, 1)),
    distribution.model = "ged"   # 广义误差分布
)
fit_gjr <- ugarchfit(spec_gjr, data)

5. forecast包

forecast 包是 R 语言中最主流的时间序列预测工具之一。它提供了一套完整且自动化的解决方案，用于分析、建模和预测单变量（univariate）时间序列数据。

核心功能包括：

功能类别 核心函数 说明
自动化建模 auto.arima() 自动搜索并拟合最优的ARIMA模型，根据AIC、AICc或BIC等准则进行选择。
指数平滑 ets() 实现指数平滑状态空间模型，自动选择最优的误差、趋势和季节性组合。
高级时间序列 tbats() 拟合TBATS模型，专门用于处理具有复杂季节性的时间序列（如多个季节周期）。
时间序列分解 stlf()、stlm() 基于STL（Seasonal-Trend decomposition using Loess）分解进行预测。
基础预测 naive()、snaive()、rwf()、meanf() 提供朴素法、季节性朴素法、随机游走、均值等基准预测方法。
其他模型 arfima() 拟合分数阶差分ARIMA（ARFIMA）模型。

forecast 包的典型工作流是：拟合模型 -> 生成预测 -> 可视化结果。以下是一些核心函数的用法示例：

  forecast() |>
  autoplot()

五、平滑和滤波

1. TTR包

TTR（Technical Trading Rules）包是R中金融技术分析的核心包，提供了非常丰富的平滑函数。这些函数大多数是基于移动平均思想设计的，主要用于处理价格、成交量等金融时间序列数据。

TTR包提供了多种移动平均函数，它们的核心参数通常包括： * x: 待平滑的时间序列数据。 * n: 移动平均的窗口期数。以下是主要的移动平均函数及其特点：

函数 全称 / 核心特点 简要说明
SMA() Simple Moving Average (简单移动平均) 计算过去n个观测值的算术平均值。
EMA() Exponential Moving Average (指数移动平均) 赋予近期数据更高权重的指数加权平均值。可通过wilder参数调整衰减方式。
WMA() Weighted Moving Average (加权移动平均) 通过wts参数自定义权重，权重可为线性或其他形式。
DEMA() Double Exponential Moving Average (双指数移动平均) 通过DEMA = (1+v)*EMA(x) - EMA(EMA(x))*v公式，旨在减少滞后。
HMA() Hull Moving Average (赫尔移动平均) 通过加权平均的差值计算，响应速度非常快，几乎消除了滞后。
VWAP() / VWMA() Volume-Weighted Average Price (成交量加权平均价格) 计算成交量加权的平均价格，常用于衡量交易效率。

TTR包还提供了一系列高性能的滚动窗口计算函数，如runMean（滚动均值）、runMedian（滚动中位数）、runSD（滚动标准差）等，这些也是实现数据平滑的常用工具。

2. HP滤波

在R中实现HP（Hodrick-Prescott）滤波，主要有以下几个包和函数：

包名 核心函数 特点与适用场景
hpfilter hp1() (单边), hp2() (双边) 专门为HP滤波设计，功能专注。hp1()基于卡尔曼滤波，适用于需要实时更新的场景（如巴塞尔III协议中的信贷缺口计算）。 hp2()使用稀疏矩阵，处理大数据集时效率更高。
mFilter hpfilter() 多功能滤波包，集成了HP、BK、CF等多种滤波器。适合需要对比多种滤波方法的研究场景。注意：此函数实现的是双边HP滤波。
mhpfilter hp_filter() 提供标准HP滤波，特点是能通过广义交叉验证（GCV）自动选择最优平滑参数λ。若不确定λ值，此包可提供数据驱动的选择建议。
jumps hpfj(), auto_hpfj() HP滤波的扩展版本，允许趋势中包含自动识别的跳跃或断点。适用于处理存在结构性突变的经济时间序列。

2.1. 使用 hpfilter 包

这是最专门的实现，安装和用法如下：

# 安装并加载包
install.packages("hpfilter")
library(hpfilter)


# 示例：假设 y 是你的时间序列数据（向量或数据框）
# 使用双边HP滤波，lambda=1600（季度数据常用值）
yt <- hp2(y, lambda = 1600)  # 提取趋势项
yc <- y - yt                 # 计算周期项（残差）

对于单边滤波，只需将 hp2 替换为 hp1 即可。lambda参数的常用取值是：年度数据100，季度数据1600，月度数据14400。

2.2. 使用 mFilter 包

这个包提供了一个统一的接口，适合快速上手：

# 安装并加载包
install.packages("mFilter")
library(mFilter)


# 对时间序列对象应用HP滤波
result <- mFilter(y, filter = "HP", lambda = 1600)


# 查看结果
trend <- fitted(result)   # 趋势成分
cycle <- residuals(result) # 周期成分

mFilter包的输入数据y最好是ts（时间序列）对象。

2.3. 使用 mhpfilter 包

如果希望自动选择lambda，可以使用这个包：

# 安装并加载包
install.packages("mhpfilter")
library(mhpfilter)


# 使用默认lambda=1600进行分解
result <- hp_filter(y, lambda = 1600)


# 结果会以data.table格式返回，包含原始数据、趋势和周期项
print(result)

此外，mhpfilter包还提供了mhp_filter()函数，可通过GCV自动选择最优的lambda值。

3. 卡尔曼滤波

在R中实现卡尔曼滤波（Kalman Filter）的包和函数同样非常丰富。其中，KFAS 和 dlm 是两个最核心、功能最全面的选择。

3.1. KFAS 包

功能最全面、最强大。支持指数族分布（如泊松、二项式）的状态空间模型。采用精确扩散初始化处理非平稳序列，计算效率高。适合需要处理复杂模型（如非高斯数据）的研究场景。

# 安装并加载包
install.packages("KFAS")
library(KFAS)


# 定义一个简单的局部水平模型 (Local Level Model)
# 观测方程: y_t = mu_t + eps_t, eps_t ~ N(0, H)
# 状态方程: mu_{t+1} = mu_t + eta_t, eta_t ~ N(0, Q)
model <- SSModel(y ~ SSMtrend(degree = 1, Q = matrix(NA)), H = matrix(NA))
# 注意：这里的 y 是你的时间序列数据（向量或矩阵）


# 使用 KFS 函数进行卡尔曼滤波和平滑
# 通过 updatefn 和 method 参数可以估计模型中的未知参数 (H 和 Q)
fit <- KFS(model, filtering = "state", smoothing = "state")


# 提取结果
trend <- fitted(fit)   # 状态（趋势）的滤波值
residuals <- residuals(fit) # 残差

3.2. dlm 包

最经典、最易上手的入门之选，专注于正态线性状态空间模型。提供了从模型构建、滤波(dlmFilter)到平滑(dlmSmooth)、参数估计（dlmMLE）和贝叶斯分析的一整套工具。

# 安装并加载包
install.packages("dlm")
library(dlm)


# 构建一个简单的局部水平模型
# 观测方程: y_t = mu_t + v_t, v_t ~ N(0, V)
# 状态方程: mu_t = mu_{t-1} + w_t, w_t ~ N(0, W)
buildModel <- function(params) {
  dlmModPoly(order = 1, dV = exp(params[1]), dW = exp(params[2]))
}


# 假设 y 是你的时间序列数据 (ts 对象)
# 使用 dlmMLE 估计模型参数 (V 和 W)
fit <- dlmMLE(y, parm = c(0, 0), build = buildModel)
mod <- buildModel(fit$par)


# 进行卡尔曼滤波和平滑
filtered <- dlmFilter(y, mod)
smoothed <- dlmSmooth(filtered)


# 提取结果
trend_filtered <- filtered$m[-1] # 状态的滤波值
trend_smoothed <- smoothed$s[-1] # 状态的平滑值

3.3. FKF 包

追求极致速度。完全用C语言编写，并调用BLAS/LAPACK线性代数库。FKF.SP是其升级版，采用序贯处理（Sequential Processing） 进一步提升效率。适合处理高维、大规模数据集。

# 安装并加载包
install.packages("FKF")
library(FKF)


# 定义状态空间模型的各个矩阵
# 详细参数含义请参考文档，此处仅为示意
a0 <- matrix(0, nrow = 1)  # 初始状态
P0 <- matrix(100, nrow = 1) # 初始状态协方差
dt <- matrix(0)            # 状态方程截距
ct <- matrix(0)            # 观测方程截距
Tt <- matrix(1)            # 状态转移矩阵
Zt <- matrix(1)            # 观测矩阵
HHt <- matrix(1)           # 状态方程误差协方差
GGt <- matrix(1)           # 观测方程误差协方差
yt <- t(y)                 # 观测数据，需转换为矩阵，每一列是一个时间点


# 执行快速卡尔曼滤波
fkf_obj <- fkf(a0, P0, dt, ct, Tt, Zt, HHt, GGt, yt)


# 查看滤波结果
filtered_state <- fkf_obj$att # 状态的滤波值

3.4. kalmanfilter包

基于Rcpp和RcppArmadillo实现，特点在于能轻松处理缺失值和外生变量（解释变量），并支持时变参数。

实践建议：

  • 功能全面、处理复杂模型，首选 KFAS。它功能最强大，能处理非高斯模型。

  • 入门学习、快速上手，推荐 dlm。它是经典的“教科书”级实现，语法清晰，文档丰富。

  • 处理超大规模数据，考虑 FKF 或 FKF.SP。它们的C语言后端提供了卓越的计算性能。

  • 数据预处理复杂，含缺失值/外生变量。kalmanfilter 提供了便捷的解决方案。

六、隐含马可夫模型

在金融与投资领域，R语言主要通过fHMM和depmixS4这两个核心包来处理隐马尔可夫模型（HMM）。其中 fHMM 是专门为金融数据分析而设计的首选。

1. fHMM

fHMM (Fitting Hidden Markov Models to Financial Data) 是专门为分析和识别金融市场“状态”或“制度”（regimes）而开发的R包。

核心功能：

  • 市场制度检测：能识别时间序列数据中的不同市场状态，如“牛市”、“熊市”或“震荡市”。
  • 层级模型支持：支持层级隐马尔可夫模型（HHMM），可同时分析不同频率的数据（如日线和月线）。
  • 完整工作流：提供从数据下载、模型定义、参数估计、状态解码到预测的完整工具链。

典型工作流如下：

  1. 设置与控制 (set_controls)：定义模型参数，如状态数(states)、状态依赖分布(sdds)等。

  2. 数据准备 (prepare_data)：将原始数据转换为模型所需的格式。

  3. 模型拟合 (fit_model)：执行模型参数的最大似然估计。

  4. 状态解码 (decode_states)：使用Viterbi算法推断每个时间点最可能的状态。

  5. 结果分析 (summary, plot)：查看模型摘要、参数估计和状态概率等。

  6. 模型预测 (predict)：基于当前状态，对未来观测值进行预测。

# 安装
install.packages("fHMM")


# 基本工作流示例 (以德国DAX指数为例)
library(fHMM)


# 1. 下载数据
dax <- download_data(symbol = "^GDAXI")


# 2. 设置模型参数 (例如：3个状态，t分布)
controls <- set_controls(
  states = 3,
  sdds = "t",
  file = dax,
  date_column = "Date",
  data_column = "Close",
  logreturns = TRUE,
  from = "2000-01-01",
  to = "2022-12-31"
)


# 3. 准备数据
data <- prepare_data(controls)


# 4. 拟合模型
model <- fit_model(data)


# 5. 解码隐藏状态 (使用Viterbi算法)
model <- decode_states(model)


# 6. 查看结果
summary(model)

2. depmixS4

在进行专业的金融制度识别与分析，首选 fHMM 包。若需要进行更通用、定制化的HMM研究，depmixS4 包是更加强大的基础工具。它是一个应用广泛的HMM框架，支持多种数据分布，可用于金融时间序列分析。

fHMM 包和depmixS4 包的对比

特性 fHMM depmixS4
主要定位 专为金融数据设计，是领域专用包。 通用HMM框架，功能全面灵活。
核心功能 拟合（分层）HMM，专注于识别金融市场制度（如牛市/熊市）。 拟合带协变量的HMM，支持多种分布和混合模型。
特色亮点 支持分层HMM，可同时分析不同时间尺度（如日频和月频）的数据。 灵活性极高，可自定义转移矩阵、响应分布等。
安装方式 install.packages("fHMM") install.packages("depmixS4")
学术参考 Oelschläger & Adam (2021); Oelschläger et al. (2024) Visser & Speekenbrink (2010)

实践建议：

两个包为将隐马尔可夫模型应用于量化金融研究和实践提供了坚实的基础。进行专业的金融制度识别与分析，如识别市场状态（如牛熊市） 或进行分层建模，fHMM是首选。进行更通用、定制化的HMM研究，depmixS4 包是强大的基础工具。
