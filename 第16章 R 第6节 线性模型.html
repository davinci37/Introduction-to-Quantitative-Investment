第16章 R 第6节 线性模型

一、引言

线性模型（Linear Model）是统计学和数据分析中最核心的建模工具之一。无论是探索变量之间的定量关系，还是构建预测系统，线性回归模型都因其简洁性、可解释性和坚实的理论根基而占据不可替代的地位。

R语言作为数据科学领域的通用语言，为线性模型的构建、诊断、扩展与优化提供了极为完备的工具链。本文将从投资经理的视角出发，系统阐述R语言在线性模型各环节中的应用，涵盖模型设定、参数估计、统计推断、诊断检验、模型选择及高级扩展方法。

线性模型的基本形式可表示为：

\[y_i = \beta_0 + \beta_1 x_{i1} + \beta_2 x_{i2} + \cdots + \beta_p x_{ip} + \varepsilon_i, \quad i = 1, 2, \ldots, n\]

其中，\(y_i\)为响应变量（因变量），\(x_{i1}, \ldots, x_{ip}\)为预测变量（自变量），\(\beta_0\)为截距项，\(\beta_1, \ldots, \beta_p\)为回归系数，\(\varepsilon_i\)为随机误差项。模型的核心假设包括：线性关系（响应变量与预测变量之间呈线性关系）、误差独立同分布、误差服从均值为零的正态分布、以及同方差性（即误差的方差恒定）。

在投资分析的实践中，线性模型广泛应用于因子收益预测、资产定价模型、宏观经济变量关系建模以及风险度量等场景。

二、一般线性模型

1. 函数语法与参数

R语言中拟合线性模型的核心函数是lm()，它属于基础包stats。其基本语法为：

lm(formula, data, subset, weights, na.action, method = "qr",
   model = TRUE, x = FALSE, y = FALSE, qr = TRUE,
   singular.ok = TRUE, contrasts = NULL, offset, ...)

各主要参数的含义如下：

  • formula：模型公式的符号描述，形如y ~ x1 + x2，用于指定响应变量与预测变量之间的关系。
  • data：包含模型变量的可选数据框。
  • subset：指定用于拟合的观测子集。
  • weights：权重向量，用于加权最小二乘估计。
  • na.action：指定数据中包含缺失值时的处理方式，默认为na.omit。
  • method：拟合方法，目前仅支持"qr"（QR分解）。
  • singular.ok：逻辑值，控制是否允许奇异拟合。

2. 公式的符号体系

lm()的公式语法提供了高度灵活的模型规格说明能力：

  • y ~ x：简单线性回归
  • y ~ x1 + x2：多元线性回归（加性模型）
  • y ~ x1:x2：仅包含交互项
  • y ~ x1 * x2：等价于x1 + x2 + x1:x2，包含主效应和交互效应
  • y ~ .：使用数据框中除y之外的所有变量作为预测变量
  • y ~ I(x^2)：在公式中嵌入数学变换

3. 示例

3.1. 简单线性回归

以下通过身高与体重的示例展示lm()的基本用法：

# 样本数据
height <- c(151, 174, 138, 186, 128, 136, 179, 163, 152, 131)
weight <- c(63, 81, 56, 91, 47, 57, 76, 72, 62, 48)


# 拟合线性模型
model <- lm(weight ~ height)
print(model)

输出结果显示截距为-38.4551，斜率为0.6746，表明身高每增加1个单位，体重平均增加0.6746个单位。

3.2. 多元线性回归实战

以R内置数据集mtcars为例，建立每加仑里程数（mpg）与发动机排量（disp）、马力（hp）和车重（wt）之间的多元回归模型：

data(mtcars)
input <- mtcars[, c("mpg", "disp", "hp", "wt")]
model <- lm(mpg ~ disp + hp + wt, data = input)
summary(model)

拟合得到的回归方程为：

\[\hat{y} = 37.1055 - 0.000937 \cdot x_{disp} - 0.03116 \cdot x_{hp} - 3.8009 \cdot x_{wt}\]

该模型可用于对新样本进行预测。例如，对于一辆disp=221、hp=102、wt=2.91的汽车，预测里程为22.71英里/加仑。

4. 模型输出解读与统计推断

4.1 summary()函数的输出详解

对拟合后的模型对象调用summary()，可获得模型的详细统计摘要：

summary(model)

输出内容主要包括：

  1. 残差统计量（Residuals）：最小、第一四分位、中位数、第三四分位和最大值，用于初步判断残差分布。
  2. 系数估计表（Coefficients）：包含每个回归系数的估计值、标准误、t统计量和p值。
  3. 拟合优度：包括决定系数\(R^2\)和调整\(R^2\)，用于衡量模型对数据的解释程度。
  4. 模型整体显著性：F统计量及其p值，检验所有回归系数是否同时为零。

4.2 系数的解释

在简单线性回归中，截距（Intercept）表示当所有预测变量为零时响应变量的期望值；斜率（Slope）表示预测变量每增加一个单位时响应变量的平均变化量。需要特别注意的是，当预测变量的零值在现实中无意义时，截距的解释应谨慎对待。

在多元回归中，每个回归系数表示在其他变量保持不变的情况下，该预测变量每变化一个单位对响应变量的边际影响（即偏回归系数）。

5. 模型诊断与假设检验

线性模型的有效性依赖于若干关键假设。R语言提供了丰富的诊断工具来检验这些假设。

5.1 残差分析

残差分析是模型诊断的核心。基础R通过plot(lm_object)可自动生成四组诊断图：

par(mfrow = c(2, 2))
plot(model)

这四张图分别为： - 残差与拟合值图：检验线性关系和同方差性 - 正态Q-Q图：检验残差的正态性 - 尺度-位置图：检验同方差性 - 残差与杠杆图：识别强影响点

5.2 假设的统计检验

更为严格的诊断可通过专门的统计检验完成：

  • 线性关系检验：可通过将连续预测变量视为分类变量的F检验来评估。
  • 同方差性检验：Breusch-Pagan检验可用于诊断异方差问题。
  • 正态性检验：Shapiro-Wilk检验（样本量<5000时）或Kolmogorov-Smirnov检验（大样本时）用于检验残差正态性。
library(lmtest)
library(car)


# Breusch-Pagan检验（异方差）
bptest(model)


# 方差膨胀因子（多重共线性）
vif(model)


# Shapiro-Wilk正态性检验
shapiro.test(residuals(model))

5.3 多重共线性诊断

多重共线性是指预测变量之间存在高度相关性，会导致回归系数估计不稳定、标准误膨胀。方差膨胀因子（VIF）是诊断多重共线性的常用指标。一般认为VIF大于10表明存在严重的多重共线性问题。

5.4 异常值、高杠杆点与强影响点识别

  • 离群点：残差绝对值较大的观测值
  • 高杠杆点：预测变量空间中远离中心的观测值，可通过帽子值（hat values）识别
  • 强影响点：对回归系数估计产生较大影响的观测值，常用Cook距离度量
# 帽子值（杠杆值）
hatvalues(model)


# Cook距离
cooks.distance(model)

6. 模型比较与变量选择

6.1 嵌套模型的方差分析比较

对于嵌套模型（即一个模型是另一个模型的特殊情况），可使用anova()函数进行F检验，比较模型的拟合优度是否存在显著差异：

model1 <- lm(mpg ~ wt, data = mtcars)
model2 <- lm(mpg ~ wt + hp, data = mtcars)
anova(model1, model2)

该检验通过比较两个模型的残差平方和变化来判断增加变量是否显著改善了模型拟合。

6.2 基于信息准则的变量选择

AIC（Akaike Information Criterion）和BIC（Bayesian Information Criterion）是变量选择中广泛使用的准则。step()函数可基于AIC进行逐步回归：

# 逐步回归（基于AIC）
step_model <- step(model, direction = "both")

此外，StepReg包提供了更为系统的逐步回归分析框架，支持AIC、AICc、BIC、Cp、调整\(R^2\)等多种选择准则。

7. 预测与区间估计

7.1 点预测

使用predict()函数可基于拟合模型对新数据进行预测：

new_data <- data.frame(disp = 221, hp = 102, wt = 2.91)
predict(model, newdata = new_data)

7.2 置信区间与预测区间

predict()函数通过interval参数可同时输出置信区间（均值的区间估计）和预测区间（个体值的区间估计）：

# 置信区间
predict(model, newdata = new_data, interval = "confidence", level = 0.95)


# 预测区间
predict(model, newdata = new_data, interval = "prediction", level = 0.95)

预测区间通常比置信区间更宽，因为它包含了模型误差的额外不确定性。

R语言为线性模型的完整分析流程提供了系统而强大的工具支持。在投资分析的实务中，熟练掌握这些工具意味着能够更加严谨地进行因子筛选、模型验证、风险预测和策略回测。然而，值得强调的是，任何统计工具的价值都取决于使用者的理论素养和业务理解。模型的构建不应沦为单纯的”数据挖掘”，而应在坚实的经济学或金融学理论指导下，将R语言的分析能力与投资逻辑深度融合，方能在复杂多变的市场环境中做出经得起检验的量化决策。

三、广义线性模型

1. 理论框架

广义线性模型（Generalized Linear Model, GLM）是经典线性回归模型的重要推广。它通过引入连接函数（link function）和允许响应变量服从指数分布族中的任意分布，极大地拓展了线性模型的适用范围。

GLM由三个核心组件构成：

随机组件（Random Component） ：指定响应变量(Y)的条件分布，属于指数分布族。常用分布包括正态分布（Gaussian）、二项分布（Binomial）、泊松分布（Poisson）和伽玛分布（Gamma）等。

系统组件（Systematic Component） ：预测变量的线性组合，即：\(\eta = \beta\_0 + \beta\_1 x_1 + \cdots + \beta\_p x_p\)。

连接函数（Link Function） ：连接随机组件与系统组件的桥梁，将响应变量的期望值\(\mu = E(Y)\)与线性预测子\(\eta\)联系起来：\(g(\mu) = \eta\)。连接函数的选择取决于响应变量的分布特性。

与普通线性回归相比，GLM的核心优势在于：响应变量不必服从正态分布，也不必满足方差齐性假设。

2. glm()函数详解

2.1 函数语法

R语言中构建GLM的核心函数是glm()，其基本语法为：

glm(formula, family = gaussian, data, weights, subset,
    na.action, start, offset, control, model = TRUE,
    method = "glm.fit", x = FALSE, y = TRUE, contrasts = NULL, ...)

各主要参数含义如下：

  • formula：模型公式，如y ~ x1 + x2
  • family：指定响应变量的分布族和连接函数，是GLM与lm()最核心的区别参数
  • data：包含模型变量的数据框
  • weights：观测权重向量，用于加权似然估计
  • subset：指定用于拟合的观测子集
  • na.action：缺失值处理方式
  • start：迭代优化的初始参数值
  • offset：模型中固定的偏移项
  • control：控制迭代过程参数（如最大迭代次数、收敛阈值）

2.2 family参数详解

family参数是glm()的核心，它通过一个列表对象指定了响应变量的分布族和连接函数。R语言内置的family对象及默认连接函数如下：

分布族 默认连接函数 适用场景
gaussian() identity 连续、对称数据（等价于线性回归）
binomial() logit 二分类/比例数据（逻辑斯谛回归）
poisson() log 计数数据
Gamma() inverse 正连续、右偏数据
inverse.gaussian() 1/mu^2 正连续、高度偏斜数据
quasi() identity 自定义方差-均值关系
quasibinomial() logit 过度离散的二项数据
quasipoisson() log 过度离散的计数数据

每种分布族还支持替代连接函数，例如binomial()可选用probit、cauchit、log、cloglog等；poisson()可选用identity、sqrt等。

规范连接函数（Canonical Link） 是每个分布族的默认连接函数，具有良好的数学性质。在实践中，除非有特殊的理论依据，通常使用规范连接函数即可。唯一的常见例外是Gamma族，有时会使用link="log"而非默认的inverse。

3. 主要GLM类型及应用

3.1 逻辑斯谛回归（Logistic Regression）

当响应变量为二分类（如违约/不违约、上涨/下跌）时，使用family = binomial(link = "logit")。逻辑斯谛回归中，连接函数为logit：\(\log(\frac{p}{1-p}) = \beta\_0 + \beta\_1 x_1 + \cdots\)。

标准建模流程：

# 二分类逻辑斯谛回归
fit_logit <- glm(y ~ x1 + x2 + x3,
                 data = mydata,
                 family = binomial(link = "logit"))


summary(fit_logit)                      # 模型摘要
confint(fit_logit)                      # 回归系数的95%置信区间
exp(coef(fit_logit))                    # 优势比（Odds Ratio）
exp(confint(fit_logit))                 # 优势比的置信区间
predict(fit_logit, type = "response")   # 预测概率

在投资分析中，逻辑斯谛回归广泛应用于信用风险建模（违约概率预测）、市场方向判断（涨跌预测）和事件驱动策略的信号生成。

关于二项分布响应的三种输入形式： 1. 二值向量（0/1） 2. 两列矩阵（成功次数/失败次数） 3. 因子变量（两个水平）

3.2 泊松回归（Poisson Regression）

当响应变量为计数数据（如交易次数、违约次数、索赔次数）时，使用family = poisson(link = "log")。泊松回归中，(() = _0 + _1 x_1 + )，其中()为计数期望值。

# 泊松回归
fit_poisson <- glm(count ~ x1 + x2 + x3,
                   data = mydata,
                   family = poisson(link = "log"))


summary(fit_poisson)
exp(coef(fit_poisson))  # 发生率比（Incidence Rate Ratio）

在精算与风险管理中，泊松回归常用于保险索赔次数建模、操作风险损失事件频率分析等场景。

4. 模型结果解读

对GLM对象调用summary()可获得详细的统计摘要：

summary(fit_logit)

输出内容包括：

  1. 偏差残差（Deviance Residuals） 的统计量：最小值、四分位数、最大值
  2. 系数估计表：估计值、标准误、z统计量和p值
  3. 偏差统计量（Deviance） ：模型的残差偏差和零偏差
  4. AIC（Akaike Information Criterion）：用于模型比较

与线性模型不同，GLM的系数解释依赖于连接函数：

  • 逻辑斯谛回归：系数取指数后解释为优势比（Odds Ratio）

  • 泊松回归：系数取指数后解释为发生率比（Incidence Rate Ratio）

  • 伽玛回归：系数解释取决于所选的连接函数

嵌套模型的比较可使用anova()函数，对于GLM通常采用卡方检验：

anova(fit1, fit2, test = "Chisq")

5. 模型诊断

GLM的诊断比线性模型更为复杂。R语言提供了多种诊断工具：

5.1 残差类型

GLM定义了多种残差类型：

residuals(fit, type = "deviance")   # 偏差残差（默认）
residuals(fit, type = "pearson")    # 皮尔逊残差
residuals(fit, type = "working")    # 工作残差
residuals(fit, type = "response")   # 响应残差

5.2 诊断图

基础R的plot()方法对GLM对象仍可产生诊断图，但对于二项数据等特殊情形，解释需谨慎：

par(mfrow = c(2, 2))
plot(fit_logit)

更先进的诊断可使用第三方包： - performance::check_model()：提供全面的GLM诊断可视化 - DHARMa包：基于模拟的残差诊断，特别适用于GLM

library(DHARMa)
simulation_output <- simulateResiduals(fit_logit, plot = TRUE)

5.3 拟合优度

对于GLM，传统的(R^2)不再适用。常用的替代指标包括： - 偏差（Deviance）的比较 - 实际值与预测值的相关系数：cor(observed, predict(model, type = "response")) - 伪(R^2)（如McFadden’s (R^2)）

6. 实战案例：信用违约预测

以下通过一个完整的逻辑斯谛回归案例展示GLM在投资领域的应用：

# 1. 数据准备（模拟数据）
set.seed(2026)
n <- 1000
default <- rbinom(n, 1, 0.15)
income <- rnorm(n, 50000, 15000)
debt_ratio <- runif(n, 0.1, 0.8)
credit_score <- rnorm(n, 700, 50)


df <- data.frame(default, income, debt_ratio, credit_score)


# 2. 模型拟合
fit_default <- glm(default ~ income + debt_ratio + credit_score,
                   data = df,
                   family = binomial(link = "logit"))


# 3. 模型摘要
summary(fit_default)


# 4. 优势比解释
exp(coef(fit_default))


# 5. 过度离散检查
dispersion <- deviance(fit_default) / df.residual(fit_default)
cat("Dispersion ratio:", round(dispersion, 4), "\n")


# 6. 模型预测
new_borrower <- data.frame(income = 45000,
                           debt_ratio = 0.45,
                           credit_score = 680)
pred_prob <- predict(fit_default, newdata = new_borrower,
                     type = "response")
cat("Predicted default probability:", round(pred_prob, 4), "\n")


# 7. 模型比较（嵌套模型）
fit_reduced <- glm(default ~ income + credit_score,
                   data = df,
                   family = binomial)
anova(fit_reduced, fit_default, test = "Chisq")

R语言的glm()函数为广义线性模型提供了统一而强大的实现框架。GLM家族覆盖了投资分析中绝大多数非正态响应变量的建模需求。在实务应用中，模型的选择应基于响应变量的数据特征和业务问题的理论约束。逻辑斯谛回归适用于二分类预测（如违约概率），泊松回归适用于频率建模（如交易次数），伽玛回归适用于严重程度建模（如损失金额）。理解每种分布族的假设及其对推断结论的影响，是构建可靠量化模型的根本前提。

四、变量筛选

1. 引言

变量筛选（Variable Selection）是回归建模中重要的环节。当候选预测变量较多时，并非所有变量都对响应变量具有显著的解释能力。部分变量可能冗余、存在多重共线性，或仅仅是噪声。盲目保留所有变量不仅会降低模型的可解释性，还会导致过拟合，损害模型的泛化能力。

前进法（Forward Selection） 和后退法（Backward Elimination） 是两类最经典的逐步变量筛选策略。R语言通过stats基础包的step()函数、MASS包的stepAIC()函数以及StepReg等专门包，为这两种方法提供了完善的支持。

2. 前进法（Forward Selection）

2.1 原理与流程

前进法从空模型（仅包含截距项）开始，逐步向模型中添加变量。每一步中，算法评估所有尚未进入模型的候选变量，选择使模型拟合优度提升最大（如AIC下降最多或p值最小）的那个变量加入模型。该过程持续进行，直到没有新的变量能够显著改善模型为止。

前进法的核心逻辑可概括为：

  • 初始化：模型仅含截距项
  • 迭代：在每一步中，遍历所有未被选入的变量，逐一尝试加入模型
  • 选择：选取使某个预定义准则（如AIC、BIC或p值）最优的变量加入
  • 终止：当无变量能继续改善模型时停止

2.2 前进法的特点

  • 计算效率较高：相对于后退法，通常需要评估的模型数量较少
  • 适用于高维数据：当预测变量数量远多于样本量（\(p \gg n\)）时，前进法是少数可行的选择之一
  • 局限性：一旦某个变量被加入模型，后续不会被移除（“一步错，步步错”的风险）

3.后退法（Backward Elimination）

3.1 原理与流程

后退法与前进法方向相反，从全模型（包含所有候选变量）开始，逐步移除变量。每一步中，算法评估当前模型中的每一个变量，选择对模型贡献最小（如移除后AIC下降最多或p值最大）的那个变量予以剔除。该过程持续进行，直到移除任何变量都会显著损害模型为止。

后退法的核心逻辑可概括为：

  • 初始化：模型包含所有候选变量
  • 迭代：在每一步中，评估当前模型中的每个变量
  • 剔除：移除使某个预定义准则最优的变量
  • 终止：当无变量可被移除时停止

3.2 后退法的特点

  • 考虑了变量间的联合效应：由于起始于全模型，后退法在每一步都能评估各变量在其他所有变量存在时的贡献
  • 计算成本较高：当候选变量数量庞大时，全模型可能无法拟合（特别是在\(p > n\)时）
  • 局限性：一旦某个变量被移除，后续不会被重新加入

4. R语言实现

4.1 基础函数：step()

R基础包stats中的step()函数是执行前进法和后退法最直接的工具。其核心参数为direction，可取值为"forward"（前进法）、"backward"（后退法）或"both"（逐步法，即前进与后退交替进行）。

前进法示例（以mtcars数据集为例，预测mpg）：

# 前进法：从空模型开始
null_model <- lm(mpg ~ 1, data = mtcars)
full_formula <- mpg ~ cyl + disp + hp + drat + wt + qsec + vs + am + gear + carb


forward_model <- step(null_model,
                      scope = full_formula,
                      direction = "forward")

scope参数定义了模型搜索的范围，即候选变量的全集。若不指定scope，step()默认使用当前模型作为上限。

后退法示例：

# 后退法：从全模型开始
full_model <- lm(mpg ~ ., data = mtcars)


backward_model <- step(full_model,
                       direction = "backward")

当scope参数缺失时，step()的direction默认值为"backward"。

逐步法（双向筛选） ：

# 逐步法：前进与后退交替
stepwise_model <- step(full_model,
                       direction = "both")

在"both"模式下，算法在每一步既考虑添加新变量，也考虑移除已有变量，实现了更灵活的搜索。

4.2 基于BIC的筛选

step()函数默认使用AIC（赤池信息准则）作为模型比较的准则。若希望使用BIC（贝叶斯信息准则），可通过k = log(n)参数调整惩罚项：

n <- nrow(mtcars)


# 使用BIC进行后退法筛选
bic_backward <- step(full_model,
                     direction = "backward",
                     k = log(n))

4.3 进阶函数：stepAIC()

MASS包中的stepAIC()函数功能与step()类似，但在某些场景下提供了更强的鲁棒性：

library(MASS)


# 前进法
forward_aic <- stepAIC(null_model,
                       scope = full_formula,
                       direction = "forward")


# 后退法
backward_aic <- stepAIC(full_model,
                        direction = "backward")

stepAIC()与step()的主要区别在于其对某些模型类（如广义线性模型）的处理更为稳健。

4.4 综合包：StepReg

StepReg包提供了更为系统化的逐步回归分析框架，支持线性回归、Logistic回归、Cox回归、泊松回归、Gamma回归和负二项回归等多种模型类型：

library(StepReg)


# 前进法（线性回归）
result_forward <- stepwise(formula = mpg ~ .,
                           data = mtcars,
                           type = "linear",
                           strategy = "forward",
                           metric = "AIC")


# 后退法
result_backward <- stepwise(formula = mpg ~ .,
                            data = mtcars,
                            type = "linear",
                            strategy = "backward",
                            metric = "BIC")

StepReg的优势在于支持多种选择准则（AIC、AICc、BIC、CP、HQ、调整\(R^2\)等），并提供了数据分割选项以避免统计推断的无效性问题。

4.5 GLM的变量筛选

对于广义线性模型（GLM），step()和stepAIC()同样适用：

# Logistic回归的前进法变量筛选
full_glm <- glm(default ~ ., data = credit_data, family = binomial)
null_glm <- glm(default ~ 1, data = credit_data, family = binomial)


forward_glm <- step(null_glm,
                    scope = formula(full_glm),
                    direction = "forward")

glmtoolbox包中的stepCriterion()函数也为GLM提供了专门的变量筛选功能，支持AIC、BIC、调整\(R^2\)、Mallows’ Cp等多种准则。

5.完整实战案例

以下通过模拟数据展示前进法与后退法的完整工作流程及结果对比：

# 1. 加载数据
library(MASS)
data(Boston)
set.seed(2026)


# 2. 准备训练集与测试集
train_idx <- sample(1:nrow(Boston), 400)
train <- Boston[train_idx, ]
test <- Boston[-train_idx, ]


# 3. 前进法
null_model <- lm(medv ~ 1, data = train)
full_formula <- medv ~ crim + zn + indus + chas + nox + rm + age +
                dis + rad + tax + ptratio + black + lstat


forward_result <- step(null_model,
                       scope = full_formula,
                       direction = "forward",
                       trace = TRUE)  # trace=TRUE可查看每一步的详细信息


# 4. 后退法
full_model <- lm(medv ~ ., data = train)
backward_result <- step(full_model,
                        direction = "backward",
                        trace = TRUE)


# 5. 查看最终选中的变量
cat("前进法选中的变量:", names(coef(forward_result))[-1], "\n")
cat("后退法选中的变量:", names(coef(backward_result))[-1], "\n")


# 6. 测试集预测性能比较
pred_forward <- predict(forward_result, newdata = test)
pred_backward <- predict(backward_result, newdata = test)


mse_forward <- mean((test$medv - pred_forward)^2)
mse_backward <- mean((test$medv - pred_backward)^2)


cat("前进法测试集MSE:", round(mse_forward, 4), "\n")
cat("后退法测试集MSE:", round(mse_backward, 4), "\n")


# 7. 查看筛选过程的详细信息
summary(forward_result)
summary(backward_result)

6. 方法比较与注意事项

6.1 前进法与后退法的对比

维度 前进法 后退法
起始模型 空模型（仅截距） 全模型（所有变量）
适用场景 \(p > n\) 或变量数较多 \(n > p\) 且全模型可拟合
计算量 通常较小 通常较大
变量间交互 无法在后续步骤中调整已选变量 每一步都能重新评估所有变量
风险 早期加入的”坏变量”无法移除 早期移除的”好变量”无法召回

重要提示：前进法和后退法可能不会收敛到同一个最终模型。在实证分析中，两种方法的结果往往存在差异，这正是它们各自局限性的体现。

6.2 统计学家的提醒

需要特别强调的是，前进法、后退法和逐步回归在统计学家中并不被普遍推崇。主要原因包括：

  • 多重检验问题：每一步都在进行假设检验，但未对多重比较进行校正，导致最终模型的p值、标准误和置信区间均失效
  • 过拟合风险：在训练集上”精心挑选”的变量，在独立测试集上往往表现不佳
  • 理论依据缺失：这些方法是纯粹的数据驱动算法，不依赖于任何坚实的统计理论
  • 交互项处理不当：当模型中包含交互项时，这些方法无法保证主效应在交互项之前进入模型

6.3 实践建议

  • 交叉验证优于逐步筛选：建议使用交叉验证选择模型，而非依赖单次逐步筛选的结果
  • 保留测试集：始终保留独立的测试集来评估最终模型的泛化能力
  • 结合领域知识：变量筛选不应完全自动化，应结合业务或理论背景进行人工判断
  • 谨慎解读统计量：经过逐步筛选后得到的p值和置信区间不具备常规的统计推断效力

R语言为前进法和后退法提供了从基础到高级的多层次工具支持。step()函数是入门首选，stepAIC()提供了更强的稳健性，而StepReg包则适用于需要系统化模型选择框架的场景。

然而，工具的有效性取决于使用者的判断。前进法和后退法应被视为探索性工具而非确定性结论。在实际建模工作中，建议将逐步筛选的结果与交叉验证、领域知识和理论考量相结合，构建真正稳健且可解释的回归模型。

五、glmnet包

1. 概述

glmnet是R语言中用于拟合带惩罚项（正则化）广义线性模型的核心包，由Jerome Friedman、Trevor Hastie、Rob Tibshirani等统计学权威学者开发。该包通过惩罚最大似然估计（penalized maximum likelihood）求解模型，在正则化参数λ的网格上计算lasso或弹性网络（elastic net）惩罚的正则化路径。

glmnet支持以下模型类型：

模型类型 family参数 适用场景
线性回归 "gaussian" 连续型响应变量
逻辑斯谛回归 "binomial" 二分类响应变量
多项逻辑斯谛回归 "multinomial" 多分类响应变量
泊松回归 "poisson" 计数型响应变量
Cox比例风险模型 "cox" 生存分析数据
多元响应线性回归 "mgaussian" 多个连续响应变量
自定义GLM族 GLM family对象 任意指数分布族

该包的算法采用循环坐标下降法（cyclical coordinate descent），以路径方式（path-wise fashion）求解，计算效率极高，并能充分利用输入矩阵x的稀疏性。一个重要的实用特性是：由于算法依赖热启动（warm starts），拟合完整的正则化路径通常比计算单个λ值的拟合更快。

2. 核心优化问题

glmnet求解如下优化问题：

\[ \min_{\beta_0,\beta} \frac{1}{N} \sum_{i=1}^{N} w_i \cdot l(y_i, \beta_0 + \beta^T x_i) + \lambda \left[ (1-\alpha) \frac{\|\beta\|_2^2}{2} + \alpha \|\beta\|_1 \right] \]

其中：

  • \(l(y_i, \eta_i)\)为第\(i\)个观测的负对数似然贡献（高斯情形下为\(\frac{1}{2}(y_i-\eta_i)^2\)）

  • \(\alpha\)为弹性网络混合参数，控制L1与L2惩罚的比例

  • \(\lambda\)为正则化强度参数，控制惩罚的整体强度

该公式适用于预测变量已标准化为单位方差的情形。

3. 核心参数详解

3.1 模型选择参数

alpha：弹性网络混合参数，取值范围\(\alpha \in [0,1]\)。

  • \(\alpha = 1\)：LASSO（L1惩罚，默认值）

  • \(\alpha = 0\)：岭回归（Ridge，L2惩罚）

  • \(0 < \alpha < 1\)：弹性网络（Elastic Net），混合L1与L2惩罚

Lasso倾向于从相关变量中”选其一而舍其余”，而岭回归则将相关变量的系数相互”收缩”；弹性网络混合了这两种特性：当预测变量呈组相关性时，\(\alpha=0.5\)倾向于整组选择或整组剔除。

family：响应变量的分布族，可选值包括"gaussian"、"binomial"、"multinomial"、"poisson"、"cox"、"mgaussian"。从4.0版本起，family参数也支持stats包中的任意GLM族对象。

3.2 正则化路径参数

nlambda：λ序列的长度，默认值为100。实践中建议保持默认值或更大。

lambda：用户自定义的λ序列。通常不提供此参数，由程序自动构建。警告：避免提供单个λ值（交叉验证后的预测应使用predict()方法）；应提供一个递减的λ序列，因为glmnet依赖热启动机制加速计算。

lambda.min.ratio：生成λ序列中最小值与最大值之比。默认值取决于样本量\(nobs\)与变量数\(nvars\)的关系：

  • 若\(nobs > nvars\)，默认值为0.0001（接近零）

  • 若\(nobs < nvars\)，默认值为0.01

3.3 数据预处理参数

standardize：逻辑值，指示是否在拟合前对预测变量矩阵x进行标准化（使其具有单位方差），默认值为TRUE。系数始终以原始尺度返回。若所有变量已处于相同量纲，可考虑关闭标准化。

intercept：是否拟合截距项，默认TRUE；设为FALSE则强制截距为零。

3.4 收敛控制参数

thresh：坐标下降的收敛阈值。每次内层坐标下降循环持续运行，直到任何系数更新后目标函数的最大变化量小于thresh乘以零偏差（null deviance）。默认值为1e-7。

maxit：所有λ值上的最大数据遍历次数，默认值为1e+5。

3.5 变量选择与约束参数

penalty.factor：应用于每个系数的单独惩罚因子，是一个与lambda相乘的数值，用于实现差异化的收缩强度。

  • 设为0表示该变量不受惩罚，始终被纳入模型

  • 默认所有变量为1

  • 设为Inf的变量会被转换为exclude（排除）

  • 惩罚因子内部会重新缩放，使其总和等于变量数\(nvars\)

exclude：要从模型中排除的变量索引，默认无。相当于对排除的变量施加无穷大惩罚因子。用户也可提供一个exclude函数。

dfmax / pmax：限制模型中非零系数的最大数量（dfmax）或曾经非零的最大变量数（pmax）。适用于变量数量极大时只需部分路径的情形。

lower.limits / upper.limits：每个系数的上下界约束向量。下界默认-Inf（每个下界必须非正），上界默认Inf。

3.6 观测权重参数

weights：观测权重向量，默认每个观测的权重为1。glmnet会将权重重新缩放，使其总和等于样本量\(N\)。

4.主要函数

4.1 glmnet()：核心拟合函数

glmnet(x, y, family = c("gaussian", "binomial", "multinomial", "poisson", "cox"),
       weights, alpha = 1, nlambda = 100, lambda.min.ratio,
       lambda, standardize = TRUE, intercept = TRUE, thresh = 1e-07,
       dfmax, pmax, exclude, penalty.factor, lower.limits, upper.limits,
       maxit = 1e+05, ...)

输入要求： - x：数值矩阵（不能为数据框），每行为一个观测，每列为一个变量 - y：响应变量，其类型取决于family

4.2 cv.glmnet()：交叉验证选择λ

cv.glmnet(x, y, ..., nfolds = 10, type.measure = c("deviance", "mse", "mae", "class"))

通过K折交叉验证自动选择最优λ值。type.measure指定交叉验证的评估指标。

4.3 辅助函数

  • predict()：基于拟合模型对新数据进行预测
  • plot()：绘制正则化路径图
  • coef()：提取指定λ下的回归系数
  • print()：打印模型摘要

5. 完整示例

以下以波士顿房价数据为例，演示从岭回归到弹性网络的完整流程：

# 1. 加载包与数据
library(glmnet)
library(MASS)  # 包含Boston数据集


data(Boston)
x <- as.matrix(Boston[, -which(names(Boston) == "medv")])
y <- Boston$medv


# 2. 岭回归 (alpha = 0)
fit_ridge <- glmnet(x, y, alpha = 0, family = "gaussian")
plot(fit_ridge, xvar = "lambda", label = TRUE)
# 岭回归的系数随λ变化而收缩，但不会归零


# 3. LASSO (alpha = 1, 默认)
fit_lasso <- glmnet(x, y, alpha = 1, family = "gaussian")
plot(fit_lasso, xvar = "lambda", label = TRUE)
# LASSO的系数会随λ增大而逐个归零，实现变量选择


# 4. 弹性网络 (alpha = 0.5)
fit_enet <- glmnet(x, y, alpha = 0.5, family = "gaussian")


# 5. 交叉验证选择最优λ (以LASSO为例)
set.seed(2026)
cv_fit <- cv.glmnet(x, y, alpha = 1, family = "gaussian",
                    nfolds = 10, type.measure = "mse")


# 查看最优λ
print(cv_fit$lambda.min)        # 最小MSE对应的λ
print(cv_fit$lambda.1se)        # 1个标准误法则对应的λ（更稀疏）


# 6. 绘制交叉验证曲线
plot(cv_fit)


# 7. 提取最优模型系数
coef_min <- coef(cv_fit, s = "lambda.min")
coef_1se <- coef(cv_fit, s = "lambda.1se")


# 8. 对新数据进行预测
new_data <- x[1:5, ]  # 取前5条作为新样本
pred_min <- predict(cv_fit, newx = new_data, s = "lambda.min")
pred_1se <- predict(cv_fit, newx = new_data, s = "lambda.1se")

glmnet包凭借其极高的计算效率、统一的建模框架和灵活的惩罚结构，已成为高维数据建模领域的事实标准工具，在金融资产定价、基因表达数据分析、信用评分建模等场景中得到了广泛应用。

六、ordinalNet包

ordinalNet 是一个用于拟合带弹性网络（Elastic Net）惩罚的序数回归模型的R包。它通过坐标下降算法进行模型拟合，能够高效地处理具有序数结果变量的数据。其核心方法详见 Wurm, Hanlon, and Rathouz (2021) 的论文。

1. 核心特性与模型框架

ordinalNet 的核心是提出了 ELMO（elementwise link multinomial-ordinal） 模型类别。它支持多种模型链接函数和结构，为序数回归提供了极大的灵活性。

  • 支持的模型族 (Family)：可通过 family 参数指定，包括:

    • "cumulative"：累积概率模型
    • "sratio"：停止比模型
    • "cratio"：连续比模型
    • "acat"：相邻类别模型

  • 支持的链接函数 (Link)：可通过 link 参数选择，包括 "logit", "probit", "cloglog", "cauchit" 等。

  • 三种模型结构 (Parallelism)：这是 ordinalNet 的一大特色。

    • 平行模型 (Parallel)：所有预测变量在各响应类别间共享一套系数，适用于标准的序数数据。这是最简洁的模型。
    • 非平行模型 (Nonparallel)：每个响应类别（除基线外）都有自己的系数集，适用于无序类别响应或需要更高灵活性的场景。
    • 半平行模型 (Semi-parallel)：允许部分变量平行、部分非平行，是一种折中方案。弹性网络惩罚会将其“收缩”向更简洁的平行模型，在灵活性与简洁性之间取得平衡。

2. 主要函数与参数

ordinalNet 包的核心是 ordinalNet() 函数，其主要参数如下：

参数 说明 默认值
x 协变量矩阵。建议将分类变量转换为没有基线组的一套指示变量（dummy variables）。 无
y 响应变量。可以是因子（factor）、有序因子（ordered factor）或代表多项计数的矩阵。 无
alpha 弹性网络混合参数。alpha=1 为 Lasso 惩罚，alpha=0 为 Ridge 惩罚。 1
family 指定模型族，如 "cumulative"。 "cumulative"
link 指定链接函数，如 "logit"。 "logit"
parallelTerms 逻辑值，TRUE 表示包含平行项。 TRUE
nonparallelTerms 逻辑值，TRUE 表示包含非平行项。 FALSE
lambdaVals 用户自定义的惩罚参数 λ 序列。 NULL
nLambda 自动生成 λ 序列的长度。 20
lambdaMinRatio λ 序列中最小值与最大值的比率。 0.01

此外，ordinalNet 还提供了其他有用的函数：

  • ordinalNetTune()：通过K折交叉验证来为 λ 选择合适值。

  • ordinalNetCV()：在每折交叉验证内部调优模型，并评估调优后模型的样本外预测性能。

  • coef(), predict(), summary() 等，用于提取系数、进行预测和查看模型摘要。

3. 使用示例

以下是一个使用 ordinalNet 拟合平行累积 Logit 模型（即比例优势模型）的基本示例：

library(ordinalNet)


# 加载示例数据（来自 ordinalgmifs 包）
data(hccframe)
y <- hccframe$group
x <- as.matrix(subset(hccframe, select = -group))


# 拟合平行累积 Logit 模型 (比例优势模型)
fit <- ordinalNet(x, y,
                  family = "cumulative",
                  link = "logit",
                  parallelTerms = TRUE,
                  nonparallelTerms = FALSE)


# 查看模型摘要
summary(fit)


# 提取系数（默认选择 AIC 最优的模型）
coef(fit, matrix = TRUE)

七、plm包和面板数据

plm 是 R 语言中用于面板数据（Panel Data）计量经济学分析的核心包。它提供了一套完整且强大的工具集，让线性面板数据模型的估计、检验和推断变得非常直接。

1. 核心功能

plm 包的功能可以划分为以下几个主要模块：

  • 模型估计：提供多种面板数据模型的估计函数。
  • 统计检验：包含丰富的模型设定、序列相关、截面相关等检验。
  • 稳健协方差矩阵：提供多种异方差和自相关稳健的标准误估计。
  • 数据处理：提供专门的面板数据框（pdata.frame）和数据转换函数。

2. 支持的模型类型 (Model Estimation)

plm 包能估计大量线性面板数据模型，其主要估计函数包括：

函数 模型类型 说明
plm 核心估计函数 面板数据模型的主力，支持固定效应 (within)、随机效应 (random)、组间 (between)、一阶差分 (first-difference) 等。也支持工具变量 (IV) 和 Hausman-Taylor 模型。
pvcm 变系数模型 允许不同个体有不同的系数。
pgmm 广义矩估计 (GMM) 用于动态面板数据模型。
pggls 可行广义最小二乘法 (FGLS) 用于处理面板数据中的异方差或自相关。
pmg 均值组 (MG) 估计 用于处理截面相关性的非平稳面板。
pcce 共同相关效应 (CCE) 估计 处理存在共同因子的面板数据模型。
pldv 受限因变量模型 用于面板数据中的二元或计数等受限因变量。

3. 统计检验

plm 提供了全面的检验函数来验证模型假设：

  • 模型设定检验：用于判断应该使用混合OLS、固定效应还是随机效应模型。例如 pFtest (F检验)、plmtest (拉格朗日乘子检验)、phtest (Hausman检验)。
  • 序列相关检验：检验面板数据模型中的误差项是否存在自相关。
  • 截面相关检验：检验不同个体之间的误差项是否相关（pcdtest）。
  • 面板单位根检验：检验面板数据序列的平稳性（purtest）。
  • 面板格兰杰因果检验：检验变量间的因果关系（pgrangertest）。

4. 数据处理

plm 提供了专门用于处理面板数据的工具：

  • pdata.frame：一种增强的数据框，用于存储面板数据，并通过 index 参数明确个体和时间维度。
  • 数据转换：提供了 Between(), within(), lag(), lead(), diff() 等函数，方便进行组间、组内变换及滞后、差分操作。
  • 数据诊断：is.pbalanced() 检查数据是否平衡，pdim() 查看面板维度等信息。

5.使用示例

下面是一个使用 plm 包进行面板数据回归的典型流程：

# 1. 安装并加载包

# 2. 加载内置数据集 (Grunfeld, 10家公司的投资数据)

# 3. 估计模型

            index = c("firm", "year"), model = "pooling")


# 个体固定效应模型 (One-way FE)

          index = c("firm", "year"), model = "within")

          index = c("firm", "year"), model = "random")

# 6. 使用稳健标准误

coeftest(fe, vcov = robust_se)

八、rlm()函数和稳健回归

rlm()（Robust Linear Model）函数来自R的MASS包，是一种经典的稳健回归方法。它的核心思想是为回归找到更稳健的系数估计，自动降低数据中异常值（outliers）的影响。

1. 核心用法与参数

rlm()的基本用法与lm()非常相似：

library(MASS)


# 基本语法
model <- rlm(formula, data, ...)


# 完整参数（以formula方法为例）
rlm(formula, data, weights, ..., subset, na.action,
    method = c("M", "MM", "model.frame"),
    wt.method = c("inv.var", "case"),
    model = TRUE, x.ret = TRUE, y.ret = FALSE, contrasts = NULL)

以下是几个关键参数的详细说明：

  • method: 指定估计方法。
    • "M"（默认）：标准的M估计（M-estimation）。
    • "MM"：MM估计。具有更高的抗扰动性（breakdown point），能抵抗高达50%的异常值，但计算更复杂。
  • psi: 指定权重函数（psi函数），这是rlm()的核心。MASS包内置了三种常用的psi函数：
    • psi.huber (默认)：稳健性适中，保证解的唯一性。
    • psi.bisquare (Tukey’s biweight)：对远离中心的异常值权重会降至0，更激进，但可能有多个局部最优解。
    • psi.hampel：折中方案，在Huber和bisquare之间。
  • scale.est: 指定误差尺度（残差标准差）的估计方法。
    • "MAD"（默认）：使用残差的中位数绝对离差来估计，非常稳健。
    • "Huber" 或 "proposal 2"：使用Huber提出的提案2方法。
  • init: 指定迭代算法的初始值。默认"ls"使用普通最小二乘法（OLS）的结果作为初始值。
  • maxit: 最大迭代次数，默认为20。
  • acc: 迭代收敛的精度，默认为1e-4。

2. 代码示例

我们用一个包含异常值的数据集来演示rlm()的效果。

# 加载MASS包
library(MASS)


# 1. 准备数据：使用MASS包内置的stackloss数据集
data("stackloss")
head(stackloss)


# 2. 拟合一个普通的线性模型 (OLS) 作为对比
lm_model <- lm(stack.loss ~ Air.Flow + Water.Temp + Acid.Conc., data = stackloss)
summary(lm_model)


# 3. 使用 rlm() 拟合稳健回归模型 (默认的M估计 + Huber权重函数)
rlm_model_default <- rlm(stack.loss ~ Air.Flow + Water.Temp + Acid.Conc.,
                         data = stackloss)
summary(rlm_model_default)


# 4. 尝试不同的psi函数 (Tukey's bisquare) 和 MM估计
rlm_model_bisquare <- rlm(stack.loss ~ Air.Flow + Water.Temp + Acid.Conc.,
                          data = stackloss,
                          psi = psi.bisquare,
                          method = "MM")
summary(rlm_model_bisquare)

输出解读：

  • summary(lm_model)会显示OLS的结果，它可能受到数据中潜在异常值的显著影响。

  • summary(rlm_model_default)会显示稳健回归的结果。你会看到系数估计值可能与OLS不同，并且输出中会包含权重信息，表明哪些观测值被赋予了较低权重（即被认为是异常值）。

  • summary(rlm_model_bisquare)则展示了使用不同psi函数和MM估计的结果，它可能对异常值更加不敏感。

3. 注意事项

  • 应用场景：当你的数据中存在明显的异常值，且担心它们会过度影响回归结果时，应优先考虑rlm()。
  • 参数调优：psi函数的选择及其调节常数（tuning constants） 至关重要。例如，psi.bisquare的默认调节常数c = 4.685旨在保证95%的渐近效率。你可以根据对稳健性和效率的权衡进行调整。
  • 局限性：rlm()主要对响应变量（Y）中的异常值稳健，但对预测变量（X）中的高杠杆点（high-leverage points） 可能不够稳健。对于高杠杆点，可以尝试method = "MM"。
  • 模型诊断：建议同时拟合OLS和rlm()模型并比较结果。如果差异很大，说明异常值影响显著，稳健回归的结果更可信。

总的来说，rlm()是一个强大且易用的工具，能有效应对回归分析中的异常值问题。理解其核心参数（尤其是psi函数和method）是正确使用它的关键。
